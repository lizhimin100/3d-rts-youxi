# 地图编辑器（EditorPlugin）

给自己的 Godot 4.7 地图编辑器，界面照魔兽「地形编辑器 + 工具面板」的路子来。**只做地图**：
地形、对象摆放、玩家/出生点、区域、波次、保存/加载、校验、Test Map。

## 打开

1. Godot 打开本项目 → 顶部多出 **地图编辑器** 页签（图标是自绘的 16×16 小格子）。
2. 右侧 Dock 多出 **地图工具**，六页：**地形 / 对象 / 区域 / 属性 / 校验 / 历史**。
3. 第一次进入会先弹「新建地图」：地图大小（128/160/200/256）、玩家数（2/4）、随机种子，
   然后选「创建示例地图」（带地形/基地/金矿/树林）或「空白平地」。
4. 左侧竖条是「层」：**地形 / 单位 / 建筑 / 装饰 / 资源 / 区域** —— 点哪一层，
   右边 Dock 就切到对应面板，鼠标左键就干那一层的事（和魔兽工具面板一个逻辑）。

## 对魔兽编辑器的取舍

| 魔兽编辑器 | 这里 | 说明 |
|---|---|---|
| 主菜单 文件/编辑/视图/地图 | 同 | 新建、打开、保存、另存为、Test Map、撤销/重做、历史、网格/区域显隐 |
| 左侧地形/单位/装饰分层 | 同 | 六层；点层 = 拿工具，Dock 跟着切页 |
| 工具面板（Terrain / Doodad / Unit / Region） | 同 | Dock 六页；地形分成「应用纹理 / 应用高度」 |
| Doodad 按类别筛选 | 同 | 装饰子类：植被 / 岩石 / 营地 / 残迹 / 杂物 + 搜索 |
| 3D 视口 + 状态栏 | 同 | 独立 SubViewport，坐标/工具/校验常驻 |
| 触发器 / 副官 / UI 编辑器 | **不做** | 明确非目标，不把地图编辑器做成万能 IDE |
| 自定义主题 | **Godot Theme 资源** | 设计 token 编译成 `编辑器主题.tres`，不是自制 cfg |

## 地形怎么刷

地形页刻意分成两块，别再混：

| 区块 | 作用 | 工具 |
|---|---|---|
| **应用纹理** | 只改**地表颜色**，不动高度 | 草地 / 泥土 / 岩石 / 沙地（带色块）/ 擦除地表 |
| **应用高度** | 只改**起伏**，不动地表 | ↑ 抬升 / ↓ 降低 / ≈ 平滑 / ▭ 压平 |
| 其它 | | 水面（挖碗+放水）、刷子大小（1~60m）、圆/方、强度、网格吸附 |

- 抬升/降低：**按住左键不放会持续改**，松开算一笔（撤销也是一笔）。
- 纹理：刷一遍就上色，走的是独立贴地薄面（编辑器与游戏同一个生成函数）。
- 压平：以按下那一刻的地面高度为准，把范围内抹平。

## 装饰：只收自然物

「**装饰**」层的数据源**只有** `美术/模型/v7_自然/` 的白名单，**绝不再扫根模型目录**：

- 装饰（12 项，按子类筛选）：草丛 / 岩石 / 木桶 / 木箱 / 栅栏 / 旗帜 / 帐篷 / 断墙 /
  路标 / 木桩 / 营火 / 尸骨
- 「**资源**」层：树、金矿（走可采集物流程）
- 「**单位**」：农民/步兵/弓箭手/法师；「**建筑**」：大本营/兵营/铁匠铺/农场/箭塔

单位、建筑各有自己的层，**不允许**混进装饰列表。装饰列表里显示「名称 · 子类」，
选中类型后在视口空地左键放置；点已有对象是选中、拖动是移动、Shift 加选、Delete 删除。

## 建筑建造网格（与寻路共用一套）

所有建筑落点 / 朝向都只走 `代码/单位/建筑网格.gd`，**和寻路共用 1m 格**：

- 偶数占地吸**格线**（6×6 正好压 6×6 格），奇数占地吸**格心**；幂等。
- 朝向只允许 **90° 档**（资产是正交墙线；斜放会露底/破面）。
- 编辑器里放置建筑时：鼠标处实时显示半透明体块 + 占用格线框（绿=可放、红=越界/压水/压坡/压建筑），
  **R 转 90°**（Shift+R 反向）；放下后位置/朝向再吸一次，绝不骑格。
- 选中建筑时，视口里画出它压住的每一格（和建造预览、寻路阻挡是同一套格）。
- 游戏侧：农民建造、AI 建造、地图加载、开局基地全部走同一套吸附；旧图/手改 JSON
  在编辑器打开时自动修正，校验面板会提示未对齐的建筑。
- 建筑不允许缩放（占地会与寻路格错位）；旋转按钮对建筑自动按 90° 档走。

## 撤销面板（Tree）

Dock 第六页「历史」用编辑器自带的 **Tree** 实现，数据直接来自 `EditorUndoRedoManager`：

- 所有地形笔刷、对象放置/拖动、区域、玩家/波次属性修改都会出现；
- 点任意一条记录**直接跳到那一步**（不是只能 Ctrl+Z 一步一步退）；
- 灰字 = 已撤销、还能重做；「回到初始」= 撤销到打开/新建地图时的状态；
- 支持撤销一步 / 重做一步。

## 主题（token → Godot Theme 资源）

编辑器皮肤来自 `代码/界面/界面规格.gd` 的设计令牌，一次性编译成：

```
res://addons/map_editor/编辑器主题.tres
```

主屏与 Dock 都 preload 这个 **Theme 资源**，Button / TabContainer / Tree / ItemList /
LineEdit / PopupMenu / Label 语义变体全部由主题提供；控件上不再散落 StyleBoxOverride。
改 token 后重跑：

```bash
godot --headless --path . --script 工具/生成编辑器主题.gd
```

## 动效

向导开合、状态栏提示、Dock 切页、建筑放置预览都走 **Tween**，没有自制动画框架；
单位/建筑受击也是 Tween 驱动（暖橙低强度脉冲 + 0.12s 方向性顿挫），不再整片泛白闪白。

## 视角

| 操作 | 说明 |
|---|---|
| 中键拖动 / **Alt+左键拖动** | 转视角 |
| 右键拖动 | 平移 |
| 滚轮 | 缩放 |
| WASD / QE | 平移 / 转视角（3D 面板有焦点时） |
| F | 对准选中对象；1 / 2 拉近拉远；Delete 删除；Esc 取消/清选择 |
| R / Shift+R | 放置建筑时转 90° |

菜单「视图」里也有 俯视 / 斜视 / 复位 / 显示网格 / 显示区域。

## 保存位置

所有地图与运行时产物都在**项目内的 `地图/` 文件夹**，不写 C 盘：

- 手存：`res://地图/<名字>.tres`（或 .json，另存为时选格式）
- 自动保存：`res://地图/_自动保存.tres`（每 120 秒，改动过才写）
- Test Map 临时图：`res://地图/_测试地图.tres`
- 最近地图列表：`res://地图/_最近地图.cfg`

（这三个下划线文件已进 .gitignore。）

## Test Map

保存临时图 → `OS.create_process()` 起独立游戏进程并传 `--map=res://地图/_测试地图.tres`，
**不阻塞编辑器**，你可以继续改。

## 命令

```bash
# 直接切到地图页签
godot --path . --editor -- --map-editor-open
# 编辑器链路自检（Dock 六页 / Theme / Tree 历史 / 笔刷→撤销→重做 / 跳历史 / 网格 / 装饰边界 / 存读 / 校验）
godot --headless --editor -- --map-editor-selftest
# 数据层自检（新建 + 建筑网格 + 存读/JSON/五关校验/三种毛病）
godot --headless --path . -- --map-editor-test
# 设计 token → Theme 资源
godot --headless --path . --script 工具/生成编辑器主题.gd
# 开发用：开一张示例图 + 截编辑器窗口
godot --path . --editor -- --map-editor-shot=E:/tmp/ui.png --map-editor-shot-demo
```

## 数据

`代码/地图核心/地图定义.gd` → `MapDef`：version / size / seed / biome / heightmap / splatmap /
water / objects / regions / players / waves / camera_bounds / victory。
对象只存数据不存节点，加载时由 `MapLoader` 重建；老版本由 `MapStore.migrate()` 补字段。
游戏侧 `--map=<路径>` 走 `MapLoader.apply_to_level()`，地形/寻路/道具/材质全部复用现成实现。

## 已知边界

- 地表层是独立贴地薄面（不改现有地形材质），编辑器与游戏用同一个函数生成。
- 水面沿用游戏单水潭能力（取 `water.spots[0]`）。
- 4 人图能编辑能存，运行时仍是玩家/敌人两个阵营。
- 编辑器里不建远景山脊（游戏里仍然有），免得编辑区旁边立一圈山。
- 建筑资产是 StandardMaterial3D（硬约束），施工「剖切」在没有 shader 时退化为纵向压缩，
  自检同时接受两种路径。
