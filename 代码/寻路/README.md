# 代码/寻路

> 状态：现行

- **职责**：1m 栅格 A*（8 向、octile 1.25）+ 净空表 + 拉直 + 空间哈希。
- **不属于这里**：单位怎么走（`单位/单位.gd` 的 `_steer`）、大群流场（`人群/人群流场.gd`）。
- **唯一入口**：`GridPathfinder.find_path(from, to, radius)`；`RtsWorld.pathfinder()` 拿实例。
- **禁改**：`PATH_ROOM_MIN=6` 以下的地形不要放宽（会让 1m 缝进得去出不来）。

## 关键数字

| 项 | 值 | 说明 |
|---|---|---|
| 网格 | 224² ≈ 5 万格 | `CELL=1.0` |
| 单次 A* | 0.4–2.3 ms | 每帧上限 6 条 |
| 拉直 | 26 格窗口 + 二分 | `SMOOTH_WINDOW=26` |
| 净空 | `_clear` 表（每格到墙距离） | 体积判定的基础 |
| 占格 | 引用计数 | 拆建筑会减回去 |

## 已知坑

1. **不要零余量贴墙**：分离每帧推 0.027m，零余量会被推到墙外再推回来，每帧对拉（`网格寻路.gd:45-52` 记的事故）。
2. `mark_blocked_rect` 每格清 9 格 × 3 表，批量时会尖峰；改"脏块 + 下一帧统一重建"。
3. `空间哈希.gd` 是 `Dictionary + Array`，大群场景请用 `人群/人群空间.gd`（计数排序）。
