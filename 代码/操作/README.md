# 代码/操作

> 状态：现行

- **职责**：玩家输入 → 命令：选择（框选 / 点选）、指令（移动 / 攻击 / 建造 / 技能）、战区指令。
- **不属于这里**：命令怎么执行（`单位/`）、AI 决策（`ai/`）。
- **唯一入口**：`选择系统._unhandled_input` / `指令系统._unhandled_input`；所有玩家命令最后都发 `Game.order_issued`。
- **禁改**：`指令系统` 的建造放置流程（吸附 / 合法性 / 扣钱顺序）—— 三处判断已经很难对齐。

## 文件分工

| 文件 | 干什么 |
|---|---|
| `选择系统.gd` | 框选 / 点选 / 双击同类 / 选中圈（`range_ring_radius_of` 唯一出口） |
| `指令系统.gd` | 右键上下文命令、建造放置、技能施放、编队 |
| `移动指示.gd` | 绿色虚线 + 目的地标记（只订阅 `Game.order_issued`） |
| `战区指令输入.gd` | F5–F8 四类战役级指令（单击 = 目标 / 拖拽 = 区域） |
