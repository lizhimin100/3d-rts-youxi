## 2 不改的硬契约（与 v6 完全一致）

- **27 骨骼、骨骼名逐字不变**：root / hips / spine / chest / neck / head、
  shoulder|upperarm|forearm|hand ×2、thigh|shin|foot|toe ×2、cape.01–03、skirt.F/B。
- **动画名不变**：idle / walk / attack / shoot / cast / gather / build / hurt / death；
  循环 idle/walk，单次其余，death 停最后一帧。
- **坐标**：脚底 z=0，+Y 正面（导出 Godot 为 -Z 正面）。
- **材质协议**：`M_<zone>` / `M_<zone>_team`，引擎 MatKit 按名字换卡通着色器并按 zone 上色；
  贴图是乘算细节层（均值 0.9），顶点色 COLOR_0 是 Cycles 烘的接触阴影（AO）。
- **导出**：三角化 + TANGENT + TEXCOORD_0 + COLOR_0 + JOINTS_0/WEIGHTS_0，
  `export_vertex_color="ACTIVE"`。

> 换句话说：**引擎侧一行代码不用改**。把 GLB 覆盖到 `美术/模型/` 同名文件、
> 重跑 `godot --headless --path . --import` 即可。

## 3 每件改了什么（v6 → v7）

### 步兵
- 护肩：2 层 → **3 层叠压**，每层下缘压金边，顶层加脊板 + 3 颗铆钉（肩宽 0.97 → 1.06m）。
- 盔冠羽饰：单条 → **主冠 + 两根侧羽**，加高到约 0.24m，纯队伍色。
- 盾：半径 +20%，**双层凸起盾心 + 金色十字徽 + 4 端铆钉**，外倾 16°（露躯干）。
- 剑：刃长 0.72m、加宽，**长护手 + 两端翘起 + 缠绳柄 + 配重球**；握点抬高、前倾 24°，剑尖离地 0.14m。
- 新增：斜挎皮带、金色胸章（太阳盘 + 四芒）、加厚腰带 + 大金扣 + 右胯腰包、
  胫甲/大膝甲/两道绑腿、五片腰甲（原四片）。

### 弓箭手
- 兜帽：加大加深（后脑壳 + 顶部尖角 + 高帽檐），**前方敞开露脸**；披肩加宽。
- 弩：臂展 ×1.3、弩身加厚，新增**两端滑轮、绞盘、皮托、箭镞高光**。
- 箭袋：加大到 7 支箭 + 上口皮箍 + 两条背带，整体下移、外倾（不再在头顶扎成"鸡冠"）。
- 新增：两片叠压肩甲、加宽皮护腕、膝甲、左右腰包。

### 法师
- 帽：宽檐 ×1.30、帽锥更高（SIL hat 1.22 → 1.30）。
- 法杖：更长（1.80m），**三爪金座 + 水晶 ×1.6**，杖身两道金箍。
- 新增：腰间**大书**（封皮 + 书页 + 四角金片 + 金扣带 + 锁链），挪到侧前方可见。
- 保留：长袍金边、立领、肩披、金圆徽、袍摆褶。

### 农民
- 草帽：帽檐 0.205 → **0.245**、帽冠加高，编纹 12 → 14 道 + 两圈环纹 + 补丁 + 破损缺口。
- 背篓：加大（+20%）、四道绳箍、12 根柳条、**顶上卷毯**、双肩带。
- 武器：锤子 → **锄头**（0.72m 木柄 + 缠绳握把 + 锄刃 + 刃口高光）。
- 保留：围裙/口袋、补丁缝线、绑腿、卷袖口、领巾。

## 4 重建方法

```powershell
# 全量（4 件，含 QC 与导出）
& 'E:/tmp/blender_ok/blender.exe' -b --factory-startup `
  --python '工具/建模/v7_单位/build_v7.py' -- all --qc --export

# 单件（例：步兵）
& 'E:/tmp/blender_ok/blender.exe' -b --factory-startup `
  --python '工具/建模/v7_单位/build_v7.py' -- footman --qc --export
```

- 必须用 `E:/tmp/blender_ok/blender.exe`（D 盘原目录带 Low Mandatory Level，起不来）。
- 贴图来自 `美术/贴图/` 的 15 个族（`ashlar/plaster/shingle/metal/plank/leather/cloth/bark/leaf/...`），
  UV 是世界坐标盒式投影（`v5/textured.py`），**跨物体密度一致**。
- 导出后要 `godot --headless --path . --import` 让 Godot 重新导入 GLB。
- 报告：`工具/建模/v7_单位/report_v7.json`；日志：`run_*.log`。

## 5 QC 图

- 机位：**高机位俯视**（仰角约 42°）、58mm 长焦、距离 = 4.1 × 单位高，
  单位占画面高度约 35–40% —— 接近 RTS 的观感，不是影棚特写。
- 姿态：脚本次用 idle 第 8 帧（弓手用 shoot 第 13 帧，弩才抬起来），
  即"游戏里看到的样子"，而不是 T-pose。
- 背景：暗绿灰地面 + 双太阳（主光暖、补光冷），保留投影来判断体量。

## 6 已知取舍

1. **贴图内嵌**：每件 GLB 把用到的贴图族整包写入（6–14 张），所以单件 3.7–4.9 MB。
   想瘦身要做图集（3 栋建筑那套：主体/ORM/自发光），属于下一阶段。
2. **没有 LOD**：引擎 `模型工厂.gd` 已支持 `_中`/`_远` 兄弟文件，但本批未做远/中档。
3. **death 时披风可能扫到地面**：披风加长了 6cm，死亡塌地那几帧会穿地（RTS 镜头下不可见）。
4. **弓手瞄准时弩会横穿胸前**：这是 v3 起就有的"武器挂在 hand.R、由手部朝向决定"的
   设计，不是 v7 引入的；要改得动 `anim_shoot`，本轮按"不改动画"的约束保留。

## 7 本轮踩过的坑（已修，别再犯）

| 症状 | 根因 | 修法 |
|---|---|---|
| 护肩把脑袋吞了 | 叠甲内缘伸到头盔半径以内，高机位正好盖住脸 | 内缘必须 ≥ 头盔半宽 + 5mm（见 `pauldron_v7` 注释） |
| 弓手脸被蓝布糊死 | 兜帽做了整圈外壳 | 只做后脑 240° 弧，前方敞开 |
| 农民肩头有个蓝盒子 | `Builder.cyl` 的 loc 是**底面**，转 90° 后整根被推出去半根长度 | 卷毯 loc 补 `-L/2` |
| 农民 GLB 多一根 `neutral_bone` | 草帽的 3 个 cyl 忘了传 `weight`，产生无权重顶点 | 所有几何必须显式权重；导出后查 `skins[0].joints` 是否 27 |
| 法师脚底 -0.037m | 袍摆褶盒子中心太低，插进地面 | 抬到 `knee_z - 0.20`，脚底严格 z=0 |
