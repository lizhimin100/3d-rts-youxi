# Game/系统

> 状态：现行

- **职责**：玩法规则：战斗结算、投射物、技能、据点、日夜、野怪营地、升星。
- **不属于这里**：单位状态机（`单位/`）、AI 决策（`ai/`）。
- **唯一入口**：各系统的 `_process` + 单位回调（`take_damage` / `cast`）。
- **禁改**：`战斗.gd` 的伤害公式与 `射程基准.gd` 的 `R1=0.015 米/单位`（全项目射程口径）。

## 文件分工

| 文件 | 干什么 |
|---|---|
| `战斗.gd` | 命中判定 / 护甲 / 格挡 / 受伤倍率 / 击杀经验 |
| `投射物.gd` | 箭 / 火球（**无碰撞检测**，`k>=1` 落点结算） |
| `技能.gd` / `技能运行时.gd` / `技能特效.gd` | 技能定义 / 运行时状态 / 特效 |
| `据点.gd` | 地图中心资源箱（180s 首刷、每 120s、占 15s 给 200 金 80 木） |
| `日夜.gd` | `DAY_LENGTH=360`，`Game.is_night()` 唯一出口 |
| `野怪.gd` / `野怪营地.gd` | 中立怪与营地（拆窝后不再补怪） |
| `升星.gd` | 击杀者独得 15 经验；一星 = 金×2 + 木×3 |

## 自检

## 已知坑

1. `投射物.gd:130` 用未 clamp 的 `_t` 算 y，最后一帧过冲（60Hz ≈ 4cm，20Hz ≈ 12cm）。
2. 据点计时 `_process` 每 0.2s 判一次，但必须加整段 `_tick`；自检用 `1/60` 真步长。
