# Game/单位

> 状态：现行

- **职责**：节点制单位的**状态机 + 移动 + 采集 + 建造 + 战斗动作**，一个单位一个 `Node3D`。
- **不属于这里**：群体渲染（`人群/`）、AI 决策（`ai/`）、战斗结算公式（`系统/战斗.gd`）。
- **唯一入口**：`RtsUnit._process`；外部只能通过 `order_*` 白名单下令。
- **禁改**：
  * 不要再新增"直接写 `global_position`"的控制器 —— 现有 4 个（`_steer` / `_update_separation` / `_tick_crowd` / `_update_wall_pushout`）已经互相打架。
  * `set_state` 对"同名单次动作仍在播"直接 return（攻击只砍一刀的已知行为）。
  * 盾牌挂在 `hand_L`，改模型后必须 `--import`。

## 文件分工

| 文件 | 行数 | 干什么 |
|---|---:|---|
| `单位.gd` | 3.7k | 全部状态机：移动 / 攻击 / 采集 / 建造 / 技能 / 升星 |
| `单位视觉.gd` | — | 模型装配 + 动画播放（`play(state, speed)`） |
| `建筑.gd` | 1.4k | 建筑状态（建造进度 / 训练队列 / 研究）；可用性走 Model |
| `建筑网格.gd` | — | **建筑占格唯一入口**（1m 格、`DEFAULT_YAW=-PI`、禁缩放） |
| `可采集物.gd` | — | 树 / 金矿的剩余量与采集接口 |
| `关卡桥.gd` | — | `RtsWorld`：单位 / 建筑 / 寻路 / 地面的全局查询桥 |
| `工地表现.gd` | — | 建造中的视觉 |

## 已知坑

1. `_go_to(pos, force=true)` 必须清零 `_repath_cd`，否则原地不动。
2. 5 套"到点"判据（0.35 / 0.6 / 1.2 / 1.4 / 2.0s），同一位置会出现"战斗说到不了、采集说早到了"。
3. `单位.gd:1481` 把 dt 夹到 0.1，`time_scale>5` 时只跑 60%。
