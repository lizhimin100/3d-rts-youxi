# Game/核心

> 状态：现行

- **职责**：主场景装配（`主场景.gd`）、全局状态（`游戏状态.gd` = autoload `Game`）、地形、地图生成、关卡。
- **不属于这里**：玩法规则（`系统/`）、决策（`ai/`）。
- **唯一入口**：`Views/scenes/主场景.tscn` → `主场景._ready()` 按 1→5 顺序装配。
- **禁改**：`主场景._ready` 的装配顺序（地形 → 日夜 → 据点 → 副官 → 输入）；漏一步就是"某个系统整局不工作"。

## 文件分工

| 文件 | 行数 | 干什么 |
|---|---:|---|
| `主场景.gd` | 1.3k | 装配 + QA 挂载（`--xxx-test` 都在 `_mount_tests`） |
| `游戏状态.gd` | — | autoload `Game`：阵营 / 单位注册 / 资源 / 信号 / `suggest` |
| `地形.gd` | 1.3k | 高度场 + 坡度 + 贴地 |
| `地图生成.gd` | 2.1k | 程序化地图（对称、资源、营地） |
| `关卡.gd` | 1.5k | 从 `MapDef` 实例化关卡 |
| `常量.gd` | — | `RtsConst`：Order / State / Kind / Phase 等枚举 |

## 已知坑

1. `Game.elapsed` 是游戏内秒（受 `time_scale` 影响），`Time.get_ticks_msec()` 是墙钟，两者不能混。
2. `--quit-after` / `--resolution` 是**引擎参数**，必须在 `--` 之前。
3. `_mount_script` 对不存在的文件静默跳过 —— QA 挂了但没跑起来时，先确认路径。
