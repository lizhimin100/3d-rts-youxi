# 音频来源与许可（重要：这里是"零外部素材"的凭证）

本工程**所有音频都是程序生成的**，没有从网络下载任何素材，因此不涉及第三方版权：

| 类别 | 生成脚本 | 产出 |
|---|---|---|
| 音效（17 条：点选/框选/移动/攻击/命中/死亡/建造完成/建造锤击/建造放置/采集/法术/箭矢/塔射/低血/升级/胜负） | 工具/音频/合成音效.py | 音频/*.wav（48kHz 单声道） |
| 背景音乐（经营 80s / 会战 72s） | 工具/音频/合成音效.py | 音频/bgm_经营.wav、bgm_会战.wav（48kHz 立体声） |

> **BGM 的"无缝循环"是播放端做的**（见 代码/音频/音效管理.gd 的 _make_seamless_loop）：
> 载入时把尾 0.35s 与头 0.35s 等功率交叉淡化、再把尾段截掉，循环点两侧的样本就是
> 原文件里相邻的样本。换任何一首 BGM 都不用先离线处理文件。
> 旧素材（音频/BGM/ 的 40kHz 版、音频/bgm_战斗.wav）已删除，不再参与构建。
| 单位语音（4 兵种 × 3 应答 + 死亡） | 工具/音频/合成语音_v2.py | 音频/语音/*.wav（48kHz 单声道） |
| 口令与提示（前进/进攻/撤退/金币不足/人口已满/建造完成） | 工具/音频/合成语音_v2.py | 音频/*.wav |

> 语音走的是 **Windows 自带的 SAPI 中文语音（Microsoft Huihui Desktop）**，台词是脚本里写死的中文短句；
> 合成后再用 DSP 降调、加胸腔共振、软失真、短混响，做成战场粗嗓门。**仍然零外部素材、零版权风险。**

## 重新生成

脚本需要 **numpy**。系统 Python（C:\Program Files\Python312）没装 numpy 时，用 DSH 自带运行时：

    # 1) 音效 + BGM（约 20s）
    <python-with-numpy> 工具/音频/合成音效.py

    # 2) 语音 + 口令（调用 Windows PowerShell 的 System.Speech，约 15s）
    <python-with-numpy> 工具/音频/合成语音_v2.py

    # 3) 验收（不再生成报告清单）
    <python-with-numpy> 工具/音频校验.py           # 按 SPEC 反查素材是否齐全、规格是否达标

    # 只重做某一块
    <python-with-numpy> 工具/音频/合成音效.py --only sfx
    <python-with-numpy> 工具/音频/合成音效.py --only bgm
    <python-with-numpy> 工具/音频/合成语音_v2.py --only voices

## 电平约定（实测值）

| 类别 | 峰值 | 总线 |
|---|---|---|
| 界面点选 | -19 dBFS | UI（-16 dB，播放端再补 +6 dB） |
| 指令移动 | -15 dBFS | UI |
| 战斗命中 / 攻击 | -4 ~ -5 dBFS | SFX（-6 dB） |
| 建造 / 采集 / 箭矢 / 塔射 | -6 ~ -8 dBFS | SFX |
| 单位语音 / 口令 | -8 dBFS | Voice（-8 dB） |
| BGM | -4.5 / -3.5 dBFS | Music（-19 dB，另叠 BGM_DB -1；4k/8k/16k 收 1.5/4/7 dB） |

## 为什么不用网上素材

1. 许可要一条条核（CC0 之外都可能有署名/商用限制），核漏了就是法务风险；
2. 风格不统一：一包里是写实锤子、另一包是卡通音，拼起来很廉体验；
3. 程序生成可以**参数化**：想更轻/更闷，改脚本里的包络和滤波器就行，不用换文件。
