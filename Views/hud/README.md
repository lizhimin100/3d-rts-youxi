# Game/界面

> 状态：现行 · **铁律：没被点名的界面地方一律不要动**（`Documents/界面说明.md` 第一条）

- **职责**：HUD 底栏 / 顶部播报 / 选中面板 / 小地图 / 命令卡 / 说明气泡。
- **不属于这里**：任何游戏规则（界面只渲染状态）。训练/研究/建造判据已下沉 Model，命令卡只做翻译。
- **唯一入口**：`HUD._process`；所有尺寸走 `界面规格.gd`。
- **禁改**：底栏三段布局、经验条内嵌面板、顶部两行播报的高度算法（`_crate_banner_height`）。

## 文件分工

| 文件 | 行数 | 干什么 |

| `选中面板.gd` / `经验条.gd` | — | 竖版经验条内嵌信息面板 |
| `说明气泡.gd` + `词条.gd` | — | `RtsTipLayer`（z_index=200，必须早于面板创建） |

godot --headless --path . --script Tests/suites/界面自检.gd   # 8 项

## 已知坑

1. `Label.clip_text=true` 会把最小宽度压成 0 → 标题一律 `EXPAND_FILL`。
2. 改 `界面规格.gd` 后必须重跑：`--headless --path . --script Tools/生成编辑器主题.gd`。
3. `--editor` 启动会改资源（`.import` / uid），不要拿它做"只是看一眼"。
