# 铁血战歌 · 简易rts

一个用 **Godot 4.7 + 纯 GDScript** 从零做出来的 **3D 即时战略游戏**，玩法对标《魔兽争霸 3》：
左键选中 / 拖框群选、右键移动与攻击、屏幕边缘平滑滚屏、采金伐木、造兵升级、摧毁敌人大本营取胜。

**全部美术资产（模型、着色器、材质、环境、特效）都是在项目里用 Blender 程序化生成的**，
零外部素材；卡通三渲二（cel shading）着色器全部写在 `美术/着色器/*.gdshader` 文件里。

---

## 一、怎么跑

1. 用 Godot **4.7**（Steam 版 / 官方版皆可）打开本目录（`project.godot`）。
2. 直接按 **F5**（或用命令行）：

```powershell
# 编辑器
& 'godot.exe' --path .

# 什么都不改，直接跑主场景
& 'godot.exe' --path . --resolution 1600x900
```

首次打开会自动导入 `美术/模型/*.glb`（约 10 秒）。

> 如果刚拉了新代码、或自己加了脚本，先让 Godot 重新扫描一次：
> `godot --headless --path . --import`

## 二、操作（魔兽争霸 3 手感）

| 操作 | 键位 |
|---|---|
| 选择单个单位 | **左键单击** |
| 框选（只框自己的单位） | **左键拖拽** |
| 加选 / 减选 | **Shift + 左键** / **Ctrl + 左键** |
| 选中屏幕上所有同类单位 | **双击** |
| 移动 / 攻击 / 采集（上下文指令） | **右键** |
| 攻击移动 | **F** 然后左键点地 |
| 停止 / 原地警戒 | **X** / **H** |
| 释放技能（法师火球） | **Q / 1** |
| 建造菜单 | **B** |
| 镜头平移 | **方向键 / WASD / 鼠标怼到屏幕边缘** |
| 镜头旋转 | **Q / E** 或 **按住鼠标中键拖拽** |
| 镜头缩放 | **鼠标滚轮** |
| 镜头回中 | **空格** |
| 小地图跳转 | 在小地图上左键点击/拖动 |

**胜负**：摧毁敌方「大本营」→ 胜利；自己的大本营被拆 → 失败。结束后会出现遮罩，
点「重新开始」即可重开一局。

## 三、玩法系统

- **资源**：金币（金矿）+ 木材（树木），农民往返采集，资源量会真实消耗与枯竭。
- **人口**：大本营 +12，农场 +8；人口满了不能造兵（会提示）。
- **兵种**：
  | 单位 | 定位 | 特点 |
  |---|---|---|
  | 农民 | 经济/建造 | 采金伐木、建造建筑、能修，战斗力弱 |
  | 步兵 | 前排 | 重甲高血，近战普通伤害 |
  | 弓箭手 | 远程 | 穿刺伤害、克制轻甲、脆皮 |
  | 法师 | 法术 | 魔法远程 + **火球术**（范围伤害 + 减速） |
- **建筑**：大本营（出兵/存资源/人口）、兵营（出步兵/弓手/法师）、铁匠铺（攻防升级）、
  农场（人口）、箭塔（自动射击）。
- **护甲/伤害类型**：普通 / 穿刺 / 魔法 / 攻城 × 轻甲 / 重甲 / 城甲 / 无甲，有克制表。
- **AI**：会采资源、造农场、按兵种配比出兵、集结成波进攻、基地被袭会回防。
  三档难度（简单/普通/困难）只影响**节奏与经济**，不偷改单位数值。

## 四、工程结构

> **场景是真节点树**（不是脚本硬糊的黑盒）。打开 `场景/主场景.tscn` 能一层层扒开：
> ```
> 主场景 (Node3D)
> ├── 环境      WorldEnvironment     ← 战斗环境.tres
> ├── 主光      DirectionalLight3D   ← 暖色主光（开阴影）
> ├── 补光      DirectionalLight3D   ← 冷色补光
> ├── 关卡      RtsLevel             ← 地形网格 / 寻路 / 树·金矿·岩石 / 开局部队
> ├── 镜头      RtsCamera            ← 魔兽式镜头（子节点 Camera3D 运行时创建）
> ├── 选择系统  SelectionSystem      ← 点选 / 拖框 / 选中圈
> ├── 指令系统  CommandSystem        ← 右键上下文指令
> ├── 界面      RtsHud (CanvasLayer) ← 资源条 / 小地图 / 选中面板 / 命令卡 / 结束遮罩
> └── AI        SimpleAI
> ```
> 运行时节点总数约 **5000**（地形 6728 面 + 54 棵树 + 3 座金矿 + 26 块岩石 + 双方部队），
> 全部在 `关卡` 节点下成树，可以直接在远程场景树里选中检视。

```
project.godot              工程配置（自动加载 Cfg / Game）
场景/主场景.tscn            唯一场景，其余全部代码构建
文档/
  作战条令.md              ★ 接口契约（坐标/模型层级/API/规范），改接口先改它
  测试用例.md              ★ 严格测试用例（A~I 共 60+ 条）
  测试报告.md              每次验收自动生成
代码/
  配置/                    唯一数值来源（Cfg 单例 + GameConfig/UnitDef/DifficultyDef + 单位表）
  核心/                    常量、全局状态(Game)、主场景编排、关卡、地图生成、地形
  寻路/                    网格 A*、空间哈希
  单位/                    单位 / 建筑 / 可采集物（数据驱动 + 状态机）
  系统/                    战斗、投射物、技能
  ai/                      简单 AI
  镜头/                    魔兽式 RTS 镜头
  操作/                    选择系统、指令系统、指针拾取
  界面/                    HUD、小地图、命令卡
  美术/                    美术接口门面 + 模型工厂 / 程序动画 / 特效生成
  数据/                    阵营（经济与军队容器）
  测试/                    自检脚本与测试运行器
美术/
  模型/*.glb               12 个程序化生成的低多边形模型
  着色器/*.gdshader        三渲二主材质 / 描边 / 地形 / 水 / 特效 / 选中圈
  材质/*.tres              材质实例
  环境/战斗环境.tres       光照与后期
  主题/游戏主题.tres       UI 主题（中文字体）
  特效/*.tscn              命中/死亡/魔法/尘土/选中圈
工具/
  建模/*.py                Blender 生成脚本（可复现全部模型）
  验证.ps1                 一键验收（编译 + 跑帧 + 报错扫描 + 截图）
  导出配置.gd              把默认配置导出成可编辑的 .tres

## 五、可配置项（都在 `代码/配置/`）

- **镜头**：俯角、距离范围、边缘滚动速度/加速度/阻尼、旋转步长、边界、抖动衰减
- **经济**：初始资源、采集速率、携带量、金矿/树木储量
- **战斗**：护甲减免系数、克制表、暴击率、前摇比例、震屏强度
- **难度**：三档的思考间隔、首波延迟、波次间隔与衰减、军队上限、农民目标、经济倍率、兵种配比
- **地图**：尺寸、种子、基地坐标、树林簇数、岩石数、地形起伏
- **界面**：队伍色、小地图尺寸、HUD 配色
- **单位数值**：`代码/配置/单位表.gd`（血量/攻击/护甲/花费/训练时间/采集速率…）

想用编辑器可视化调参：跑一次
```powershell
& 'godot.exe' --headless --path . --script 工具/导出配置.gd
```
会生成 `配置/游戏配置.tres`，之后在 Godot 里双击它即可改；`Cfg` 会优先读它。

## 七、美术复现

所有模型都由 `工具/建模/*.py` 在 Blender 里程序化生成，不依赖任何外部素材：

```powershell
# 例：重建农民（Blender 5.x）
& 'D:\blender\blender.exe' -b --factory-startup --python 工具\建模\build_农民.py
```

生成脚本会输出 GLB 到 Blender 侧的可写目录，再拷进 `美术/模型/` 即可。
（注：本机 Blender 进程被低完整性沙箱限制，只能往 `D:\blender\` 树下写，
所以脚本里把输出目录设在那里，这是环境约束不是设计选择。）
