# 2026-10-24

## 地图编辑器（EditorPlugin）落地

**目标**：只做地图编辑，不碰游戏 UI/战斗/材质，编辑器是长在游戏上的一层肉。

### 新增文件

- 数据/加载层 `代码/地图核心/`（8 个，都有 .uid）
  - `地图定义.gd` MapDef（version/size/seed/biome/heightmap/splatmap/water/objects/regions/players/waves/camera_bounds/victory + height_resolution）；高度采样与 RtsTerrain 同一套对角线插值
  - `地图对象.gd` / `区域定义.gd` / `玩家槽位.gd`（含 start_yaw）/ `波次定义.gd`
  - `地图存储.gd` MapStore（.tres + JSON + migrate + 最近地图 + user:// 临时图路径）
  - `地图校验.gd` MapValidator（五关：出生点可走 / 资源可达 / 玩家不重叠 / 边界 / 敌方出生点）
  - `地图加载器.gd` MapLoader（new_map 程序生成、build_walkable_mask、to_map_data、apply_to_level、build_splat_overlay、capture_default）
- 编辑器 `addons/map_editor/`：`plugin.cfg` `插件.gd` `编辑会话.gd` `主屏.gd` `视口.gd` `停靠面板.gd` `资产目录.gd` `预览工厂.gd` `README.md`
- 自检 `代码/测试/地图编辑器自检.gd`（`--map-editor-test`）

### 对老代码的改动（仅 4 处，全部加法）

1. `代码/核心/地形.gd` 加 `@tool`（编辑器才能复用同一份地形网格/材质）。
2. `代码/核心/关卡.gd` 加 `map_def` 字段 + `build_from_map_def()`（build() 原样不动）。
3. `代码/主场景.gd` 加 `--map=` 分支、`--dump-mapdef=`、`--map-editor-test` 挂载；默认流程一行没变。
4. `project.godot` 加 `[editor_plugins] enabled=.../plugin.cfg`。

### 踩过的坑（重要）

- `EditorUndoRedoManager` **没有** `has_undo()`；要 `get_history_undo_redo(get_object_history_id(def))` 拿 UndoRedo 再 undo/redo，否则静默无效。
- MergeMode 枚举在 `UndoRedo.MERGE_*`，不在 EditorUndoRedoManager。
- `ItemList.add_item()` 返回 **void**，不能 `var idx = add_item()`（4.7 实测）。
- 撤销记录里 `after` 必须传**活引用**（`def.objects` 里的同一批实例），传克隆会让 `selection` 变野指针。
- 笔刷必须"一笔一条"：按下快照 / 松开提交；`stroke_to` 只发 `terrain_live` 轻量信号，别每帧跑校验（校验 160² 要几百毫秒）。
- 视口相机：`_pitch` 是俯角（负值），高度必须写 `-sin(_pitch)`；写成 `sin` 会钻到地下看"山碗"。
- `SubViewportContainer.stretch=true` 会接管 SubViewport 尺寸，隐藏时变 0×0 → 渲染器刷 `compute threads (0)` / `uniform_set is null`。改 `stretch=false` + `resized` 自己同步 + 隐藏时 `UPDATE_DISABLED`。
- Dock 想显示：`EditorDock` 挂在 `SideDockTabContainer` 上，要 `tc.current_tab = tc.get_tab_idx_from_control(editor_dock)`；`add_control_to_dock` 后 TabContainer 若不给 EXPAND_FILL 会只有 47px 高。
- 生成器自净：密林里会有"走不到的树"，new_map 末尾跑一次 BFS `_prune_unreachable_trees`，新建图才能 0 错误。
- 装饰对象别再塞进 `MapData.rocks`，否则关卡 MultiMesh 会重复画一遍。

### 验收结果

- 默认游戏：地形 27748 面 / 2048 节点 / 12+7 单位（与改动前一致）。
- `--map-editor-test`：31 项全过（新建/存读/JSON/五关校验/三种毛病）。
- `--headless --editor -- --map-editor-selftest`：9 项全过（Dock 300×401、笔刷→撤销→重做、放对象→撤销、存盘读回、校验）。
- `--dump-mapdef` + `--map=`：285 对象往返成功，35920 面。
- 截图确认：主屏「地图编辑器」页签 + 3D 地图（草地上有基地/兵营/铁匠铺/金矿/区域圈/网格）、状态栏坐标与"0 错误 / 0 提醒"。

### 已知边界

- 地表层是独立贴地薄面（不改地形材质），水域仍是单水潭取 spots[0]，4 人图只有 2 个运行时阵营。

## 第二轮：UI 按魔兽世界编辑器重做 + 修一堆真 bug

用户反馈：地形笔刷分不清（纹理/高度）、找不到装饰品、顶部标签图标巨大、Dock 按钮没反应、
不知道怎么转视角、没有新建地图尺寸设置、保存跑到 C 盘。

### 改了什么

1. **布局照 WE 重排**：主屏 = 菜单栏（文件/编辑/视图/地图）+ 快捷条 + 左侧「层」竖栏
   （地形/单位/建筑/装饰/资源/区域）+ 3D 视口 + 状态栏；视口左上角常驻当前工具徽标，
   底部常驻操作提示。Dock 五页改成 **地形 / 对象 / 区域 / 属性 / 校验**。
2. **地形页拆成两块**：`应用纹理`（草地/泥土/岩石/沙地，带色块 + 擦除）与
   `应用高度`（↑抬升/↓降低/≈平滑/▭压平），标签里写清"只改颜色/只改起伏"。
3. **启动先弹「新建地图」向导**（地图大小 128/160/200/256、玩家数、随机种子、示例/空白），
   不再偷偷自动建图。
4. **页签图标**：原来 `_get_plugin_icon()` 返回 `res://icon.svg`（整个项目大 Logo），
   编辑器把它放大显示 → 现在自绘 16×16 小地图图标。
5. **Dock 按钮没反应的真因**：① 重写主屏时漏了 `viewport.setup(session)`，视口拿不到会话永远不建图；
   ② Dock 调相机靠按名字找节点；③ 无选中时按钮静默无效。
   → 改成 `session.viewport` / `session.dock` 直接引用；无选中时按钮自动置灰；粘贴不受限。
6. **视角**：中键/Alt+左键转、右键拖平移、滚轮缩放、WASD/QE、F 对准；菜单「视图」也有。
7. **相机默认距离** size×0.95（原来 0.66 太近）；编辑器**不建远景山脊**
   （`RtsTerrain.build()` 加第 4 个可选参数 `p_far_ridges := true`，游戏默认不变）。
8. **保存全部进项目**：`res://地图/` —— 手存 `<名字>.tres`、`_自动保存.tres`、`_测试地图.tres`、
   `_最近地图.cfg`；后三个已进 .gitignore。实测游戏 `--map=res://地图/_自动保存.tres` 能载入。

### 新踩的坑

- 重写 `setup()` 时漏一行 `viewport.setup(session)` → 视口静默不建图，查了半天。
- 编辑器窗口被别的程序挡住时会**降频不渲染**，`get_viewport().get_texture().get_image()`
  截到的是旧帧；截图前要 `window_move_to_foreground()` + 等两帧。
- `--map-editor-shot=` 前缀长度是 18，`substr(19)` 会吃掉路径首字符。
- 主屏切换要在 Dock 之前/之后留几帧，否则编辑器布局会把 Dock 页签重置回检查器。

### 本轮验收

- 默认游戏：27748 面 / 2048 节点 / 12+7 单位（与改前一致）；`--autotest` 通过。
- 数据自检 31 项、编辑器链路自检 9 项（含 Dock 是否在前台）全过。
- 实拍编辑器窗口：菜单/快捷条/层栏/示例地图（基地/兵营/金矿/区域圈）/地形页（纹理+高度+刷子）都在。
