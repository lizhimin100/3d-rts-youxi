## 地图编辑器四路攻坚 + 单位/自然物材质统一

### 1. 交互链路（根因：方法根本不存在）
- `编辑会话.gd` 里**从未实现** `set_tool` / `set_mode` / `set_category`，而 `停靠面板.gd`
  的所有工具按钮都在调它们 → 运行时 Invalid call，点按钮等于点石头。已补齐。
- 新增 `armed` 状态（手持工具 / 手型浏览），默认 **false**：
  - false：左键按住拖动 = 转视角；点中对象仍可选中/拖走
  - true：左键按 mode 干活（刷地形 / 放对象 / 画区域）
- `视口.gd` 新增 `_left_orbit` 区分左键轨道旋转与中键；H / Esc 收工具；右键空地收工具；
  手型下不画笔刷光标；新增 `reset_interaction_state()`（新建地图前清笔画/框选/多边形残留）。
- 主屏左侧栏顶部加「手型 浏览」按钮；rail 高亮 + 停靠面板工具高亮都跟 `armed` 联动
  （手型时全不点亮）。徽标文案统一走 `session.tool_hint()`。
- `set_mode/set_tool/set_category` 故意**不做"状态没变就提前返回"**：少发一次信号会让
  UI 高亮和真实状态对不上（踩过）。

### 2. 新建地图"闪一下就没"
- 根因：`主屏.gd._process` 每 0.4s 强推 `_wizard.visible = (session.def == null)`，
  已有地图时刚弹出的向导立刻被自己藏掉。
- 改为事件驱动：`_wizard_wanted` + `_wizard_dirty`，只在"点了新建 / 地图建好 / 没地图"
  三种事实下同步，不再每帧覆写。

### 3. 树像石头（真正根因：albedo 是灰度图）
- 拆 `树.glb` 的 glTF：材质结构完全正确（M_bark/M_leaf 分层、带 normal），
  但**所有 albedo 贴图三通道完全相等**（树叶 198,198,197 / 岩石 224,226,227 /
  草丛 198,198,197 逐像素同源），glTF 又没 baseColorFactor → 全部渲染成灰白。
- 结论：文生 3D 那批资产（树/草/岩石/金矿/木桩/尸骨）albedo 通道本身就废。
- 解法（引擎侧，不重烘贴图）：`代码/美术/自然材质.gd`（`自然材质库`）把灰度贴图降级成
  细节噪声，颜色从 `调色板` 取；材质名带 `自然_` 前缀，让 ArtKit 染色和 MatKit zone 都跳过。
- 叶色补偿从 1.28 下调到 1.06、背光减弱（原先叶尖过曝成黄块）。

### 4. 单位（老板点名"重中之重"）
- 单位走的是**另一条链路**：MatKit 卡通 shader + `M_<zone>` 调色板 zone + `_team` 注入阵营色。
  调色板 50 个 zone 齐全（skin/cloth/steel/leather/hair/crystal…），所以单位**本来就有颜色**，
  问题不在缺色。
- 真实问题：建筑与单位共用一档曝光（albedo_gain 0.94 / ao 0.55），单位是"深色军装 + 亮钢盔"，
  同一档压下去中间调全死 → 远看是**黑白剪影**（蓝披风 + 白盔 + 纯黑腿）。
- 分档修复（`材质库.gd`）：
  - 建筑/道具：GAIN_PROP 0.94 / AO_PROP 0.55 / RIM_PROP 0.10
  - 角色：GAIN_CHAR 1.12 / AO_CHAR 0.30 / RIM_CHAR 0.20
  - 角色再加 `emission = base_color × 0.16`（等价"补一点环境光"，只救暗部色相，
    不是自发光；crystal/ember/ore 保留原自发光）。建筑不加（大面积浅色会发灰发飘）。
  - `is_char` 必须进材质缓存 key，否则同一 steel zone 在建筑/单位上互相顶掉。
- `美术接口.apply_team_color` 传 is_char；`预览工厂` 对角色分流到 MatKit（默认阵营色），
  编辑器里不再是灰白人偶。

### 5. 杂牌军漏网之鱼：地表碎石/草丛
- `地表细节._add_boulders` 和 `_add_procedural` 走 `装饰库._batch_material`，
  那里把 albedo_color 抬到 **1.25 白** 绕开调色板 → 碎石/草丛算出近 0.9 近白，
  草地上出现一块块白斑，跟关卡里"自然_rock 冷灰"两种皮。
- 改为从 `MatKit.palette()` 取 grass/rock 基色，按"贴图 0.88 × 逐实例顶点色均值
  （草 0.97 / 石 0.72）"反解 albedo_color，最终色落回调色板原色。

### 6. 曲面数学（地形）
- 每格一张**双三次 Hermite 片** `S(u,v)=Bu·A·Bvᵀ`，节点切向
  `m_u=(h₊ₓ−h₋ₓ)/2`、`m_uv=(h₊₊−h₊₋−h₋₊+h₋₋)/4` → 跨格 C¹；边界 ghost 用线性外推。
- 法线解析求 `N=normalize(−∂S/∂x, 1, −∂S/∂z)`，不用 generate_normals；
  UV 世界参数化 `(x/size+0.5, z/size+0.5)`。
- 曲率驱动自适应细分（逐格实测弦高选 nu/nv∈{1,2,3,4,6}，邻格 2:1 平衡 + 红绿缝合）。
- **回归**：agent 初版 SURFACE_TOL=0.05 顶到 129643 面、建图 2.5s。已改 0.10
  （200m 图 72485 面）；并给 `build()` 加可选 `p_tol`，编辑器笔刷拖动中传 0.55 换帧率，
  松手再按 0.10 补精（`height_at` 走解析求值，不受网格精度影响，放置不会漂）。

### 地表色块（游戏里看不见的坑）
- 编辑器正常、游戏里看不出。排查：mesh 98304 顶点、顶点色 (0.31,0.35,0.15,0.93)、
  visible=true、材质正常 —— 全对。真因两个叠一起：
  1. 色带是"同色系深浅"，受光材质 + 3 档太阳光把深绿抬成中绿，和地形糊成一片；
  2. 偏移只有 0.06m，和地形曲面细分误差（0.0376m）+ 深度精度打架。
- 修：`shading_mode = UNSHADED` + 偏移 0.22m + 色带 4 档扩到 **5 档**（多一档枯草/沙斑，
  让色相也变）+ alpha 0.93 + 块尺寸 10 格 → 5.5 格、中块 3.9 → 2.2、对比 2.15 → 2.45。
- 诊断技巧：关掉 `vertex_color_use_as_albedo`、albedo 设洋红，地面立刻变洋红
  → 证明 mesh 在渲染，问题在顶点色/混合，不在节点。

### 小地图：边框为什么"根本看不见"
- 控件 `material` 是圆形裁剪 shader，**`_draw` 里画的一切都会被 discard** ——
  圆环画在 rad±2 处自然一起被裁掉，怎么加粗都没用。
- 修：新建内部类 `RingFrame extends Control` 作为**子控件**（不受父级 material 影响），
  由它画外黑边(7px) + 金环(3.5px) + 内阴影 + 四向刻度。
- `_map_rect()` 四周缩进 7px，地形不再顶到控件边缘，圆形裁剪不再切出"毛边"。

### 地图边缘"凹凸不平"
- 远景山脊关掉后，地图四周就是网格断口。新增 `RtsTerrain._build_skirt()`：
  沿四条边向下拉 `max(18, size*0.12)` 的垂直崖壁（顶点色从深到浅），
  边界从"被截断"变成"设计出来的断崖"。独立 mesh，不进 `triangle_count()`。

### 底栏：字跑出框 / 图标小 / 字号不一
- 命令卡按钮 **96×50 → 118×54**（118 = 图标24 + 间距6 + 四个中文字64 + 内边距20），
  图标 18 → 24，字号统一 `FS_BODY`（以前紧凑版 FS_SUB、宽版 FS_BODY，看着大小不一）。
- 命令卡宽 屏宽 44% → **48%**，6 个按钮排一行不折行。
- 选中卡：头像 84 → 100、血条 12 → 14、数值块 `EXPAND_FILL` 铺满整行、图标 16 → 22。

### 副官开关（替代开局提示）
- 删掉主场景那条 3.5s 的 notify，改在小地图正下方常驻按钮「副官 · 开/关」，
  绿/灰字区分状态，tooltip 说明，点击调 `Adjutant.set_enabled()`。
- 副官补回 `var enabled: bool`（重写时漏了，HUD `get("enabled")` 拿不到 → 一直显示"关"）。
- `bool(x)` 在 GDScript **不是构造器**，会报 `Nonexistent 'bool' constructor`；用 `x == true`。

### 队伍
- 队伍 SpinBox 本来就有（0~3），这次补上语义：tooltip 写明"同队=盟友"，
  并动态列出「当前盟友：玩家 2」/「没有盟友（各自为战）」。

## 00:40 · 地形观感 + 左侧菜单 + 计时器

### 地形色块："迷彩布" → "大块呼吸"
- 上一版 5.5/2.2/1.0 格 + 对比拉到 2.45 → 碎成迷彩，三角面折痕明显。
- 现在：**大块 12 格（≈15m）+ 中块 4.5 格 + 细粒只占 3%**，对比 **1.55~2.0**，
  `temperate` 五档色带压到 0.112~0.334（同一色系的深浅，不再一半黄一半墨绿）。
- 结论：色块尺度 ≈ 视距的 1/3 时最耐看；比这更小就是噪点，更大就成"光照渐变"。

### 地图边缘：压平 + 岩石色断崖
- `RtsTerrain._flatten_border(3)`：最外 3 圈按权重拉向四边平均高度 →
  `_build_skirt()` 的顶边是直线，不再跟着地形长出一圈狗牙。
- 裙边颜色从"近黑"改成岩石灰 `(0.19,0.17,0.15)~(0.345,0.316,0.272)`，
  断崖才看得出是"一道崖"，而不是一团影子。

### 左侧一列：小地图 / 副官 / 菜单
- 资源条末尾加**战斗计时**（`clock` 图标 + `MM:SS`，读 `Game.elapsed`）。
- 小地图下方竖排两个按钮：「副官 · 开/关」「菜单」。
- 菜单（PopupMenu，带 gear/team/surrender 图标）：设置 / 队伍 / 投降
  - 设置：主音量滑块 + 副官接管开关
  - 队伍：列出你/敌方/本图所有槽位的队伍
  - 投降：确认后 `Game.game_over.emit(false)`
- 新增 4 个 SVG：`clock / team / gear / surrender`（64×64，白色描边，走 `Spec.icon_tex`）。

### 图标"跑出胶囊"
- `Spec.icon()` 只设了 `custom_minimum_size`，HBox 一拉长 holder 就变宽，
  图标按 KEEP_ASPECT_CENTERED 缩到一侧 —— 这就是"图标跑到框外/贴角落"。
- 修：holder 加 `SHRINK_CENTER`（不参与拉伸），TextureRect 显式 offset 全 0。

### 两个"找不到"的坑
- 副官按钮偶发不显示：`_sync_adjutant()` 只在 `_build` 和 `_apply_layout` 时调，
  而副官节点比 HUD 晚建 → 第一次永远找不到、之后没机会重试。
  修：副官 `add_to_group("adjutant")` + HUD 用 `get_first_node_in_group`，
  并在 `_refresh_stats`（0.12s 定时）里做"补挂 + 可见性翻转时重摆版面"。
- 队伍动态盟友 tooltip 已按要求删除，只留一句静态说明。
