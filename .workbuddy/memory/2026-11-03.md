  15 条"达成"里 **5 条本波对目标 0 伤害**（unit_died 命中 ID 即达成，可能是别家补的）；
  `goal_damage` 字段已落盘，报告能分"本波参与/他方击杀"。
- **T15 循环（本轮唯一逻辑修复）**：`_switch_count` 进 bank 不清零 → T11b→tech→probe 后，

  要么在 `_model_call` 里按 args.size() 分派。测试脚本里 `profile([units])` 这种"入参本来就是数组"的除外。
