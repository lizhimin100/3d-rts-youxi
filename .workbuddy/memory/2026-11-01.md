- 踩坑记录（都写进 MEMORY 第 7 节了）：
  1. **tooltip 弹不出来的真因**是 `mouse_filter=IGNORE`，不是没绑；不是内容为空。

## 晚（二）：底栏第六版 —— 双形态 + 滑动动画 + 训练骨架

玩家三条新口径：①单选时头像贴命令卡、信息面板贴头像左边；②多选/建筑开训时头像滑回最左，

- 新增 `HUD._compact_bottom()` / `建筑面板.is_expanded()` 两种形态；`_place_smooth()` 绝对矩形 + 0.22s 补间。
- 中段 `content_height()` 与建筑面板都改成**常数 224**（防"行高反推内容高"的自激）。
- 队伍格改成 **容器自适应**（小最小尺寸 + EXPAND_FILL），彻底删掉"按高度反推格高"的算法 ——
  那套会把最小高顶回 VBox，第二排直接掉出底栏（audit 报 OUT-OF-SCREEN）。
- 坑：`Object.get_meta(key, null)` 的默认值传 null **仍会报 ERROR**（每帧一条），要传非 null 哨兵。
- 坑：`Control` 的 size 被容器/最小尺寸撑大后不会自己缩回来；`_place_smooth` 必须在"目标没变但
  几何漂移"时把它拉回，否则面板下沿掉出屏幕。
- 验收：界面 8/8、建造 23/23、科技 27/27、autotest 通过、1280/1600/1920 三档 UI_AUDIT issues=0。
