## 环境笔记（这几轮反复踩的）

  删目录比删一堆文件安全（按 1 个 target 计）。回收站工具在中文路径下偶发 `trash-failed`，
  且**部分文件可能已被移走** —— 想"精简目录"时别先 mv 再 rm -rf，容易两头空。
- Godot 编辑器在导入大批新资产时会 `Not Responding`，但**内存还在涨就是还在干活**，
  别急着杀；内存停滞 + CPU 零增长才是真卡死。
- 日志是 **GB18030** 编码，`grep` 中文会匹配不到；用数字/ASCII 词（如 `153`、`71466`）判断，
  或先 `iconv -f GB18030 -t UTF-8`。

## 战争迷雾 + 收尾提交（续做轮）

**战争迷雾实现**（`代码/战争迷雾.gd`，class_name `RtsFog`）：
- 观察方 = 玩家阵营 + 其盟友（同队即盟友）；按各单位 `def.sight_range` 点亮 96² visibility 网格；三态：可见 / 已探索 / 未探索。
- 地形贴合雾面：复用项目既有「albedo 贴图 + 透明 + UNSHADED + DEPTH_DRAW_DISABLED」做法，抬升 0.30m（高于地表层 0.22m）；每 tick 重绘一张 fog 贴图（约 6.7Hz），便宜。
- 表现三层：地形暗化遮罩 + 雾中敌方单位/建筑 `visible=false`、中立资源仅未探索才隐藏 + 小地图复用同一张 fog 贴图遮罩且敌方单位按可见性跳过。
- 接线：`主场景._setup_fog()`（`level.add_child(fog)` + `fog.setup(terrain, player_faction, world_size)`）；`小地图._draw()` 取 `get_tree().get_first_node_in_group("fog_system")` 盖遮罩。
- headless 验收（`--quit-after 900`）：退出码 0、无 SCRIPT ERROR；`FOG_DEBUG=1` 实测 初始可见 506 格、隐藏敌方单位 57 个。

**API 坑（已踩，记下来防回退）**：此 Godot 4.7 构建里 `SurfaceTool.add_uv` 与 `ArrayMesh.surface_set_array` **不存在**；雾面最终走 `ArrayMesh.add_surface_from_arrays` 直接给定 `ARRAY_TEX_UV` + 贴图驱动（构建时给 UV，运行时只 `ImageTexture.update`）。`AudioEffectLimiter` 真实属性是 `threshold_db`/`ceiling_db`（无 attack/release），上一轮遗留的运行时报错已修。

**① 编辑器打不开 = BGM 素材头坏了（真因，别再猜导入卡）**
- 用户放到根目录 `BGM/` 的四个 wav，`RIFF` 与 `data` 的长度字段都是 `0xFFFFFFFF`
  （ffmpeg 流式写未收尾）。Godot WAV 导入器据此 seek 越界，**刷 6 万行

- 修法：按真实长度重写两个长度字段（载荷逐字节不变），并并入 `音频/`：
  `bgm_和平_和` / `bgm_和平_森` / `bgm_战` / `bgm_舒缓`（各 40kHz 立体声，
  前三首 90s、舒缓 31s）。修完 `--import` 0 错误，编辑器正常起。
