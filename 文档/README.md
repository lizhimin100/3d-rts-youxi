## 3. 代码索引（给 agent 的地图）

`索引/文件索引.md` 由 `工具/生成文件索引.py` 生成，含：

- 171 个脚本 / 87,458 行的模块汇总；
- 每个文件的行数、`class_name`、`extends`、**首条注释（职责）**、preload 出/入、自检入口；
- 健康指标：最大的 10 个文件、缺头注释数、私有字段读取/动态调用计数。

用法：**先 grep 索引，再决定打开哪个文件**。不要一上来读 `简单AI.gd`（7531 行）。

重跑：

```powershell
python 工具/生成文件索引.py
```

## 4. 新 agent 的第一小时

1. 读本页（3 分钟）。
2. 读 `开发交接.md` 的 §0 一、§1、§2（10 分钟）——这三节能避免 90% 的返工。
3. 按任务在 §1 找到对应文档，只读那一篇（15 分钟）。
4. 用 `索引/文件索引.md` 定位 2–3 个文件，读函数头而不是全文（20 分钟）。
5. 改完按 `开发交接.md` §5 跑最小闸门；提交前看 `git status`。

**不要做的事**：通读 `简单AI.gd`；从 `主场景.gd` 的 QA 段开始读；相信注释里的常数（已有两处过期：`REPATH_INTERVAL` 注释写 0.8s 实际 0.25s；`建筑.gd` 头注释写研究 +15% 实际平铺 +1）。
