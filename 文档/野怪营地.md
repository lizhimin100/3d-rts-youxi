## 1. 目标（一句话）

地图编辑器里有一个"野怪营地"对象：**摆一个点 = 定义一处刷怪点**，
营地里刷哪几种野怪、各几只、多久刷一次**当场可配**，进游戏后按配置刷，
并且**在小地图上有一个固定图标**标出这个营地。

它和现在的区别：

| | 现在（2026-11-01 之后） | 目标 |
|---|---|---|
| 野怪从哪来 | 玩家在编辑器里**一只一只摆** | 玩家摆**营地**，营地按配置刷 |
| 配置 | 无 | 兵种 / 每波数量 / 刷新间隔 / 上限 |
| 小地图 | 只有零星红点 | 营地有**锚点图标**，一眼看到"哪有野怪" |
| 代码刷新 | **已整块删除**（玩家要求） | 按营地配置恢复，但**数据来自地图**，不是硬编码 |

## 2. 数据格式草案（`MapObject` 上加字段，不新建类）

营地在文件里就是一条普通对象，用 `type_id = "creep_camp"`：

```gdscript
# MapObject.properties（都是可选，缺省走下面的默认值）
{
    "creeps": [                       # 刷什么：id → 权重（权重不必是整数）
        {"id": "gnoll_warrior", "weight": 2},
        {"id": "gnoll_scout",   "weight": 1},
    ],
    "per_wave": 2,                    # 每波放几只
    "interval": 30.0,                 # 多少秒一波
    "cap": 6,                         # 这片营地最多同时存在几只
    "radius": 6.0,                    # 出生点散布半径（米）
    "minimap_icon": "creep_camp",     # 小地图图标 key（见 §4）
}
```

存盘走现有的 `MapObject` 序列化，**不需要新资源类型**；
`地图校验.gd` 里加一条：`creeps[].id` 必须是 `UnitDef` 里存在的 `UNIT`，
否则报"未知野怪 id"。

## 3. 需要动的地方（清单）

1. **单位表**：新增一条 `creep_camp` 的 `UnitDef`（`kind = BUILDING`、`max_hp = 0` 或不可选中，
   或者干脆让营地**不是 UnitDef**、只由 `MapLoader` 单独处理 —— 二选一，见 §5 的取舍）。
2. **编辑器**：
   * `资产目录.gd`：分类「单位」下加一条（或新开「野怪」分类）；
   * `停靠面板.gd`：选中营地时对象页多一块"营地配置"（兵种多选 + 三个数字框）；
   * `MapObject` 的 `properties` 直接存，不用改序列化。
3. **地图加载器**：`spawn_map_objects()` 里 `type_id == "creep_camp"` 时，
   不生成普通建筑，而是注册一个"营地"给 `野怪.gd`。
4. **野怪.gd**：恢复一份**由地图驱动**的刷怪循环（和这次删掉的那份不同：
   参数全部来自地图对象，不再有 `WANT_CAMPS` 这种硬编码）。
   `camp_positions()` / `camp_config()` 对外暴露给 AI 与小地图。
5. **小地图**：`小地图.gd` 画营地图标（固定像素大小，不随缩放变），
   战争迷雾下**只在已探明时显示**（和敌方建筑一致的口径）。
6. **AI**：`简单AI._nearest_creep_camp()` 改成读营地表，而不是扫 `neutral.units`。

## 5. 现在（本轮）的真实状态

**代码刷新野怪已经整块删除**，具体删掉的是：

- `WANT_CAMPS` / `_place_camps()` 最远点采样自动撒营地
- `SPAWN_INTERVAL` / `PER_CAMP_CAP` 定时补怪
- `NIGHT_WAVE` + `night_started` 钩子（入夜成批扑家）
- 地牢（`dungeon`）：`UnitDef`、`代码/美术/地牢外观.gd`、`combo:dungeon`、
  编辑器里的条目与中立例外、相关自检与文档

**现在野怪只有一个来源：玩家在地图编辑器里一只一只摆。**

摆的时候记得把「摆放归属」选成**中立**：`gnoll_warrior` / `gnoll_scout`
在 `MapAssets.NEUTRAL_OK` 白名单里，能保持 `owner = -1`；
进图后由 `地图加载器` + `野怪.gd` 落到中立阵营（打人、还手、上小地图、AI 认它是敌人）。

`代码/系统/野怪.gd` 现在只做两件事：建中立阵营、收编漏网的无阵营野怪。

## 6. 验收口径（将来实现时照这个验）

1. 编辑器摆一个营地 → 存盘 → Test Map → 进图后**按配置真的刷出对应兵种**；
2. 改 `per_wave` / `interval` → 刷怪节奏跟着变（不用改代码）；
3. 小地图上营地图标**位置正确**，且不随缩放漂移；
4. 删掉营地 → 那片地不再刷怪；
5. `--qa-terrain` / `地图编辑器自检` 全绿（营地不能破坏原有占位/归属判定）。
