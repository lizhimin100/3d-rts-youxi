# 动画规范（一个单位一套动作）

> 2026-11-07 建立。起因：玩家给 Agent 加过攻击动画，结果"步兵好像有好几种攻击"，
> 他要的是「攻击时只播那一个卡一刀的动作」。
> 这份文件管两件事：**动作名与语义**、**动作白名单**。改动画之前先读它。

---

## 1. 一条铁律：一个状态只对应一个 clip

| 状态 | clip | 播放方式 | 语义 |
|---|---|---|---|
| `idle` | `idle` | 循环 | 待机 |
| `move` → `walk` | `walk` | 循环，按地速变速 | 走路 |
| `attack` | `attack` | **单次** | 一次完整攻击：起手 → 命中 → 收势 |
| `shoot` | `shoot` (+ `reload`) | 单次 | 远程射击；有 `reload` 才播装填 |
| `cast` | `cast` | 单次 | 施法（只有带主动技能的单位才有） |
| `gather` | `gather` | 循环 | 挥斧/挥镐（农民专用） |
| `build` | `build` | 循环 | 抡锤（农民专用） |
| `hurt` | `hurt` | 单次 | 受击 |
| `death` | `death` | 单次，停最后一帧 | 死亡 |

**不许一个状态对应多套动作。** 如果确实要做"两种攻击"，
那是**两个技能**，由技能系统在时间轴上选择播哪一段（见 `文档/技能系统.md`），
不是在 `attack` 里塞一段连砍让引擎随机/循环播。

### 1.1 什么算"一次完整攻击"

- 长度 = `attack_cooldown` 的 40%~65%（步兵 0.9s / 冷却 1.75s = 51%），
  剩下的是站桩收势，让玩家看清"这一刀打完了"；
- 动作里**只能有一次向前的挥击**。可以在末尾带一点回位，但回位幅度必须小于 30%，
  否则连续播放时会读成"第二刀"；
- 首尾姿势不要做成"可无缝循环"的样子 —— 那正是"看起来在连砍"的根源。

### 1.2 已经踩过的坑

| 现象 | 根因 | 修法 |
|---|---|---|
| 无骨骼单位的攻击"快速砍两刀三刀" | `程序动画._做攻击()` 用 `fmod(t, 总)`，状态停在 ATTACK 就一直循环挥 | 钳到 `[0, 总]`，一次攻击一刀（2026-11-07 已修） |
| 步兵在某个角度不播攻击 | `UnitVisual.play` 去重把 `state == "attack"` 挡掉 | `_begin_swing` 用 `force=true`（已修，别改回去） |
| 兵"还有第二种待机" | 模型里带 `idle_b` / `idle_scratch` / `idle_stretch`，被降级链落到 | 白名单裁掉（见 §2） |
| 没有技能的兵会"挥手施法" | `cast` 降级链落到 `attack`，或者模型自带 `cast` | 白名单：没 `abilities` 就不给 `cast` |

## 2. 动作白名单（唯一入口）

`代码/单位/单位视觉.gd::_allowed_anims(def)` 按 UnitDef 推导允许集，
`代码/美术/骨骼动画.gd::set_allowed()` 在绑定时执行裁剪。

```
一定会用到： idle walk hurt death
能攻击（attack_damage>0 且 attack_range>0）： attack
有投射物（projectile != NONE）： shoot reload
有主动技能（abilities 非空）： cast
是农民（gather_rate>0）： gather build carry_gold carry_wood
```

不在集合里的 clip **一个都不播**，即使模型的降级链能落到它。
启动日志会打印一次：

```
[动画] 裁掉未使用动作：idle_b（允许：idle, walk, hurt, death, attack, shoot, reload）
```

### 2.1 当前被裁掉的动作

| 模型 | 被裁 | 原因 |
|---|---|---|
| `方块人_农民.glb` | `idle_scratch` `idle_stretch` | 从未被状态机调用 |
| `方块人_联盟步兵.glb` | `cast` | 步兵没有主动技能 |
| `方块人_弩兵.glb` | `idle_b` | 未使用的第二套待机 |

> 要"启用"某个动作，正确做法是**让它有语义**：
> 给兵加技能（→ `cast` 自动进白名单），或者给它加投射物（→ `shoot`），
> **不要**去改白名单常量硬塞。

## 3. 缺动作怎么降级（唯一的降级链）

`代码/美术/骨骼动画.gd::FALLBACK`：

| 想要 | 依次退回 |
|---|---|
| `walk` | walk → idle |
| `attack` | attack → shoot → cast → walk |
| `shoot` | shoot → attack → cast → idle |
| `cast` | cast → shoot → attack → idle |
| `gather` | gather → attack → build → walk |
| `build` | build → gather → attack → walk |
| `hurt` | hurt → idle |
| `death` | death → hurt → idle |

降级只在**白名单内**发生。白名单外的候选会被跳过，最终可能"什么都不播"（保持上一帧），
这是刻意的：**宁可不播，也不要播错**。

## 4. 换/加动作的流程

1. 在 Blender 里基于**同一个骨架**做（不要新骨架，否则所有 clip 都要重导）；
2. 动作名严格用 §1 表里的名字，全小写；变体用后缀（`attack_b`）但**默认不启用**；
3. 导出 GLB → 放进 `美术/模型/...` → 删除同名 `.import` 后重新 `--import`；
4. 确认白名单是否需要放行（见 §2）；
5. 截图验证：`-- --shot=... --qa-train=footman` 或直接开局看一遍攻击；
6. 帧序列离线验证（推荐）：
   ```powershell
   & 'E:/tmp/blender_ok/blender.exe' -b -P 工具/渲染动作帧.py -- `
       "美术/模型/方块人/方块人_联盟步兵.glb" "_qa/anim_footman" "attack" 24 90
   ```
   24 帧铺成格子图，**用眼睛数挥了几刀**。这是唯一能证明"只有一刀"的办法。

## 5. 时长参考

| 单位 | clip | 长度 | 攻击冷却 | 占比 |
|---|---|---:|---:|---:|
| 联盟步兵 | attack | 0.90s | 1.75s | 51% |
| 蒸汽重步兵 | attack | 0.83s | — | — |
| 农民 | attack | 1.57s | 3.0s | 52% |
| 弩兵 | shoot | 1.30s | — | — |
| 弩兵 | reload | 2.37s | — | — |
| 法师 | cast | 1.80s | — | — |

新增单位时，`attack` 长度控制在冷却的 40%~65%。超过 70% 会让"下一刀"接不上；
低于 35% 会看起来"点一下就完事"，没有打击感。
