# 动画规范（一个状态 = 一个动作；待机除外）

> 2026-11-07 重写（第二版）。**上一版写的"动作白名单"已经作废，代码里也没有了。**
>
> 玩家原话（这一版的口径）：
> 「你只需要修改步兵攻击动画，播放攻击动画只需要播放砍一刀的那一个攻击动画即可，
>  不需要整什么白名单黑名单。找到之前没损坏的 glb 文件，不要修改那里只导入。
>  步兵的待机可以随机多个不同动画，移动、攻击和举盾动画都只用一个。」
>
> 所以这一版只有三条规则：**一个状态一个 clip**、**待机可以随机**、**没有名单**。

---

## 1. 三条规则

### 1.1 一个状态 = 一个 clip

| 状态 | clip | 播放方式 | 语义 |
|---|---|---|---|
| 待机 | `idle*`（多个） | 循环，**随机挑一个** | 站着不动 |
| 移动 → `walk` | `walk` | 循环，按真实地速变速 | 走路 |
| 攻击 | `attack` | **单次**，播完回 idle | **一刀**：起手 → 命中 → 收势 |
| 射击 | `shoot` | 单次 | 远程；有 `reload` 才接装填 |
| 施法 | `cast` | 单次 | 只有带主动技能的单位才会用到 |
| 采集 | `gather` | 循环 | 挥斧/挥镐 |
| 建造 | `build` | 循环 | 抡锤 |
| 受击 | `hurt` | 单次 | 挨打 |
| 死亡 | `death` | 单次，停最后一帧 | 死亡 |
| 技能持续 | 技能卡上的 `anim_hold` | 循环 | 举盾 = `shield_hold` |

**不许一个状态播多套动作。** 要"两种攻击"就是两个技能，由技能卡在时间轴上选，
不是在 `attack` 里塞连砍让引擎随机播。

### 1.2 待机可以随机（唯一例外）

资产里所有以 `idle` 开头的 clip 会自动进"待机池"，每次进待机随机抽一个，且**不连续重复**
（`SkeletonAnim._pick_idle`）。步兵池 = `idle / idle_scratch / idle_stretch`。
只有 1 个待机时行为退化成"永远那一个"，和以前一模一样。

### 1.3 没有白名单 / 黑名单

- 播放器只做两件事：**名字映射**（move → walk）和**缺动作降级**（见 §3）；
- 除了 `ONE_SHOT`（attack/shoot/cast/hurt/death/reload）之外，**所有 clip 一律设成循环**；
- 于是 `gather` / `build` / `carry_*` / 新的技能持续动作**进资产就生效**，代码零改动；
- 以前那套 `_allowed_anims()` 白名单已经删除。**不要再加回来**：它的唯一效果是
  "新动作忘了登记就播不出来"，而它想解决的问题（一个状态播多套）由 §1.1 的命名约定解决。

## 2. 资产从哪来（这条比代码重要）

**只用没损坏的原始 GLB，不要在 Blender 里"手术"改动作数据。**

### 2.1 2026-11-07 的事故（别再犯）

`工具/加举盾动作.py` 走 Blender 的 ACTIONS 导出时，把除 `shield_hold` 以外的
所有动作的骨骼旋转曲线写成了**常量**。后果：引擎里 AnimationPlayer 在播、轨道一条不少，
肉眼却是"所有动画都没了"。这个脚本**已删除**。

要往已有模型里补动作，用 `工具/合并glb动作.py`：
它是**纯数据搬运**（不经 Blender，不改网格/骨骼/材质），并且自带体检；
跨 rig 借动作时可以 `--fill-rest` 补静止帧。

### 2.2 现在的步兵资产

`美术/模型/方块人/方块人_联盟步兵.glb` = **原版文件 + 纯数据追加的三个动作**。

2026-11-07 逐项比对过（原版 = 提交 `9e22ca4` 里那份 E 盘导出的新版方块人）：

| 项 | 结果 |
|---|---|
| nodes / skins / meshes / materials / images / textures | **完全一致**（30 / 1 / 3 / 3 / 1 / 1） |
| 原有 6 个动作的攻击曲线 | **JSON 全等**（attack / cast / death / hurt / idle / walk 一个字节都没动） |
| 新增动作 | `shield_hold` / `idle_scratch` / `idle_stretch`（只追加，不改旧数据） |

所以"模型本体被改坏"这种事在现行资产上不存在：**要动动作，只准用
`工具/合并glb动作.py` 做纯数据追加，而且追加完必须跑 §4.1 的体检。**

### 2.3 换资产的流程

1. GLB 放进 `美术/模型/...`，**删掉同名 `.import`**，跑 `--import`；
2. 跑 `python 工具/检查glb动作.py <glb>` —— **每个动作在动的骨骼数必须 > 0**；
3. 跑 `代码/测试/动画验收.gd`（§4）；
4. 拍一组近景截图（`--anim-shots`）人眼过一遍。

## 3. 缺动作怎么降级（唯一的降级链）

`代码/美术/骨骼动画.gd::FALLBACK`：

| 想要 | 依次退回 |
|---|---|
| `walk` | walk → idle |
| `attack` | attack → shoot → cast → walk |
| `shoot` | shoot → attack → cast → idle |
| `cast` | cast → shoot → attack → idle |
| `gather` | gather → attack → build → walk |
| `build` | build → gather → attack → walk |
| `hurt` | hurt → idle |
| `death` | death → hurt → idle |

降级只看**资产里有没有这个 clip**，没有名单参与。

## 4. 怎么验（三条路，缺一不可）

### 4.1 数据层：动作到底活没活

```powershell
python 工具/检查glb动作.py 美术/模型/方块人/方块人_联盟步兵.glb
```

输出每个动作"在动骨骼数"和最大摆角。**0 = 这个动作在引擎里等于没有**。
2026-11-07 那次事故，用这个工具 10 秒就能定位。

### 4.2 引擎层：骨骼真的在动吗

```powershell
$g = 'E:/编辑器/tools/godot/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64_console.exe'
& $g --headless --path . --script 代码/测试/动画验收.gd
```

5 组判据，结尾一行 `ANIMTEST {json}`：
A 资产齐不齐 / B 待机池 ≥2 / C move→walk、attack→attack、举盾→shield_hold /
D 走·攻·举盾三种状态骨骼位移 > 8mm / E attack 播完回 idle（不会自动再播一遍）。

> ⚠ 无头引擎不受帧率限制（~150fps），**别按"帧数 × 1/60"算时间**，
> 要用 `Time.get_ticks_msec()`。踩过：等 1 秒其实只等了 0.4 秒 → 假红。

### 4.3 眼睛层：一刀还是一顿乱砍

```powershell
# ① 单动作铺格子图（引擎内渲，吃的是真实的卡通材质与队伍色）
& $g --path . --resolution 900x600 --script 工具/动画帧图.gd -- --anim-sheet=_qa/sheet_attack.png:attack:10

# ② 实战近景：待机 / 走 / 攻击 / 举盾 各拍一张（产物落 _qa/动作/）
& $g --path . --resolution 900x700 -- --anim-shots
```

数刀数就看格子图：**从抬手到收势只许有一次向前挥击**。
实战图看腿有没有迈、盾有没有举到身前。

## 5. 时长参考

| 单位 | clip | 长度 | 攻击冷却 | 占比 |
|---|---|---:|---:|---:|
| 联盟步兵 | attack | 0.90s | 1.75s | 51% |
| 联盟步兵 | walk | 1.10s | — | — |
| 联盟步兵 | shield_hold | 0.58s | — | 循环 |
| 农民 | attack | 1.57s | 3.0s | 52% |
| 弩兵 | shoot | 1.30s | — | — |
| 弩兵 | reload | 2.37s | — | — |
| 法师 | cast | 1.80s | — | — |

`attack` 长度控制在冷却的 40%~65%。超过 70% 会让"下一刀"接不上；
低于 35% 会看起来"点一下就完事"，没有打击感。

## 6. 已经踩过的坑

| 现象 | 根因 | 修法 |
|---|---|---|
| **所有动画都没了**（模型在滑动/定格） | GLB 里的旋转曲线被写成常量 | `工具/检查glb动作.py` 一查就知道；用原始 GLB 重新导入 |
| 无骨骼单位的攻击"快速砍两刀三刀" | 程序动画 `_做攻击()` 用 `fmod(t, 总)` 循环挥 | 钳到 `[0, 总]`，一次攻击一刀 |
| 在某个角度不播攻击 | `UnitVisual.play` 去重把 `state=="attack"` 挡掉 | `_begin_swing` 用 `force=true`（**别改回去**） |
| 兵"还有第二种待机"却看不清 | 待机池里有多个，随机抽 | 这是**要的行为**（§1.2） |
| 没有技能的兵会"挥手施法" | `cast` 降级链落到 `attack`，或模型自带 `cast` | 降级链按 §3，`cast` 只给有 `cast` 的动作 |
| 举盾 0.5 秒自己放下 | glTF 导入的动作默认一次性 | `bind()` 里除 ONE_SHOT 全设 `LOOP_LINEAR` |
