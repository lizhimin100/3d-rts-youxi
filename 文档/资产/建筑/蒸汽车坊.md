## 尺寸与朝向

- 单位 1 unit = 1 m；原点在**占地中心**，z = 0 地面；建模期正面 +Y，导出 glTF 后 **−Z**。
- 含场地与吊装梁 **12.16 × 14.48 × 10.04**（烟囱顶是最高点）。
- **车间主体** 7.20 × 12.00；台基 0–1.06、压顶 1.06–1.20、墙 1.20–5.18、山墙 5.18–8.78。
- **屋面** 45° 双坡，脊 9.006（`roof` 石板瓦 + 队色脊压条）；两侧出檐 0.42、前后 0.22。
- **山墙** 7.20 宽 × 3.60 高；门洞 2.56 宽、起拱 2.95、拱顶 4.23（**真开洞**，洞内 1.3 m 门厅）。
- **锅炉房** 2.25 × 7.00，墙脚 0.56、外墙顶 3.37，单坡屋面 4.55 → 3.45。
- **锅炉** φ1.40，0.58 起、锅筒顶 5.38、汽笛 5.86，从披屋屋面穿出。
- **烟囱** 1.02 见方，顶 10.04。

## 屋顶（八座唯一的长坡山墙）

| 项 | 值 |
|---|---|
| 类型 | `long_gable_head`（长坡 + 正面三角山墙） |
| 坡度 | 45°（半跨 3.60 / 脊高 3.60） |
| 材质 | `roof`（深板岩，整片干净、**不铺瓦垄**）+ `team` 脊压条 |
| 附加 | 平嵌天窗 5 只（近坡 3 / 远坡 2）、椽头 22 只、脊端风向标、山墙百叶 + 木挑檐、山墙木构（横梁 / 四竖棂 / 上梁 / 中柱） |
| 顶部 | 山墙木构 + 金冠盾徽 + 垂旗 + 吊装梁（滑轮 / 铁链 / 吊钩） |

- **屋面不做瓦垄**：3 m 以上的坡面上铺亮脊会读成"金属条纹板"；铁匠铺的屋面同样是一片干净石板。
- **屋脊压条是俯视唯一的通长队色**：立面上的染色在 58° 俯角下被压扁，只有脊上的水平面兜得住。
- **山墙横梁按该高度的可用宽度重算**：6.34 高处三角形只有 4.55 宽 —— 5.10 宽的横梁会两头戳出屋面。

## 换阵营

只改两个材质：`team`（`#2E5FB4`）/ `team_trim`（`#F1CD79`）。

染色点位（5 条结构线）：

| 位置 | 做法 |
|---|---|
| 屋脊 | 0.34 宽 × 12.4 长的压条（整条队色） |
| 山墙 | 垂旗（1.02 × 2.10，金流苏）+ 金冠盾徽；门柱之间无染色 |
| 烟囱 | 两道箍（0.54 / 0.26 高） |
| 门 | 双扇全关；通长队色下板（2.50 × 0.30，压在门扇下沿）+ 通长铁箍两道 + 门闩 + 对称门环 |
| 檐口 | 压梁下 0.16 饰带 + 披屋檐口 0.05 压条 + 山墙封檐板 5 cm 细线 |

实测可见占比：**正视 7.34% / 3-4 视 4.99% / 俯视 4.17%**（规范 6–9%）。

## 已知

- **山墙三角形是"头"，长屋是"身"**：这座的识别度全在正面那块三角 + 45° 长坡，
  从正侧方看就是一大片屋面 —— 这是形体的必然，不是漏做（侧视图里只有 2 只天窗的窄边）。
- **锅炉半径被夹在 1.53 m 的净空里**（主檐封板 4.06 ↔ 披屋墙内表面 5.59），只能 φ1.40。
  想放大锅筒必须先把披屋外移，别只改半径。
- **吊装梁外挑 2.03 m**，是全场地的 +Y 边界（7.43）；远景（LOD2）只留梁与滑轮，
  链条会掉 —— 远景看不到链条，但梁不能掉，否则"车间"少一半叙事。
- **门厅内部是黑的**：1.3 m 深的门厅完全被关着的双扇挡住。这是有意的（v3 起门厅只留围合，
  不要为了"看得见"去点亮内壁。
