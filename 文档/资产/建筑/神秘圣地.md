## 尺寸与朝向

- 单位 1 unit = 1 m；原点在**占地中心**，z = 0 地面；建模期正面 +Y，导出 glTF 后 **−Z**。
- 含场地与四簇水晶 **13.70 × 14.17 × 16.18**（晶尖是最高点）。
- **三级十二边形台基**：apothem 5.30 / 4.80 / 4.32，压顶顶面 0.52 / 0.80 / 1.06。
- **圣所**：十二边形，外 apothem 3.66（对边距 7.32），墙厚 0.30，墙面 1.04–6.10；
  12 面墙板 + **10 根壁柱**（正面两角不放 —— 那里离门套只有 1 cm）。
- **山门**（实心门廊）：4.04 宽 × 2.16 深 × 4.38 高，从地面砌起；
  拱洞 1.90 宽、直边 3.10 / 拱顶 4.05；**隧道进深 1.44**，尽头是发光门板。
- 台阶 4 级（0.168 / 级，踏面 0.34，逐级加宽 4.10 → 4.82）。
- 山花 4.32 宽，檐口 4.56 / 顶 5.78；鼓室里的徽记 0.98。
- **鼓座**：十二边形 apothem 2.70，6.44–8.70；12 根亮柱 + **6 扇发光窗** + 队色箍。
- **穹顶**：七段环，8.96–12.62，最大 apothem 2.84（鼓形），**12 根 `roof_pale` 亮脊**。
- **采光亭**：8 柱 + 发光核，12.16–13.94；锥顶到 14.86，针到 15.28，晶尖到 **16.18**。

## 屋顶（六座唯一的穹顶）

| 项 | 值 |
|---|---|
| 类型 | `dome_ring`（鼓座 + 鼓形穹顶 + 环列水晶） |
| 穹顶 | 十二边形回转体，7 段环，母线 ap 2.72 → 2.84 → 2.80 → 2.58 → 2.16 → 1.52 → 0.76 → 0.28 |
| 材质 | `roof_edge`（近黑板岩）+ `roof_pale` 亮脊 ×12 |
| 附加 | 滴水圈（`stone_light`）、6 面队色徽牌、4 簇穹顶基部水晶 |
| 顶部 | 8 柱采光亭（发光核）+ 三折锥顶 + 金箍 + 金针 + 六棱晶尖 |

- **整组平着色**：十二边形相邻面夹角正好 30°，小于 `shade_auto` 的 32° ——
  走平滑会被磨成一个深色圆盘（农场筒仓踩过同一个坑）。
- **深板岩上只用亮脊**：1.5:1 的暗缝在 RTS 距离上糊成一片；`roof_pale` 亮脊 2.4:1 才读得出起伏。
- **穹顶不做全身球**：鼓形（先鼓到 2.84 再收）比半球更"东方/奇幻"，也和城镇大厅的
  八角尖顶拉开。七段环是"低模能接受的最低圆度"，再少就读成金字塔。

## 换阵营

只改两个材质：`team`（`#2E5FB4`）/ `team_trim`（`#F1CD79`）。

染色点位（**4 个高度带**，全部贴结构线；每一个开间一幅，读起来是"制服"不是"掉漆"）：

| 高度 | 位置 |
|---|---|
| 低 0.5–0.8 | **一级压顶顶面的一圈队色块**（12 块，俯视唯一的大面积横向染色）+ 二级台身队色箍 |
| 低 0.4–1.1 | 山门门楣队色檐壁（3.80 × 0.30，正立面最显眼的一块）+ 火盆柱箍 |
| 中 2.0–4.0 | **八个盲拱里各一幅燕尾还愿幡**（金杆 + 金端头 + 燕尾）+ 山门正面两幅垂旗 |
| 高 8.2–8.5 | 鼓座整圈队色箍 |
| 高 10.6–11.2 | 穹顶 **6 面队色徽牌**（金边菱形 + 中央晶点） |

实测可见占比：**正视 7.33% / 3-4 视 6.03% / 俯视 5.37%**（规范 6–9%）。
俯视那一档是这一座最难的 —— 立面染色在 58° 俯角下会被压扁，所以一级压顶面上
必须有一圈横向染色，否则俯视只剩 1.5%。

## 已知

- **台基顶面只剩 0.66 m 的露台**：墙外皮 3.66、三级压顶 4.32，中间被 12 根壁柱
  的基础（外伸到 4.10）占掉大半。所以天台两道同心环最后删掉了 —— 放不下，
  勉强塞进去只会读成一圈碎砖。
- **鼓座窗不能开太大**：鼓座只有 2.26 m 高，窗高 1.14 时上下各留 0.46 / 0.5，
  再高一点窗顶就会撞上队色箍（第一版就是这么撞的，箍从窗中间横穿过去）。
- **俯视角的染色必须画在水平面上**：立面上的队色箍在 58° 俯角下被压扁到 1/3，
  实测俯视只有 1.53%；把一圈色块压到一级压顶顶面之后才到 5.37%。
- **水晶的亮尖比例不能超过 1/4**：`crystal_pale` 的尖端一旦超过整根长度的 30%，
  远景读成"白尖铅笔"而不是"紫水晶"（第四版就这么翻的）。
- **门廊不做柱廊**：这一座的尺度（门廊 4 m 宽、3.5 m 高）上，两根独立圆柱会读成
  "细杆撑着平板"，侧视时檐部是悬空的。改成实心山门 + 1.44 m 深的拱洞之后，
  "进不去的地方"那种分量才出来，发光门也只露出一部分 —— 越看不全越神秘。
