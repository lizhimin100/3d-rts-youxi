# 农场 · 交付说明（v2）

> 第五座。六座屋顶类型里剩下的那一格是 **`mono_pitch`（单坡）** —— 农场做成
> "单坡谷仓 + 石砌仓塔 + 三条田垄"：谷仓前檐 5.40 / 后檐 7.40（21.8°），
> 正面是一堵 8.4 m 宽、带半木构骨架的墙 + 一扇 3.6 m 的双开大门；

> 谷仓大门从"一块深色板"改成**石砌门套 + 亮木门扇 + 石梁中段的队色匾**。
>

## 尺寸与朝向

- 单位 1 unit = 1 m；原点在**占地中心**，z = 0 地面；建模期正面 +Y，导出 glTF 后 **−Z**。
- 含场院、仓塔与围栏 **15.35 × 12.75 × 10.11**（塔顶飘带是最高点）。
- **横向展开**：高:宽 **0.66** —— 与哨塔（3.0 竖）和城镇大厅（1.4）完全不同的一组比例。
- 谷仓 8.40 × 5.00（前檐 5.40 / 后檐 7.40，单坡 21.8°）；石台 12.10 × 5.98，顶 0.62。
- **仓塔** φ3.16（阶梯**十二边形**），基座 0.10 → 1.50、筒身 1.50 → 6.98、
  石檐 6.98 → 7.22、木锥顶 7.22 → 9.22（**48°** 坡），旗到 10.11。
- 披屋 2.25 × 2.60（贴谷仓左墙，向外单坡 5.20 → 4.10）；田垄 3 条 × 0.95 宽 × 5.0 长。

## 已知

- **农场是"横向建筑"，剪影面积大、染色点少**：15.35 × 12.75 的投影比哨塔大 3 倍，
  同样的染色面积占比只有一半。v2 把"三道筒仓蓝箍"换成"塔的布带 + 门扇 + 窄腰带 +
  门柱箍 + 封条 + 水井横梁"六处，才把 3-4 视从 4.73% 拉到 6.02%。
- **单坡屋面的正面投影就是一整块**：正面看到的屋檐只有 1.2 m 高，但 3/4 视角是 5.0 × 8.4 的大面。
  所以屋面必须有"通风百叶 + 暗缝 + 旧瓦补丁 + 露明椽头"四件事，否则读作"一块斜板"。
- **仓塔整组必须 flat + 排除细分**：十二边形一被细分或平滑，立刻变回"现代筒仓"。
- 田垄的作物（麦 0.075 宽 / 白菜 0.34 / 南瓜 0.36）在 RTS 距离是 3–4 像素，
  靠"三色交替 + 垄头挡土石"读出节奏，不靠单株造型。
- **谷仓大门不带"半开"**：两扇各 1.77 宽，往院子一开就压到田垄和作物上。
  RTS 尺度上，关着但有石套 / 亮木 / 队色 / 徽记 / 踏跺的门，读得比开着的门清楚。
