# 铁誓军团 · 资产整合包 使用说明

一套可直接被 **Godot 4 编辑器** 导入的模型资产 + 地形纹理 + 地形图集生成工具箱。
本包不含 Blender 工程流水线，只交付**成品资产**与**重生成工具**，目标机不需要装 Blender。

---

## 0 · 目录结构

```
铁誓军团_资产包/
├─ 使用说明.md            ← 本文件
├─ 建筑/                  ← 9 座建筑（Godot 原生 .glb，可直接拖入）
│  ├─ 铁匠铺/ 兵营/ 城镇大厅/ 哨塔/ 箭塔/
│  │  农场/ 伐木场/ 神秘圣地/ 蒸汽车坊/
│  │  每座含：<名>.glb（主模型）、<名>_低模.glb、<名>_手游_近/中/远.glb（3档LOD）
│  │         <名>.blend（源文件）、说明.md（建模说明）、图集/（主体/ORM/自发光 PNG）
│  └─ 白模/              ← 9 座建筑的中性白模（见 §2）
├─ 地形/                  ← 地形纹理底材 + 图集（见 §3）
│  ├─ 草地.png / 泥土.png / 裂纹泥地.png   （512² 无缝底材）
│  ├─ 地形材质.blend
│  ├─ 材质/              ← 草泥 / 泥裂纹 / 草裂纹 三套图集（rgba图集 + 两张底材 + godot shader + report）
│  └─ 地块/              ← 8×8 m 干裂泥地 GLB 地块（可平铺）
└─ 地形生成工具箱/        ← 纯 Python 地形图集生成器（见 §4）
   ├─ terrain_gen.py / terrain_check.py
   ├─ 使用说明书.md（工具箱详细文档）
   ├─ 参数配置.json
   └─ 模板文件/（terrain_blend.gdshader、cell_lut 样例）
```

## 1 · 建筑模型导入 Godot 4

1. 把 `建筑/<名称>/` 整个文件夹拖进 Godot 项目资源管理器（FileSystem 面板）。
2. Godot 对 `.glb` 是**原生支持**：拖入后会自动生成 `<名>.glb.import` 与可实例化的 `<名>.tscn`，双击即可放进场景。
3. 每座建筑自带多档模型：
   - `<名>.glb` —— 高精度主模型
   - `<名>_低模.glb` —— 低模
   - `<名>_手游_近/中/远.glb` —— 手游三档 LOD，按相机距离切换
4. 贴图在 `图集/`：`主体.png`（albedo/色彩）、`ORM.png`（Occlusion+Roughness+Metallic 合图）、`自发光.png`（emissive）。
   若要在 Godot 还原材质，建 `StandardMaterial3D`，把三张图分别接到 Albedo / ORM / Emissive，参考各建筑 `说明.md`。
5. 换阵营色：原模型用纯色 PBR 材质（无贴图），阵营色集中在 `team` / `team_trim` 两色；在 Godot 里改这两个材质的 `albedo_color` 即可整体换肤。

## 2 · 白模怎么用

`建筑/白模/<名称>_白模.glb` 是每座建筑的**中性灰白模型**：所有材质被合并成 1 个
`baseColorFactor = [0.8,0.8,0.8]`、`metallic=0`、`roughness=1` 的 PBR 材质，几何与原模型完全一致。

用途：
- **换美术风格**：直接套自己的材质 / shader，不必先剥离原阵营色。
- **重拓扑 / 重贴图**：作为干净的拓扑参考。
- **快速占位**：不需要任何贴图就能进场景跑通布局。

> 生成方式可复现：本包的 `白模生成器.py`（纯标准库，无第三方依赖）解析 GLB、把材质引用重定向到单一白材质并剥离贴图，
> 不依赖 Blender。用法 `python 白模生成器.py <输入.glb> <输出_白模.glb>`，需要时对自己导出的新模型再跑一遍即可。

## 3 · 地形（底材 + 图集）在 Godot 的使用

- **底材**：`地形/草地.png`、`地形/泥土.png`、`地形/裂纹泥地.png` 是 512²、8bit RGB、无 alpha、sRGB、无缝（1 tile = 8 m）的平铺贴图，直接当 albedo 用。
- **双材质硬边过渡图集**：`地形/材质/<草泥|泥裂纹|草裂纹>/` 各含
  - `atlas_*_rgba.png` —— 一张遮罩图集（进引擎的主文件）
  - `atlas_*_rgb.png` / `atlas_*_n.png` / `atlas_*_h16.png` —— 各自平铺的底材 / 法线 / 高度
  - `godot/terrain_blend.gdshader` —— 配套 shader（由 `地形生成工具箱/模板文件/terrain_blend.gdshader` 生成，含 `cell_lut`）
  - `report.md` —— 验收数据
- **地块**：`地形/地块/裂纹泥地.glb`（+ `_低模.glb`）是 8×8 m 可平铺的几何地块，缝是真几何。

## 4 · 地形图集生成工具箱（重新生成 / 改参）

`地形生成工具箱/` 是一套**纯 Python**（numpy / opencv / pillow，不需要 Blender）的工具，
8 秒出一套图集，所有参数集中在 `参数配置.json`（脚本里没有写死的数值）。

```bash
pip install numpy opencv-python-headless pillow

python 地形生成工具箱/terrain_gen.py      # 出图集 + 高度 + 法线 + shader + LUT
python 地形生成工具箱/terrain_check.py    # 跑 a–f 六项验收，写 report.md
```

新增底材（岩石 / 雪地等）放到 `地形/`（与 `草地.png` 同级，需满足 512² 起、尺寸为 256 的整数倍、无缝）。
详细规格见 `地形生成工具箱/使用说明书.md`。

## 5 · 给「另一个 agent」的提示

- 想**换阵营色 / 换皮肤**：改建筑材质里的 `team`/`team_trim` 两色，或用 `建筑/白模/` 重新上材质。
- 想**改地形过渡**：调 `地形生成工具箱/参数配置.json`（gain / amp / band 等），重跑 `terrain_gen.py` 即可。
- 想**加新建筑 / 新底材**：建筑 `.blend` 源文件已附在 `建筑/<名称>/`，地形底材按 §3 规格放进 `地形/`。
- 本包刻意**未**包含 Blender 建模流水线与 Godot 阵营染色脚本，以保持轻量与可移植；如需可在原工程里取。
