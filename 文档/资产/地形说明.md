# 地形 · 地表底材（Albedo）

三份 512² 的无缝平铺贴图：**草地** / **泥土** / **裂纹泥地**。纯 Albedo —— 图里没有
烘焙光照、没有阴影、没有 AO，引擎里自己打光，这是"能二次打光"的前提。

另有 3D 地块 `地块/裂纹泥地.glb`（8×8 m，缝是几何做的），见 `地块/说明.md`。

## 交付物

| 文件 | 内容 |
|---|---|
| `草地.png` | 草地底材（暖黄绿 + 四叶草簇） |
| `泥土.png` | 泥地 / 土路底材（暖土色 + 极弱干裂纹） |
| `裂纹泥地.png` | 3D 地块专用：更细一档的干裂纹（胞元 ≈ 0.53 m），底色略亮 |
| `地形材质.blend` | 节点源：`terrain_grass` / `terrain_dirt` / `terrain_mud_cracked` |
| `地块/` | 8×8 m 的可平铺地块（GLB + blend + 说明） |
| `材质/草泥/` | 草↔泥的**双材质硬边过渡图集**（遮罩 / 有符号距离 / 高度 / 法线），见其 `report.md` |

## 规格

| 项 | 值 |
|---|---|
| 尺寸 / 格式 | 512 × 512，8bit **RGB**（无 alpha），sRGB |
| 建议平铺尺寸 | **8 m × 8 m**（512 px → 64 px/m） |
| 采样 | Linear（有渐变，不能用 Closest），mip 正常开 |
| 引擎材质 | roughness 0.95、metallic 0、specular 0 —— 地面不要反光 |
| 无缝 | 已验证，见下 |

平铺尺寸不是随便写的：6 m 时 40 m 视野里能看出格子节奏，8 m 才压住。
换尺寸只影响"一块贴图铺多大"，不影响无缝。

## 在画面里的位置

明度秩序（规则 C39）里地面是**最低一档**，两份底材都守这条：

| | 平均明度 | 与墙体关系 |
|---|---|---|
| 草地 | 0.528 | 比 `stone_light`(#9C968C, 0.59) 暗 11% |
| 泥土 | 0.397 | 比 `earth`(#7B654C) 略暗，贴近建筑底座边缘的踩实土 |
| 裂纹泥地 | 0.346 | 3D 地块的板面，灯光下会更亮 |
| 墙体（参考） | 0.55–0.59 | — |

色相都从建筑调色板借：草地 ← `moss` #51603B 提亮往黄偏；泥土 ← `earth` #7B654C。
所以地面和建筑是同一套色，不会出现"绿草地 + 暖石头"的色温打架。

## 引擎接入

- 直接当 Base Color 贴图，`UV1`，平铺 8 m；两张都用同一个材质模板，只换图。
- **不要**给 gloss / clearcoat / 环境反射：地面的价值在于"退到建筑后面"。
- 需要粗糙度差异时再单独出 ORM（本次按需求只交 Albedo）。

## 双材质过渡（`材质/草泥/`）

草与泥**不是**两张图叠一个软蒙版——软蒙版 = alpha 混合 = 交界处两种颜色互相污染，
mip 一开还会拉出灰边。这里做的是**硬边二选一**：一张 1024² 的遮罩图集告诉 shader
"这个像素是草还是泥"，两张底材各自照常平铺。

| 进引擎的 | 说明 |
|---|---|
| `atlas_草泥_rgba.png` | R=遮罩 0/255，G=有符号距离（128=边界，±24 cm），B=宽度抖动场，A=255 |
| `草地.png` / `泥土.png` | 原样不动，一个字都没改 |

16 格 = 四角材质（左上/右上/右下/左下，1=泥）的 16 种组合，一格 8 m、256 px。
`atlas_草泥_h16.png` / `_n.png` 是配套的高度与法线（交界有 8 mm 台阶），
`atlas_草泥_rgb.png` 只是派生的预览图，别进引擎。

**导入注意**：R/G/B 都是数据通道，Godot 里必须关掉 sRGB，否则距离场被 gamma 拉弯。

完整规格与验收数字见 `材质/草泥/report.md`；Godot 材质与 16 字节 LUT 在 `材质/草泥/godot/`。

## 重新生成

```bash
# 生成两张 PNG + 材质 blend（约 30 s）
"D:/360安全浏览器下载/blender.exe" -b --factory-startup --python blender/bs_v6/tr_tex.py

# 标定：把每层噪声渲成灰度，量出 p2/p98（改 Noise 参数后要重跑，再回填 NORM）
... --python blender/bs_v6/tr_tex.py -- calib

# 体检出图：3×3 平铺 / 2× 近景 / 128² 远景
... --python blender/bs_v6/tr_check.py

# 进场景验收：兵营站在草地/泥土/拼接上（复用 shotlib 的机位与布光）
... --python blender/bs_v6/tr_scene.py
```

双材质过渡图集是纯 numpy 管线，**不需要 Blender**（工具与参数见 `地形生成工具箱/`）：

```bash
python 地形生成工具箱/terrain_gen.py     # 约 8 s，出 25 个文件
python 地形生成工具箱/terrain_check.py   # 复算 a–f，重写 report.md
```

改配色：只动 `tr_tex.py` 顶部的 `GRASS` / `DIRT` 字典（或直接开 `.blend` 拖色标），
不用碰节点。改密度：`TUFT_CUT`（草簇）与 Voronoi 的 `scale`（裂纹）。
