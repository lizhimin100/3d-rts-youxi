## 1. 一条铁律：按钮由**表**生成，不在代码里散着写

```
addons/map_editor/按钮表.gd     ← 唯一的按钮定义（数据）
        ↓
addons/map_editor/主屏.gd       ← 只负责摆（`_build_quick_bar` / `_build_rail`）
        ↓
代码/界面/界面规格.gd::icon_button()  ← 唯一的按钮皮肤与尺寸
        ↓
美术/图标/<name>.svg            ← 图标资源（64×64，白色单色路径）
```

**加一个按钮** = 在 `按钮表.gd` 里加一行 + 在 `主屏._on_menu` 加一个 case。
不用碰布局、不用调像素。

---

## 2. 按钮表结构

### 2.1 顶部快捷条 `GROUPS`

```gdscript
{"name": "文件", "items": [
    {"id": 1, "text": "新建", "icon": "file_new", "tip": "新建地图（先选尺寸/人数/种子）"},
    …
]}
```

| 字段 | 说明 |
|---|---|
| `id` | **必须**和 `主屏.gd::_on_menu(id)` 的 case 对上 |
| `text` | 最多 **2~3 个字**。长了挪进 `tip` |
| `icon` | `美术/图标/<icon>.svg`；找不到会静默退回纯文字 |
| `tip` | tooltip，写"做什么 + 快捷键" |
| `kind` | 可选：`normal` / `primary` / `danger`（删除这类不可逆操作用 danger） |

组与组之间自动加分隔线。当前分组：文件 / 编辑 / 检查 / 数值 / 视角。

### 2.2 左侧层栏 `LAYERS`

```gdscript
{"layer": "unit", "text": "单位", "icon": "sword", "tip": "切到「对象·单位」：摆兵、野怪"}
```

`layer` 是**逻辑键**（terrain / unit / building / doodad / resource / region），
主屏用 `match` 把它映射到 `MODE_*` + `MapObject.Category`。
改文案/换图标不影响行为；改行为只动主屏那一个 `match`。

## 3. 按钮规范（和 `文档/UI风格.md` 同一套）

| 项 | 值 |
|---|---|
| 工具栏按钮高度 | **34**（`EditorTool` 变体） |
| 层栏按钮 | **84 × 46**（`EditorLayer` 变体） |
| Dock 小按钮 | **30**（`EditorSmall` 变体） |
| 图标尺寸 | 三档：**快捷条 20 / 层栏 24 / Dock 16**（= 按钮高 × 0.55） |
| 图标与文字间距 | 7px |
| 图标着色 | 统一暖白 `(0.80,0.76,0.66)`，hover / 选中转 `GOLD_HI`。**不用纯白**：十几个白图标并排＝一片噪点 |
| 按钮描边 | 金的 28%（`LINE_GOLD`），hover 哑金，选中**整块填金褐** `BG_CHECKED`（只换描边色看不出"我拿着哪个工具"） |
| 对齐 | **图标 + 文字一起靠左**（拉伸按钮必须 `alignment = LEFT`） |
| 纯图标按钮 | 正方形 `h × h`，必须有 tooltip |
| 危险操作 | `kind = "danger"`（红底），且文案里不出现"确定吗"这类二次确认 —— 靠 Ctrl+Z |

> ⚠️ 踩过的坑：`icon_alignment` 和 `alignment` 只设一个，会出现
> 「图标钉在最左、文字单独居中」的分家效果；两个都设 CENTER 会**图标压在文字上**。
> 正确做法：`icon_alignment = LEFT` + 拉伸按钮再设 `alignment = LEFT`。
>
> ⚠️ **更硬的坑（2026-11-07 实测）**：`GridContainer` 把按钮拉宽后，
> 即使两个 alignment 都钉成 LEFT，Button 仍会把文字排回中间。
> 所以「放置分类」那四颗按钮改成 **Button 里自己放 HBox（TextureRect + Label）**，
> 见 `停靠面板._mk_cat_button()`。以后凡是要"图标紧贴文字 + 拉伸"的按钮，照这个写。

## 4. 图标资源

`美术/图标/*.svg`，64×64，白色单色路径，`界面规格.icon_tex(name)` 取。

编辑器常用（2026-11-07 新增）：

| 名字 | 用途 |
|---|---|
| `file_new` `file_open` `file_save` `file_save_as` | 新建 / 打开 / 保存 / 另存 |
| `undo` `redo` `history` | 撤销 / 重做 / 历史 |
| `check` `play` `card` `help` | 校验 / 试玩 / 数值卡 / 帮助 |
| `view_top` `view_iso` `view_reset` | 俯视 / 斜视 / 复位 |
| `copy` `paste` `delete` | 复制 / 粘贴 / 删除 |
| `rotate_l` `rotate_r` `rotate_rand` | 旋转 |
| `scale_up` `scale_down` `scale_reset` | 缩放 |
| `hand` `terrain` `region` `doodad` `mine` | 层栏 |
| `grid` | 显示网格 |
| `axe` `pick` | 伐木 / 采矿（技能卡也用它） |

新增图标：放同名 SVG → `--import` → 表里填名字即可，代码零改动。

## 5. 使用逻辑（人类视角）

1. **顶部** = 全局动作（文件 / 编辑 / 校验 / 数值 / 视角）；
2. **左侧** = 我现在在改什么（层），点一下右侧面板就跟着切；
3. **右侧** = 这一层的属性与动作（摆放归属 / 对象列表 / 选中对象的复制旋转缩放）；
4. **手型**在最上面：不拿工具时左键只转视角 + 点选，拿了工具才改地图。
   这条是编辑器最容易误操作的地方，所以手型按钮**永远在最上面**。

## 8. 二轮重做（2026-11-07，图标 / 按钮 / 排版）

> 玩家口径：「图标/按钮/排版重做：按 UI风格.md 的深石板 + 金浮雕对齐游戏 HUD」。

### 8.1 尺寸与节奏

| 项 | 改前 | 改后 | 为什么 |
|---|---|---|---|
| 快捷条按钮高 | 40 | **34** | 40 高的格子里塞 14px 字 + 28px 图标，每格都"空得发虚" |
| 图标 | 一律 28 | **20 / 24 / 16** | 图标是识别锚点，不是主角；比例 0.55 是照 HUD 命令卡量的 |
| 组标题与按钮 | 4px | **3px** | 标题是"贴纸"，不是第二行内容 |
| 按钮圆角 | 4 | **3** | 和 HUD 的 5px 折中，深石板更适合硬一点的角 |
| 按钮描边 | 灰线 | **金的 28%** | 纯灰线在深底上像"没画完的框" |

### 8.2 「选中的工具」必须一眼看出来

改前：选中的层按钮只是描边变亮 —— 十几颗长得一样的盒子里根本找不到。
改后：**整块填金褐**（`BG_CHECKED`）+ 金边 + 金字 + 金图标。
这条是"方便人类操作"的核心：余光扫一眼就知道现在手里是什么。

### 8.3 图标全部重画（30 个，`美术/图标/*.svg`）

统一口径：64×64 画布、主体 8..56、描边 4.5、圆头圆角、单色白。

修掉的"撞脸 / 认不出"：

| 旧问题 | 现在 |
|---|---|
| `sword` 斜向剑在 20px 下像一支蘸水笔 | 改成**竖直剑**（尺度问题，不是画法问题） |
| `view_top` 和 `grid` 一模一样 | 俯视 = 一块板 + 由上方落下的箭头 |
| `history` 和 `view_reset` 都是"圈+指针" | history = 表盘 + 回拨断口；复位 = **准星** |
| `scale_up/down` 里画加减号，读成"放大文字" | 一律"框 + 对角箭头"，靠箭头指内/指外分 |
| `file_save_as` 的铅笔被裁掉半截 | 软盘缩到左上，铅笔整个压在右下角 |

⛔ 不要动这七个（游戏 HUD 在用，改了会连带改 HUD）：
`cancel` `eye` `flag` `gear` `house` `surrender` `team`；
技能卡用的 `axe` `pick` `fire` `shield` `bow` 也保持原样。

### 8.4 信息不重复（UI风格 R1）

- 页头右上角 = **文件身份**（文件名 + `●` 未保存点），长句提示改放 tooltip；
- 视口右下角 = 尺寸 + 对象数；状态栏 = 坐标 / 瞬时提示 / 校验结果；
- 视口底部那行长提示（中键/右键/滚轮/H/R）**自带深石板底板**，
  不再是一行白字压在绿地上。

### 8.5 Dock

- 归属药丸：`radius 12` 胶囊 → **方角 3**；选中不再刷一整块亮蓝，
  改成"本色压到 1/3 + 本色满亮描边 + 左侧 3px 竖条"；
- 放置分类：按钮里自己排 HBox（见 §3 的坑），计数紧跟名字；
- 没有渲图的单位/建筑，占位符号**压暗**（0.62/0.75 透明度），
  不让一排白剑盖过真正的渲图头像；
- 「全图 71 ｜ 已摆 22 ｜ 可选 7」压成短句并自动换行（原来会被 Dock 宽度裁掉尾字）。
