# UI 风格（唯一风格说明书）

> 2026-11-07 建立。**这份文件回答"为什么这样设计"，`文档/界面说明.md` 回答"现在长什么样"**。
> 两者冲突时，以本文档的**理念**为准，以界面说明的**像素**为准，并且必须回来改这一份。
>
> 只写已经生效、玩家点头过的东西。没有玩家点头的"我觉得更好看"，不许写进来。

---

## 0. 一句话理念

> **人类一眼能看懂、一只手能点到的，就是好的；需要解释、需要二次确认、需要在两个地方对照的，就是坏的。**

这条不是口号，它是所有具体规则的来源。判断一个新控件该不该存在，先问三句：

1. 玩家**不读文字**能不能知道它是干什么的？（不能 → 加图标，或删掉）
2. 这条信息在屏幕上**是不是已经出现过一次**？（出现过 → 删掉重复的那份）
3. 玩家要用它，需要**移动鼠标多远、点几下**？（超过"看一眼就点" → 重排）

## 1. 六条铁律

### R1 · 一条信息只许出现一次

同一个数据在屏幕上只留一个"主位置"，其他地方要么不显示，要么只做**不同粒度**的补充。

| 反例（被玩家否决） | 正例 |
|---|---|
| 铭牌写"训练中 · 8.4s"，队列第一格右下角又写"8.4s" | 秒数只写**铭牌尾巴**；队列格底部只留一根进度线 |
| 建造进度：标题行写"建造中 42% · 剩余 12s"，进度条再写一遍 | 百分比归**铭牌**，秒数归**进度条内部**（两者粒度不同，不算重复） |
| 中段面板写"护甲 4"，命令卡又写一遍"护甲 4" | 中段是信息栏，命令卡是操作栏；命令卡只在**没有中段**时兜底 |

**判据**：把其中一个删掉，玩家会不会困惑？不会 → 删掉。

### R2 · 一个实体只用一个图标

- 建造中不管里面有几个农民，**只显示一个**农民头像（玩家 2026-11-07：「只能有一个，不要多个农民」）；
- 多选同类部队，用"名字 ×N + 每格一个头像"表达数量，**不再叠一排小头像**；
- 队列里同一个兵种训练 5 个，就是 5 个**同尺寸**格子，不许"第一个小、后面大"。

### R3 · 数值写在它描述的东西上

进度条的秒数要**压在进度条里**（玩家 2026-11-07：「不要放在进度条右上角，还很小」）；
血条的血量要贴在血条附近；工地的剩余时间要浮在**那栋楼头顶**。
"挂在面板角落的小字"是最容易失焦的写法，一律不许。

### R4 · 图标优先，但图标必须"认得出"

- 能上图标就不写字：`取消` 用 ✕ 图标，`集结点` 用旗子，`驻守` 用盾；
- 图标只允许来自 `美术/图标/`（SVG 单色，白色路径，`modulate` 上色）；
- **单位/建筑一律用渲图**（`美术/图标/单位/<id>.png`、`美术/图标/建筑/<id>.png`），不用线描符号代替；
- 图标尺寸只用四档：`28`（行内小图标）/ `36`（命令卡内嵌）/ `46`（建造行头像、确认按钮）/ `64`（大按钮）；
- 图标带文字时，文字是"副标题"，不许比图标更抢眼。

### R5 · 只有两种形态，不许发明第三种

底栏：**紧凑**（单选，三块贴右）/ **展开**（多选或建筑在干活，头像滑到最左）。
面板：**空闲**（竖排三行数值）/ **干活**（进度条 + 队列）。

新增状态时，先问"它能不能落进这两条里的某一条"。落不进 → 说明这个信息应该换个地方，而不是加第三种版式。

### R6 · 空状态就是没有

没选中 → 整条底栏消失，不是"灰掉"、不是"显示一行提示"。
建筑没在干活 → 不显示队列区、不显示"0/5 研究"。
没有法力 → 不画蓝条。

## 2. 版式骨架

### 2.1 底栏三段（从左到右）

```
紧凑（单选一个单位 / 一个闲置建筑）
                        ┌──────────┬──────────────┬────────┐
                        │ 信息面板 │ 头像 + 双条  │ 命令卡 │
                        └──────────┴──────────────┴────────┘

展开（多选 / 建筑在训练·研究·建造）
┌──────────┬──────────────────────────────┬────────┐
│ 头像+双条│ 信息面板（一路贴到命令卡）   │ 命令卡 │
└──────────┴──────────────────────────────┴────────┘
```

- 底板是一整块石金浮雕（`浮雕底板.gd`），三段**同高同底**，不许各自铺一块；
- 紧凑形态下底板**从信息面板左缘起**，左边不留空石板；
- 唯一判据：`HUD._compact_bottom()`；唯一摆放出口：`HUD._apply_layout()`。

### 2.2 面板内部（自上而下）

| 行 | 高度 | 内容 |
|---|---|---|
| 铭牌 | 42 | 菱形 + 名字（34px）+ 右侧状态尾巴（"建造中 42%" / "训练中 · 8.4s"） |
| 金线 | 11 | 带菱形宝石的分隔线 |
| 主体 | 剩余 | 空闲 = 三行数值；干活 = 进度条 + 队列 |

主体**永远不许超出** `content_height()` 的常数（左卡 184 / 中段 224）。
超了就是内容塞多了，砍内容，不许加高。

### 2.3 建造中（2026-11-07 定稿，玩家手绘图）

```
◆ 兵营                                  建造中 42%
[农民头像]  [========== 剩余 34 秒 ==========]  [✕]
```

- 头像：**一个**，46px，最左，和进度条同高、垂直居中；
- 进度条：占满剩余宽度，26px 高，**秒数写在条里面**（白字 + 4px 黑描边，18px）；
- 取消：✕ 图标按钮，46px，最右，红色系描边，`tooltip` 说明"全额退款"；
- 点头像 = 选中工地里的**全部**农民（1 个就是单选）；世界点不到工地里的农民，这是唯一入口；
- 世界中的工地头顶：一块深底金边小牌，写 `N秒`，底边一条真实进度线；**只给自己的工地看**。

## 3. 组件库（照抄，不要重新发明）

| 组件 | 文件 | 用法 |
|---|---|---|
| 尺寸/字号/颜色令牌 | `代码/界面/界面规格.gd` | 所有尺寸只从这里取；字号只用六级 |
| 水平进度条 | `建筑面板.gd` 内嵌 `Bar` | `feed(ratio, color, caption)`；caption 就是条内文字 |
| 竖排三项数值 | `数值列.gd` | 34px 等宽数字，20% 金线分栏 |
| 队伍网格 | `选择网格.gd` | 单选 34px 铭牌；多选每页 16 格 |
| 命令格 | `命令卡.gd` | 4 列；`btn.name = "指令_<label>"`（自检按名字找） |
| 说明气泡 | `说明气泡.gd` + `词条.gd` | 文案全在词条，面板里不许现编 |
| 图标 | `界面规格.icon_tex / unit_icon / building_icon` | 找不到会 `push_warning`，方便发现漏配 |

### 3.1 按钮

- 主操作（训练/建造）：亮金描边 + 图标 + 名字；
- 危险操作（取消/投降）：红系描边，**必须同时有图标和 tooltip**；
- 不可用：整体降到 35% 亮度 + 保留图标轮廓，**不许换成另一套灰色皮肤**；
- 所有按钮 `focus_mode = NONE`（键盘焦点框在 RTS 里只会碍事）。

### 3.2 文案

- 数字带单位：`8.4s` 写成 `8.4 秒`；`42%` 保留百分号；
- 状态用"动词 + 进度"：`建造中 42%`、`训练中 · 8.4 秒`、`研究中`、`升级中 45%`；
- 一句话不超过 12 个汉字（铭牌尾巴的宽度极限）；
- 长句一律进 tooltip / 说明气泡，**不许挤进铭牌**。

## 4. 图标规范

### 4.1 来源（只认这三处）

| 类型 | 路径 | 谁生成 |
|---|---|---|
| 通用符号（盾/剑/旗/✕/时钟…） | `美术/图标/<name>.svg` | 手写 SVG，白色单色路径 |
| 单位头像 | `美术/图标/单位/<id>.png` | `工具/渲染单位图标.py` |
| 建筑头像 | `美术/图标/建筑/<id>.png` | `工具/渲染建筑图标.py` |

新增一个符号图标：在 `美术/图标/` 放同名 SVG，`界面规格.icon_tex("名字")` 直接可用，
**不要**在面板里临时拼字符或画方框。

### 4.2 尺寸与着色

- 尺寸只用 28 / 36 / 46 / 64；
- 单色 SVG 用 `modulate` 上色：正文 `text_main()`、强调 `accent()`、危险暖红；
- 单位/建筑渲图**不染色**（它们自带材质颜色），只允许整体降透明度表示禁用。

### 4.3 现有符号表

`attack_move bow cancel clock coin eye fire flag gear hammer heart house mana move
pop return shield staff stop surrender sword team tower upgrade wood anvil`

新增技能时优先复用：举盾 = `shield`，连射 = `bow`，装填 = `clock`。

## 6. 被否决的版本（别做回去）

| 版本 | 玩家原话 | 现在的做法 |
|---|---|---|
| 建造行一排 4 个 34px 小头像，挂在进度条右上 | 「只能有一个，不要多个农民」「不要放在进度条右上角，还很小」 | 一个 46px 头像在最左 |
| 建造进度只有一条没字的条，秒数在铭牌尾巴 | 「上面有显示多少多少秒」 | 秒数压在条里 + 工地头顶小牌 |
| 5 列命令卡 | 「平平无奇、还很挤」 | 4 列，单格 142px |
| 底栏一直铺满全屏 | 「左边就不要再有多余的空白面板」 | 紧凑形态底板跟随中段 |
| 每个多选单位各画一个射程圈 | 「似乎有两个圆圈」 | 只在单选时画 |
| 中间一大块"战场概览" | 「没选中不要大板」 | 空选中 → 整条底栏消失 |
