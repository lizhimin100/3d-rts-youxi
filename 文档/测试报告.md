## 五、边缘滚动（`代码/测试/边缘滚动自检.gd`，真实窗口 + 真实鼠标）

```
四向：上 11.648m / 下 11.534m / 右 11.650m / 左 11.533m   → 全部通过
```

**修复记录**（用户点名"推边缘不动"）：
1. 原实现要求"鼠标动过才允许滚动" → 玩家把光标顶在边缘不动就永远不滚。改为"鼠标在窗口内即可"。
2. 原实现要求"鼠标坐标必须落在窗口内" → 但窗口模式下 OS **不锁光标**，推到边缘时光标会跑到窗口外，
   `get_mouse_position()` 给负数，直接被判定为"不在窗口内"而不滚。改为"落在边缘带**或窗口外**都按方向滚"。
3. 判定区从 10px 加宽到 **22px**（实测光标常卡在 1877/1920 打不进去）。
4. `_mouse_over_ui()` 收紧为"只有 MOUSE_FILTER_STOP 且非满屏容器"才算挡住镜头。
