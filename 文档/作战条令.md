## 0. 一句话目标

Godot 4.7 工程里，按 F5 就能玩：类魔兽争霸3的 3D RTS，单人对战简单 AI，摧毁敌人大本营获胜、可重开。
美术**全部**由 Blender 程序化生成（GLB），三渲二卡通渲染（着色器写在 `.gdshader` 文件里）。

## 1. 坐标、单位、比例（所有建模必须遵守）

| 项目 | 约定 |
|---|---|
| 世界单位 | 1 Godot 单位 = 1 米 |
| 上方向 | +Y（Godot 标准） |
| **角色朝向** | **-Z**（Godot 的"前方"）。**Blender 里必须朝 +Y**：glTF 导出做 (x,y,z)→(x,z,-y)，实测 Blender (0,-0.22,1.72) → Godot (0,1.72,+0.22)，即 **Blender -Y = Godot +Z（屁股朝前）**，Blender +Y = Godot -Z。已用探针验证，别信直觉 |
| 原点位置 | **脚底 / 建筑地面 = 原点 (0,0,0)**，即模型最低点贴在 y=0 |
| 角色身高 | 农民 1.62m / 步兵 1.78m / 弓箭手 1.72m / 法师 1.80m |
| 建筑尺寸 | 大本营 8×8×9m，兵营 6×5.5×4.6m，铁匠铺 5.5×5×4.2m，农场 4×4×2.6m，箭塔 3×3×8m |
| 树 | 4.5~6.5m 高，树冠直径 3~4m |
| 金矿 | 4×3.5×3.2m |
| 岩石 | 1.2~2.6m |
| 朝向一致性 | 全部模型**正面朝 -Z**；建筑正门朝 -Z。禁止出现歪脖子/背对/侧对 |

**法线/着色**：全部**平面着色（flat shading）**，低多边形硬朗块面感，不要 smooth shading 的塑料光滑感。
**面数预算**：角色 3000–9000 三角面；建筑 4000–20000；树 800–3000。**面数不是限制，形体质量才是。**

## 7. 操作与镜头（HAWKEYE 实现）

- **镜头**：`RtsCamera extends Node3D`，子 Camera3D。
  - 屏幕边缘（可配阈值像素）滚动，**带加速度与阻尼**，绝不瞬移；插值用 `lerp` + `move_toward`。
  - 俯视角固定 50°（可配），可 Q/E 旋转 45°，滚轮缩放 14–34m，受地图边界约束。
  - `func focus_on(pos: Vector3) -> void`（小地图点击用，平滑飞过去）
  - `func shake(strength: float, duration := 0.35) -> void`
- **选择**：`SelectionSystem` 管理 `selected: Array`；左键单选（射线-胶囊相交，不用物理引擎）、左键拖框多选（屏幕矩形投影）、Shift 加选、双击同类型全选。
  - 选中圈：实例化 `美术/特效/选中圈.tscn`（ANVIL 提供，带 `.gdshader` 脉冲），贴地。
- **指令**：右键上下文——点敌方=攻击；点自己农民可采的资源=采集；点空地=移动（编队偏移）；点自己建筑=农民送资源/建筑集结点。
- **快捷键**：A 攻击移动、X 停止、H 保持、B 建造菜单、Q/W/E 技能、方向键/边缘滚动镜头、鼠标中键拖拽旋转、滚轮缩放。

### 9.2 部件层级契约（**动画系统靠它**）

> **v3 起（2026-10-18）以 `美术规范.md` 末尾的“v3 资产契约”为准。**
> v3 角色是**真骨骼**：`Armature/Skeleton3D + AnimationPlayer`，27 根骨（root / hips / spine / chest / neck / head，
> shoulder/upperarm/forearm/hand ×2，thigh/shin/foot/toe ×2，cape.01..03，skirt.F/B）。
> 下面这套 `Root→Body→Torso→…` 的 18 空节点契约是 **v2 无骨骼资产**的遗留，只用于旧资产兜底；
> 新资产不要按它验收（会误判“缺 Weapon/Shield 空节点”）。
>
> 同一轮还修掉了两个致命的骨架高度错误（源码在 `工具/建模/v3/kit3.py`，别再改回去）：
> 1. `bone_list()` 的 root~head 原来用比例系数（0.535/0.62/0.70/0.812/0.862/0.985）而非乘 H，
>    H=1.78 时头骨在 0.862m、头网格在 1.5m；death 大角度旋转会“头飞出去”。现已改为
>    hips=hip_z / spine=waist_z / chest=chest_z / neck=sh_z / head=neck_z→head_top。
> 2. `aim()` 原来用 `ref × d` 现搭基，roll 与 Blender rest 差 180°，脚掌会翻面、像倒着跑。
>    现已改为 rest 方向 → 目标方向的最小旋转；腿改用 `pose_rot()` 的关节链局部旋转。
>
> 旧 v2 层级（仅供理解旧资产）：
角色 GLB 必须导出为如下节点层级（名字逐字一致，Empty/父级也可带网格）：
```
Root
└ Body                     （髋部，位于 y≈腿长处）
  ├ Torso                 （躯干）
  │ ├ Head                （头；含头发/头盔/脸）
  │ ├ ArmL                （左上臂，枢轴在肩关节）
  │ │ └ ForearmL          （前臂，枢轴在肘）
  │ │   └ HandL
  │ ├ ArmR
  │ │ └ ForearmR
  │ │   └ HandR
  │ │     └ Weapon        （武器：剑/弓/杖/镐）
  │ └ Shield              （盾，挂在 Torso，仅步兵）
  ├ LegL
  │ └ ShinL
  │   └ FootL
  └ LegR
    └ ShinR
      └ FootR
```
建筑：单节点 `Root` + 若干子网格（可带 `Banner`、`Smoke` 之类的空节点给特效挂点）。
**枢轴必须在关节上**（肩膀/肘/髋/膝），否则动画会像断了骨头。

## 10. 代码规范（硬性，评审会查）

1. 全部 GDScript，**静态类型标注**尽量写全（`var x: int = 0`、函数参数/返回值）。
2. **每个脚本开头用中文注释说明它是干啥的**；每个公开函数上方一行中文注释。
3. Godot 4 写法：`@onready`、`@export`、`await`、`call_deferred`、`Tween`、`get_tree().create_timer()`。
   **禁止** Godot 3 写法（`yield`、`Spatial`、`KinematicBody`、`instance()`、`OS.window_size`、`Directory.new()`）。
4. 不用物理引擎做单位和拾取（用数学），避免不确定性与抖动。
5. 不写 `.tscn` 依赖？——允许，但**手写 .tscn 必须能被 Godot 打开**；UI 一律代码构建。
6. 每帧只做必要的事；单位更新用数组遍历 + 时间片（AI 0.5s 一次思考）。
7. 任何可能为空的对象都要判空；任何索引访问都要判越界。
8. 不许 `print` 刷屏（调试用 `print` 前缀 `[模块名]`，正式路径不留每帧 print）。
