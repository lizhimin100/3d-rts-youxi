# 技能系统（组件化）

> 2026-11-07 重写。玩家的两条硬要求决定了这份设计：
> 1. **技能不要和单位绑死** —— 编辑器里能单独拎出来挂到任意单位；
> 2. **动作 / 特效 / 效果三者分开** —— 缺哪个就用占位，后续玩家能自己补。

---

## 1. 四层结构

```
代码/配置/卡/技能/<id>.tres     ← ① 数据（SkillCard）：唯一真相源，编辑器可改可加
        ↓
代码/配置/技能表.gd             ← ② 读入口：启动扫目录，转成 Dictionary（调用点零改动）
        ↓
代码/系统/技能运行时.gd         ← ③ 运行时：开关状态、修正倍率、连发、装填
   ├── 代码/系统/技能特效.gd    ← ④a 表现·特效（id → 冒一个东西；缺了退占位）
   └── 单位视觉 / SkeletonAnim  ← ④b 表现·动作（anim_on / anim_hold / anim_off）
```

**"效果"是纯数据**：开关技能的减伤/减速/攻速全部写在 `.tres` 的 `mods` 里，
`技能运行时` 不认识任何具体技能 id，只认 stat 名。

---

## 2. 技能卡字段（`代码/配置/技能卡.gd`）

| 组 | 字段 | 说明 |
|---|---|---|
| 身份 | `id` `display_name` `icon` `note` | `icon` 取 `界面规格.icon_tex` 的键 |
| 施放 | `kind` `target` `cast` `cooldown` `range` `slots` `hotkey` | `kind`：主动 / 开关 / 被动 / 采集 |
| 效果 | `mods` | 开关类：`[{stat, mul, when?}]`，同名连乘 |
| 效果 | `burst_shots` `burst_interval` `reload` | 连发 + 装填 |
| 动作 | `anim_on` `anim_hold` `anim_off` | 留空 = 不播（保持原动作） |
| 特效 | `vfx_on` `vfx_off` | 留空 = 不冒；未注册 id 退占位微光 |

### 2.1 支持的 stat（`技能表.stat_list()`）

| stat | 作用 | 例子 |
|---|---|---|
| `damage_taken` | 受到伤害倍率（`when` 限定伤害类型） | 举盾：`0.85`；穿刺：`0.65` |
| `damage_dealt` | 造成伤害倍率 | 狂暴 |
| `move_speed` | 移速倍率 | 举盾：`0.55` |
| `attack_cooldown` | 攻击间隔倍率（2.0 = 攻速 -50%） | 举盾：`2.0` |
| `attack_range` | 射程倍率 | 长弓 |
| `armor` | 护甲加法（`add` 字段） | 铁甲 |

**连乘规则**：两个 -15% 叠起来是 ×0.7225，不是 ×0.70。
这样不会减到负数，也和叠加顺序无关。

## 3. 现有技能

| id | 名字 | 类型 | 效果 |
|---|---|---|---|
| `shield_up` | 举盾 | 开关 | 受伤 -15%；受穿刺再 -35%；移速 -45%；攻速 -50% |
| `triple_shot` | 三连发 | 被动 | 一次攻击 3 发（间隔 0.12s），打完装填 2s |
| `fireball` | 火球术 | 主动 | 落点 3.5m 内 55 伤害 + 减速 40%（2.5s） |
| `chop_wood` | 伐木 | 采集 | 4 挥装满一背，树晃 |
| `mine_gold` | 采矿 | 采集 | 走进矿洞，3 载位 |

### 3.1 举盾（步兵）

```
点「举盾」(Q) → 0.2s 前摇 → 切换
  开启：damage_taken ×0.85，穿刺再 ×0.65，move_speed ×0.55，attack_cooldown ×2.0
        **姿态层**把左臂按在 shield_hold 的末帧姿势上（盾一直举在身前）；
        基础动作照常播 → 举着盾走、举着盾砍
  关闭：全部复原，0.18s 淡出姿态层，播 shield_down（模型没有就跳过）
```

> ★ 2026-11-08 改：以前是把 shield_hold 当循环动作播，结果是"每 0.58 秒抬一次手"，
>   而且移动/攻击时完全没有举盾的样子。现在见 `文档/动画规范.md` §1.4 的**姿态层**。

### 3.2 三连发（弩兵）

```
一次攻击 → 立刻排 3 发 → 每 0.12s 打一发 → 打完后 reload_t = 2.0
reload_t > 0 或还有没打完的连发 → can_fire() = false → 不开新一轮攻击
```

伤害按"每发各自结算"（3 发 = 3 次 `resolve_from_snapshot`），所以护甲/克制都正常生效。

**它也有按钮**（玩家 2026-11-07：「弩兵三连发被动也是要有按钮」）：
命令卡上给被动技能留一格，图标 + 名字 + 副行「被动生效」，点了不执行任何指令、
也不给快捷键角标，悬停能看说明。`命令卡._get_page_entries` 不再 `continue` 掉被动。

### 3.3 技能图标

| 项 | 位置 / 做法 |
|---|---|
| 资源 | `美术/图标/技能/<id>.png`（256²，暖底 + 暗角 + 深色描边） |
| 生成 | `工具/渲染技能图标.gd`（引擎内搭体素道具渲透明底原图）→ `工具/合成技能图标.py`（贴底版） |
| 底版 | 和单位头像**同一张**（从 `美术/图标/单位/peasant.png` 反解，缓存 `_qa/图标底版.png`） |
| 引用 | 技能卡 `icon` 填 `技能/<id>`；命令卡按 34px 渲图显示、保持原色 |
| 加新技能 | 在 `工具/渲染技能图标.gd` 的 `_ids` 加 id + 写一个 `_prop_xxx`，跑两条命令即可 |

## 4. 加一个技能（不用改代码）

1. 复制 `代码/配置/卡/技能/shield_up.tres` 改 id / 名字 / mods；
2. 把 id 加进 `代码/配置/卡/单位/<兵>.tres` 的 `skills` 数组；
3. 跑 `配置回归` + `技能自检`。

**只有当技能要"造成真实伤害/位移/召唤"时**才需要去 `代码/系统/技能.gd::release()`
加一个 case —— 因为那种效果没法用数值表达。

### 4.1 缺动作 / 缺特效怎么办

| 缺什么 | 表现 | 怎么补 |
|---|---|---|
| 动作 | 不播（保持 idle/walk），技能照样生效 | Blender 按 `文档/动画规范.md` 加 clip，名字填进 `anim_*` |
| 特效 | 退到"占位微光"（胸口一点淡白），并只警告一次 | 在 `技能特效.gd` 的 `match` 加一行 |

**占位是刻意的**：先让机制跑通，表现后补。补的时候不用动技能卡。

## 5. 编辑器接口（给后续"技能编辑器"）

`技能表.schema()` 返回字段清单（名字 / 类型 / 中文说明 / 默认值），
`技能表.stat_list()` 返回可用 stat，`技能表.all()` 返回全部定义。

技能编辑器只要：
1. 按 `schema()` 生成表单；
2. 读写 `SkillCard` 资源（`代码/配置/卡/技能/*.tres`）；
3. 保存后调 `技能表` 重新扫目录（或重启）。

单位卡上的 `skills` 是 `Array[StringName]`，把技能 id 拖进去即可 —— **这就是"挂到任意单位"的入口**。

## 6. 实现要点（改之前必须知道）

1. **开关技能不进 `Pending.CAST`**：`指令系统.request_ability` 看到 `target = 无` 就立刻施放，
   否则玩家点一下举盾，界面一直提示"左键选择技能目标点"。
2. **`first_ability()` 只返回主动技能**：开关/被动/采集都不参与"自动施法"，
   否则步兵会对着敌人自动举盾。
3. **`cooldown_of` 优先读技能卡**：举盾冷却 0.4s（防连点），
   若读单位卡的 `ability_cooldown`（8s）会点一次等 8 秒。
4. **技能动作用名字直接取，没有名单**：`anim_on/hold/off` 填什么就播什么，
   资产里没有就降级（见 `文档/动画规范.md`）。**唯一的坑是循环**：
   glTF 导入的动作默认一次性，不设 `LOOP_LINEAR` 的话盾举 0.4s 就自己放下 ——
   `SkeletonAnim.bind()` 里"除 ONE_SHOT 之外全循环"那条已经把它盖住了，
   所以 `anim_hold` 填一个 `shield_hold` 就直接循环，不用额外登记。
5. **`skills_rt` 只在有技能时创建**：绝大多数单位是 null，所有查询都走"null → 1.0"的快路径。
