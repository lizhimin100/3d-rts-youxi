# 技能系统（雏形）

> 2026-11-07 建立。起因：玩家要求「采矿/采木做成技能」，并给未来的技能系统搭雏形。
> 现在一共三个技能：`fireball`（法师主动）、`chop_wood`（伐木）、`mine_gold`（采矿）。

## 1. 三层结构

```
代码/配置/技能表.gd      ← 数值与元数据（唯一真相源）
        ↓
代码/系统/技能.gd        ← 执行：起手 begin_cast / 出手 release / 查询
        ↓
单位状态机（单位.gd）    ← 主动技能走 State.CAST；采集技能走 GatherPhase
        ↓
单位视觉（SkeletonAnim） ← cast / gather / shoot / reload 动作
```

**加一个主动技能只需要改两处**：
1. `技能表.gd` 的 `DEFS` 加一条（id / 名称 / 目标 / 前摇 / 冷却 / 射程 / 图标）；
2. `技能.gd` 的 `release()` 加一个 `match` 分支（真正打出去的效果）。

`has()` / `cast_time()` / `unit_has()` 都是表驱动，不用再改。

## 2. 字段

| 字段 | 说明 |
|---|---|
| `id` | `StringName` 唯一 id |
| `name` | 中文名 |
| `kind` | `主动` / `采集` / `被动` |
| `target` | `无` / `点` / `单位` / `资源` |
| `cast` | 前摇秒数（0 = 瞬发） |
| `cooldown` | 冷却秒数；主动技能实际冷却读 `UnitDef.ability_cooldown` |
| `range` | 施放距离（**身位边缘口径**，见 `文档/战斗射程口径.md`） |
| `icon` | 图标 id（`界面规格.icon` 的键） |
| `slots` | 采集类专用：这个资源点能站几个农民（载位） |

## 3. 采集技能（伐木 / 采矿）

### 触发
右键点树/矿 → `指令系统` → `RtsUnit.order_gather(node)`：
1. 按 `harvest_kind` 选技能（树 = `chop_wood`，矿 = `mine_gold`）；
2. 向资源点 `claim_slot(self)` 要一个**载位**（金矿 3 个、树 2 个），
   站位 = `slot_point(载位号)`，围着资源散开，不再全挤在矿心；
3. 走位（`GatherPhase.TO_NODE`）；
4. 到位后进 `GatherPhase.ENTER`：播技能前摇（树 0.20s / 矿 0.35s）；
5. 前摇结束进 `GatherPhase.HARVEST`，开始计时采集。

### 载位（魔兽口径）
`代码/单位/可采集物.gd`：

```gdscript
claim_slot(unit) -> int      # 占位，返回 0..n-1；满了返回 -1（退回通用站位）
release_slot(unit)           # 采满 / 换目标 / 死亡 必须调
slot_point(idx, from_pos)    # 第 idx 个载位的世界坐标（朝来访方向 ±0.62rad 散开）
```

> 漏调 `release_slot` 会让位置永久占着（人死了别人也采不了）。
> 现在在 `order_gather`（换目标）、`_finish_harvest`（采满）、`_die`（死亡）三处都让位。

### 进矿表现
采金时农民**走平**进矿口（`mouth_point`），到 72% 隐藏模型 —— 不再往下沉，
所以不会出现"半截人遁入地下"。矿口岩石本身就是遮挡，读起来就是"进洞了"。

### 挥斧与树摇晃同步
`单位._tick_chop_fx()` 读骨骼动画进度（`SkeletonAnim.phase()`），
**每次循环只在 42% 那一下**触发 `可采集物.shake()`：斧头落下 → 树抖。
没有骨骼动画时退回 0.55s 定时器。

### 动作速度
一趟采集正好挥 N 下（`CHOPS_WOOD = 4` / `CHOPS_GOLD = 3`）：

```
动画速度 = 动作原长 × N ÷ 采集时长
```

农民用 `attack`（1.57s）代替 gather → 木头 1.57×4/4.0 ≈ **1.57x**（原来 1.0x），
金子 1.57×3/3.2 ≈ **1.47x**。改采集时长或下数会自动跟着变。

## 4. 主动技能（火球术）保留原样

`UnitDef.abilities`（卡上的 `skills`）→ 命令卡按钮 / 快捷键 Q →
`RtsUnit.order_cast()` → `RtsSkills.begin_cast()` → 前摇 → `release()`。
自动施法见 `单位._update_auto_cast()`，只挑 `first_ability()`（会自动跳过采集类）。

## 5. 自检

```powershell
godot --headless --path . --quit-after 30000 -- --gather-test   # 采集链路（90s，累计入库 ≥150 金）
godot --path . --resolution 1280x800 -- --walk-test              # 走姿/脚掌翻转
```

`采集自检` 的判据 2026-11-07 改成「农民累计入库金币」，
不再用"阵营金币净增长" —— 那个会被副官/AI 同时花钱污染（实测 -240 但采集是正常的）。
