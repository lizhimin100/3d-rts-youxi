# 战斗射程口径（2026-11-08 · 锚定版）

> 这份文件是**射程的唯一说明书**。改任何单位的 `range` 之前先读这里。
>
> 玩家 2026-11-08 定的流程（原话）：
> 「你先实测近战单位要多少实际距离才能正常打人、打楼、多打一不卡；把实测通过的那个
>  实际距离**定义为攻击范围 1**（基准单位），注释写清"1 = 多少米"，这个换算定死。
>  基调定为 1 之后，我再去调各单位数值。卡上填的都是游戏射程数值，运行时统一
>  `数值 × 基准1对应的米数`，判定同一套，不给建筑加隐藏距离。」

---

## 1. 一句话

> **卡上写游戏数值（1 / 1.2 / 1.5 / 10 / 13），引擎里用米；两者只差一个常量。**

```
实际米数 = 卡上数值 × 米每1
```

| 位置 | 作用 |
|---|---|
| `代码/配置/射程基准.gd::米每1` | **唯一的换算常量**，定死，改它等于全游戏缩放 |
| `单位表._def_of_card()` | 读卡时做唯一一次换算：`attack_range = range × 米每1` |
| `UnitDef.attack_range` | **米**。所有判定（够不够得着、范围圈、AI 阈值）只认它 |
| `UnitDef.attack_range_value` | **卡上那个游戏数值**。界面显示只认它 |
| 单位卡 `range` / 建筑卡 `range` | 人填的游戏数值（1.5 / 10 / 13 …） |

## 2. 锚是怎么来的（实测，不是拍的）

用 `代码/测试/射程标定.gd` 对**步兵**跑四组行为验收，每一档都重建世界：

| 组 | 判据 |
|---|---|
| ① 打人 | 走到 6m 外的敌人身边，6 秒内必须起手（`dbg_swings > 0`） |
| ② 打楼 | 走到 6m 外的兵营边，12 秒内必须起手 |
| ③ 四打一 | 四个兵围一个靶，**四个人都要起手** |
| ④ 四围楼 | 四个兵围一栋楼，**四个人都要起手** |

结果：

```
R = 0.30 0.40 0.50 0.60 0.70 0.80 0.90 1.00   四组全部通过
```

也就是说"能不能打到"的**地板低于 0.3 米** —— 因为贴墙直顶（§4）让兵能站到墙面外
0.84m 挥砍。真正有意义的第二个实测值是**兵贴着楼挥砍时的真实间距**：

```
墙面外 1.34m（战斗自检 G 组实测） − 自身半径 0.5m = 0.84m
```

一个人站着挥一刀，够得着的就是这个尺度。**取整定锚：米每1 = 1.00 米**。

为什么不是 0.84 或 0.30：

1. 0.84 向上取整到一个身位直径，比实测地板高 3 倍以上，永远不会"贴着楼砍不到"；
2. 和现有远程/塔的米数 **1:1 对齐**（卡上 10 → 10m、13 → 13m）——
   换算法不会顺手把远程平衡改掉（这是最容易忽略的副作用）；
3. "1 = 一个人站着伸手够到的距离"，人脑好算。

> ⚠ 这个常量**定死**。要改某个单位就改它卡上的 `range`，不要动 `米每1`。

## 4. 近战打楼：没有隐藏距离

`BUILDING_REACH`（以前给建筑单开的 +0.6m 隐形余量）**已删除**，打人打楼同一把尺。

寻路仍然把建筑占地外扩 1 格（`关卡.BUILDING_BLOCK_CLEARANCE = 1`，这是绕行走位要用的，
实测改 0 会让"沿外墙走 20m"卡住）。所以兵会被挡在墙面外 2.0~2.5m —— 光靠寻路永远够不着。

解决办法是**贴墙例外**（不是加射程）：

| 位置 | 作用 |
|---|---|
| `单位._update_attack` | 目标是建筑且间隙 ≤ reach+1.5m 时，最后这段**不走寻路**，直接朝站位点顶 |
| `单位._step_direct` | 直顶判据：**没走进楼里**（距墙面 ≥ 自身半径+2cm）且本来就贴着这栋楼（≤3m） |
| `单位._wall_approach` | 标记"正在砍这栋楼"：允许进那圈净空、免墙内推挤 |
| `单位._attack_reach` | **只返回 attack_range（米）**，对建筑不加任何东西 |

实测（`战斗自检`）：

| 组 | 结果 |
|---|---|
| G 一个步兵砍兵营 | 停在墙面外 1.34m，12 秒 7 次起手、打掉 48 血 |
| G2 四个步兵从四面围楼 | **四人各 8 次起手**、共打掉 238+ 血 |

## 5. 范围圈（玩家看到的那条线）

```
圈半径 = attack_range(米) + 自身半径 + RING_TARGET_RADIUS(0.5)
```

含义：**一个标准体型（半径 0.5m）的敌人，中心只要在圈内，就一定在射程内**。
步兵（1.5m）圈 = 1.5 + 0.5 + 0.5 = **2.5m**。

| 单位 | 圈半径 |
|---|---:|
| 步兵 | 2.50 |
| 弩兵 | 10.94（10 + 0.44 + 0.5） |
| 箭塔 | 15.50（13 + 占地半宽 2 + 0.5） |

## 6. 多个近战打同一个目标

**不许所有人冲向目标中心**：

| 位置 | 作用 |
|---|---|
| `单位._attack_spot(t)` | 建筑 → 墙面外扩一圈（沿朝向散开 ±26°）；单位 → `_surround_spot` |
| `单位._surround_spot(t)` | 站到"从目标指向自己"那一侧的外圈 |
| `_update_attack` | 够不着时走 `_attack_spot`；**只差一点点**时`_step_direct` 直顶最后半步 |

三个必须同时成立的条件（缺一条就复现"只有一个兵在打"）：

1. 不要走中心（全队解析出同一格，分离力把外圈的人顶出射程）；
2. 落点要扣掉到点容差（`ARRIVE_TOLERANCE = 0.35m`）；
3. 敌人不算"占位"（`_spot_taken()` 要排除敌人）。
