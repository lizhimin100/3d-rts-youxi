# 战斗射程 / 攻击圈口径（2026-11-08 · 定稿）

> 这份文件是**射程与攻击圈的唯一说明书**。改任何单位的 `range` / `volume` 之前先读这里。
>
> 玩家 2026-11-08 定稿（原话）：
> 「R1 = 0.015 米/单位不动，实际米数 = 卡上数值 × R1。不要倍数表、不要校验工具、不要 A/B。」
> 「攻击圈固定 = 射程 × R1，不随场上最大单位体型变，不要再按'全场最大单位'修正。」
> 「命中：两圈相交即可——攻击者中心到目标中心 ≤ 攻击圈半径 + 目标判定圈半径。」
> 「步兵卡上 125 改 90（1.35 米），已确定。」

## 0. 五条口径（覆盖此前所有版本）

1. **换算**：`实际米数 = 卡上数值 × R1`，`R1 = 0.015 米/单位`（定死在 `代码/配置/射程基准.gd`）。
2. **攻击圈**：固定 = 射程（米）。**不按场上最大单位体型修正，也不加自身/目标半径。**
3. **命中**：两圈相交 —— `攻击者中心到目标中心 ≤ 攻击圈 + 目标判定圈`。
4. **判定圈**：由卡上的**体积**派生（唯一出口 `代码/配置/体积派生.gd`）。
5. **打建筑**：没有第二套口径，量到墙面（footprint 就是它的身体）。

历史版本（2026-11-07 的"扣双方半径"、2026-11-08 早上的"圈 + 全场最大体型"）**已作废**，
`选择系统.ring_target_radius()` 这个函数已经删掉，别再写回来。

## 1. 换算

| 位置 | 作用 |
|---|---|
| `代码/配置/射程基准.gd::R1` | **唯一的换算系数**，定死。改它 = 全游戏所有射程同时缩放 |
| `单位表._def_of_card()` | 读卡时做唯一一次换算：`attack_range = range × R1` |
| `UnitDef.attack_range` | **米**。所有判定（够不够得着、攻击圈、AI 阈值）只认它 |
| `UnitDef.attack_range_value` | **卡上那个游戏数值**（90 / 650 …）。界面显示只认它 |
| 单位卡 / 建筑卡 `range` | 人填的游戏数值 |

**实测地板 0.30 米**（`代码/测试/射程标定.gd` 四组行为验收的最低通过值），近战 1.35 米是地板的 4.5 倍，
不存在"贴着楼砍不到"。

## 3. 体积 → 判定圈（唯一公式）

卡上只填 **`volume`（体积）**，`1.0 = 标准体型（步兵）`。三个量都由它派生：

```
模型缩放   = volume
碰撞半径   = volume ÷ 2        （模式 2，当前生效）
判定圈半径 = volume ÷ 2
```

三种候选口径都在 `代码/配置/体积派生.gd`，**切 `MODE` 一个常量就换**：

| 模式 | 判定圈半径 | 说明 |
|---|---|---|
| 1 | `volume` | 体积写"半径米数" |
| **2** | `volume ÷ 2` | 体积写"直径米数"（**当前生效**）|
| 3 | 卡上另填 | 体积只缩放模型 |

对照表跑：`godot --headless --path . --script 代码/测试/体积标定.gd`（打印三列，只读不改）。
**待玩家实测后拍板**；拍板只改 `体积派生.MODE`，别在别处改。

现存卡（体积 = 旧 `body_radius × 2`，模式 2 下派生回去等于旧值，改口径不改变手感）：

| 单位 | 体积 | 判定圈 |
|---|---:|---:|
| 农民 | 0.84 | 0.42 |
| 弩兵 / 法师 | 0.88 | 0.44 |
| 步兵 | 1.00 | 0.50 |
| 豺狼人斥候 | 0.96 | 0.48 |
| 豺狼人战士 | 1.10 | 0.55 |
| 蒸汽重步兵 | 1.16 | 0.58 |

建筑不走体积（用 `footprint` 占地格），`judge_radius = 0`。

## 4. 命中判定

`单位._target_gap(t)` = `中心距 − 目标判定圈`（建筑 = 到墙面距离），
`单位._attack_reach(t)` = 攻击圈半径。**够得着 = `_target_gap <= _attack_reach`。**

步兵（攻击圈 1.35 / 判定圈 0.5）实测：

| 中心距 | 余量 | 够不够 |
|---:|---:|---|
| 1.55 | 1.05 | ✓ |
| 1.85 | 1.35 | ✓（正好在边界上）|
| 1.90 | 1.40 | ✗ |
| 2.25 | 1.75 | ✗ |

## 5. 显示：两个圈，不同颜色

| 圈 | 半径 | 颜色 | 何时画 |
|---|---|---|---|
| **攻击圈** | `attack_circle_radius()` = 射程（米） | 暖金 | **仅单选** |
| **选中圈（判定圈）** | `judge_radius()`（体积派生） | 阵营色 | 单选 / 多选都画 |

- 多选只画选中圈（旧版"多选同类各画一个射程圈"已经否掉，会糊成一坨）。
- 建筑的选中圈按 footprint 半对角线罩住；建筑没有额外的判定圈。
- 圈半径只有一个出口：`选择系统.range_ring_radius_of(unit)`（自检直接调这个）。

## 6. 近战打楼：没有隐藏距离

`BUILDING_REACH`（以前给建筑单开的隐形余量）**已删除**，打人打楼同一把尺。

寻路仍把建筑占地外扩 1 格（`关卡.BUILDING_BLOCK_CLEARANCE = 1`，改 0 会让沿墙走卡死）。
解决办法是**贴墙例外**（不是加射程）：

| 位置 | 作用 |
|---|---|
| `单位._update_attack` | 目标是建筑且间隙 ≤ reach+1.5m 时，最后这段**不走寻路**，直接朝站位点顶 |
| `单位._step_direct` | 直顶判据：**没走进楼里**（距墙面 ≥ 自身半径+2cm）且本来就贴着这栋楼（≤3m） |
| `单位._wall_approach` | 标记"正在砍这栋楼"：允许进那圈净空、免墙内推挤 |

实测（`战斗自检` G / G2）：一个步兵砍兵营 → 停墙面外 1.21m、12 秒 7 次起手；
四个步兵从四面围楼 → **8 / 8 / 8 / 7 次起手，没人 0 次**。

## 7. 多个近战打同一个目标

| 位置 | 作用 |
|---|---|
| `单位._attack_spot(t)` | 建筑 → 墙面外扩一圈（沿朝向散开 ±26°）；单位 → `_surround_spot` |
| `单位._surround_spot(t)` | 站到"从目标指向自己"那一侧的外圈，半径留出自身身位 + 到点容差 |
| `_update_attack` | 够不着时走 `_attack_spot`；只差一点点时 `_step_direct` 直顶最后半步 |

实测 F 组：四人围一个靶 → `[5, 5, 5, 5]` 起手，4/4 参战。
