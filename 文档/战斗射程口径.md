# 战斗射程口径（2026-11-07 统一）

> 这份文件是**射程数值的唯一说明书**。改任何单位的 `range` / `acquire_range` 之前先读这里。
> 起因：玩家反馈「弩兵实际能打到的地方比地上的圈大一圈」「近战单位的攻击距离也很怪」
> 「近战打不到建筑」。

---

## 1. 定义

`UnitDef.attack_range`（卡上的 `range`）=

> **本单位碰撞圆边缘 → 目标碰撞体边缘，允许的最大水平间隙（米）。**

不是中心距，也不是"武器长度"。`0` = 两具身体正好贴住。

于是"实际能打到"的最大**中心距** = `range + 自身半径 + 目标半径`。
步兵（0.5 + 0.5 半径、range 1.0）能打到 2.0m 中心距。

### 实现（唯一入口）

| 位置 | 作用 |
|---|---|
| `单位.gd::_target_gap(t)` | 中心距 − 目标半径 − **自身半径** = 边缘间隙；建筑量到墙面再减自身半径 |
| `单位.gd::_attack_reach(t)` | 直接返回 `attack_range`；**不再加目标半径**（旧代码加了一次，等于真实射程多算了 2×目标半径） |
| 够得着的判据 | `_target_gap(t) <= _attack_reach(t)` |
| 范围圈半径 | `选择系统._range_ring_radius()` = `attack_range + 自身半径 + 标准目标半径(0.5)` |

## 2. 射程数值：就是米数，没有档位

> 玩家 2026-11-07 二次纠正：
> 「我从来不是想整什么档位，不要弄什么 1、1.5、9 这种档位，我要的是**能调整的数值**。
>  近战单位的攻击范围是基准 1，这个 1 要能走进并正常攻击到敌人、建筑；
>  然后在这个 1 的基准上，去定义其他单位和防御塔的攻击范围具体是多少，这个我去单位卡调整。」

所以：

- **卡上的 `range` 就是米数**（边缘间隙口径，见 §1），填多少就是多少；
- **没有 `射程基准.gd`**、没有 `档位 × 基准` 的乘法、没有"改基准要同步全表"的校验；
- 近战标准值 **1.0**（基准），其它单位按"相对它多几米"直接填数字。

当前填的值（**只是当前值，随时可在卡上改**，不是档位）：

| 单位 | id | range（米） | 说明 |
|---|---|---:|---|
| 农民 | `peasant` | 1.0 | 自卫，和步兵一样 |
| 步兵 | `footman` | **1.0** | **基准** |
| 豺狼人战士 | `gnoll_warrior` | 1.0 | 近战 |
| 蒸汽重步兵 | `steam_guard` | 1.5 | 体型大一点，多 0.5 米 |
| 豺狼人斥候 | `gnoll_scout` | 9.0 | 短弩 |
| 弩兵 | `archer` | 10.0 | 标准远程 |
| 法师 | `mage` | 11.0 | 施法距离 |
| 箭塔 | `tower` | 13.0 | 必须压远程，否则被白嫖 |
| 哨塔 | `watchtower` | 0 | 无攻击，`detect_radius = 22` 只做预警 |

### 2.1 唯一的机械保证（`配置回归` 的「射程口径」一项）

不再比对"档位 × 基准"，只守两条底线（数字归玩家）：

1. 能攻击的单位 `range > 0` —— 填 0 等于谁都打不到；
2. 近战（`projectile == NONE`）`range ≤ 3.0` —— 超了说明把中心距当成边缘间隙填了。

### 2.2 配套约束

1. **`acquire_range ≤ sight_range`**：索敌不能超过视野（法师 11/12、弩兵 11/11、
   箭塔 13/15、斥候 13/13）。
2. **看不见的敌人不许锁、不许打**：`Game.is_visible_to()` / `is_node_visible_to()` 是唯一出口。
3. **前摇结束时再验一次**：`_release_attack()` 里目标跑出「射程 + 0.5m」或钻进黑雾 → 收手。

## 3. 建筑目标（一把尺，没有第二套口径）

> 玩家 2026-11-07 二次纠正：「近战 range 是 1，这个 1 要能走进并正常攻击到敌人、建筑。」

### 3.1 为什么以前打不到楼

寻路把建筑占地**外扩 1 格**（`关卡.BUILDING_BLOCK_CLEARANCE = 1`，这条是为了绕行走位，
实测改 0 会让"沿外墙走 20m"卡住，所以**保留**）。于是兵被挡在**墙面外 2.0~2.5m**，
而近战 range 只有 1.0 —— 物理上够不着。以前的补丁是塞一个
`BUILDING_REACH = 1.60` 的隐形余量，让"打楼"比"打人"多 60% 射程。
**这个常量已经删掉。**

### 3.2 现在的做法：贴墙例外（walk up and swing）

| 位置 | 作用 |
|---|---|
| `单位._update_attack` | 目标是建筑且间隙 ≤ reach + 1.5m 时，最后这一段**不走寻路**，直接朝站位点顶 |
| `单位._step_direct` | 直顶的硬判据：**没走进楼里**（`距离墙面 ≥ 自身半径 + 2cm`）且本来就贴着这栋楼（≤3m） |
| `单位._wall_approach` | 标记"正在砍这栋楼"，给两条例外：可以进那圈净空、免墙内推挤（否则刚贴上就被顶回去） |
| `单位._attack_reach` | **只返回 attack_range**。打人打楼同一把尺 |

结果（`战斗自检` 实测）：

| 组 | 结果 |
|---|---|
| G 一个步兵砍兵营 | 停在墙面外 **1.34m**，12 秒 7 次起手、打掉 48 血 |
| G2 四个步兵从四面围楼 | **四人各 8 次起手**、共打掉 252 血（以前是 [0,0,8,8]） |

> 兵停在墙面外 ≈ `reach + 自身半径` = 1.5m 处挥砍：按"边缘间隙"的口径，
> 这正是 range=1 该站的位置。想让兵贴得更死，把卡上的 range 调小即可。

## 4. 范围圈（玩家看到的那条线）

> 玩家 2026-11-07：「敌人整个模型都在圈外一些却仍然能打到。」

旧圈半径 = `attack_range + 自身半径`（1.5m），而实际能打到 2.0m 中心距 ——
敌人的**中心**站在圈外 0.5m 仍然挨打（正好差一个目标半径）。

现在：

```
圈半径 = attack_range + 自身半径 + RING_TARGET_RADIUS(0.5)
```

含义变成：**一个标准体型（半径 0.5m）的敌人，中心只要在圈内，就一定在我的射程内**。
步兵圈 = 1.0 + 0.5 + 0.5 = **2.0m**（= 最大可打中心距，实测对齐）。

| 单位 | 圈半径 |
|---|---:|
| 农民 | 1.92 |
| 步兵 | 2.00 |
| 蒸汽重步兵 | 2.50 |
| 弩兵 | 10.94 |
| 法师 | 11.94 |
| 箭塔 | 15.50（13 + 占地半宽 2 + 0.5） |

## 5. 多个近战打同一个目标（包围点）

**不许所有人冲向敌人中心**：

| 位置 | 作用 |
|---|---|
| `单位.gd::_attack_spot(t)` | 建筑 → 墙面外扩一圈（沿朝向散开 ±26°）；单位 → `_surround_spot` |
| `单位.gd::_surround_spot(t)` | 站在"从目标指向自己"那一侧的外圈，半径 = 目标半径 + 自身半径 + 想要的边缘间隙 |
| `_update_attack` / `_order_attack` | 够不着时走 `_attack_spot`，**落定在射程外一点点时强制重走最后半步** |

三个必须一起成立的条件（缺一条就复现"只有一个兵在打"）：

1. **不要走中心**：全队 12 个人解析出的落点是同一格，分离力把外圈的人顶出射程；
2. **落点要扣掉到点容差**：`ARRIVE_TOLERANCE(0.35m)` 会让人停在射程外 0.3m；
3. **敌人不算"占位"**：`_spot_taken()` 要把敌人排除。

自检：`战斗自检` 的 **F 组**，四个步兵围一个靶，断言 `dbg_swings` 四个都 > 0。

## 6. 改完怎么验

```powershell
$g = 'E:/Program Files (x86)/Steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe'
& $g --headless --path . --script 代码/测试/战斗自检.gd    # E 射程口径 / G 打建筑 / H 最大射程
& $g --headless --path . --script 代码/测试/配置回归.gd    # 「射程口径」一项
```

自检里的阈值**从卡的 range 派生**（不再硬编码 8.8 / 9.2）——
这样玩家改数值时自检不会误报，只有口径破了才红。

`H_最大射程` 会打印一张表：

```
中心距 1.60 → 间隙 0.60 / reach 1.00 → 够
中心距 2.00 → 间隙 1.00 / reach 1.00 → 够
中心距 2.05 → 间隙 1.05 / reach 1.00 → 不够
```

这张表就是"圈该画多大"的实测基线：**最远可打中心距 2.00 = 圈半径 2.00**。
