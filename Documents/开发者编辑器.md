# 开发者编辑器（《战争原岛》专属）

> 入口：Screens/scenes/dev_editor.tscn（运行时场景，不是 Godot 编辑器插件）。
> 定位：策划/数值改内容用的**工具**，不进发行版；数据直接写回 Content/data/*.json 与 Content/i18n/ui.csv。

## 怎么打开

**在 Godot 里（策划日常）**：打开项目后，顶部主屏页签会多出「**战争原岛开发者编辑器**」并自动切过去。
它由 `addons/war_island_editor` 提供，内嵌 `Screens/scenes/dev_editor.tscn`。

> 旧 `addons/map_editor`（传统 RTS 地形/对象地图编辑器）**已默认禁用**，
> 所以不会再看到旧的地图编辑器主屏。需要地形编辑时，到「项目设置 → 插件」手动启用旧插件。
> 如果还看到旧的「地图编辑器」页签：重启 Godot，或在「项目设置 → 插件」确认启用的是
> `addons/war_island_editor/plugin.cfg`。

**运行时/截图**（同一套 UI，不依赖编辑器）：

~~~powershell
# 截图/验收（无窗口跑一帧，再真实点一次兵种行）
./Tools/run-game.ps1 --shot editor editor_preview.png

# 建筑与卡牌页、长横道营地页（QA 截图配方）
./Tools/run-game.ps1 --shot editor_build _qa/editor_build.png
./Tools/run-game.ps1 --shot editor_level _qa/editor_level.png

# 直接截 Godot 编辑器主屏（开发用）
godot --editor --path . -- --dev-editor-shot=_qa/editor_plugin.png
~~~

**关于 C# 报错**：
- DPS 靶场的公式只在 C# `CombatCalculator` 里。用 **.NET/mono 版 Godot** 且跑过 `run-game.ps1`（会先 `dotnet build`）时，靶场实时可用。
- 用 **Steam 标准版 Godot**（无 C#）打开时，页签/数据编辑/写回仍然可用；DPS 区域会显示「DPS 需要 .NET 内核」，
  并且 `Game/adapters/bridge.gd` 只打印一次提示，不再刷 `No loader found for resource: ModelBridge.cs`。
- 想在标准版里看实时 DPS：换 .NET 版 Godot，或先 `dotnet build 战争原岛.csproj` 再用 mono 版打开。


## 视觉口径

- 深岩底 #12161F，分区卡片 #1B2230，圆角 + 1px 冷描边，不做 Godot 默认灰框；
- 阵营色只做标签/强调：联盟蓝、豺狼人金、鱼人绿、敌方红；
- 数字用等宽字体，正文用系统中文字体；右上角常驻 R1 = 0.015 米 / 游戏数值；
- 主题在 Screens/editor/dev_theme.gd 一次性编译成 Theme，页面不再散落 StyleBoxOverride。

## 三个页签

### 01 单位与 DPS 靶场对账

- 12 兵种列表（阵营色条、小队数、卡面 DPS）；
- 英雄区：小队人数、启用开关；
- 三维数卡：攻击 / 护甲 / 移速；射程卡实时显示 650 × R1 = 9.75 米；
- 13 项攻防穿透：hp / attack_damage / attack_cooldown / attack_range / attack_type /
  armor / armor_type / hit / dodge / crit / armor_pen_flat / armor_pen_pct / move_speed；
- 模型绑定：model_path、model_scale、use_placeholder_mesh、投射物/投射物速度/人口/体积；
- 右侧靶子模拟器：任选防守兵种，**直接调 C# CombatCalculator**（经 Game/adapters/bridge.gd），
  显示实际命中率、有效护甲、承伤比例、克制系数、单次期望伤害、最终 DPS；
  另有 6 步结算拆解、攻守互换、小队 DPS 与两条 DPS 对比条。

> 靶场与飞书多维表格同口径：有效护甲 = 护甲 × (1-百分比穿透) - 固定穿透；
> 承伤 = 1/(1+有效护甲×0.06)（负甲最多 3 倍）；DPS = 单次期望 / 攻击间隔。
> 公式本体只在 Model/Combat/CombatCalculator.cs，编辑器不重推。

### 02 建筑与卡牌

- 4 种建筑：pop、produce_tag、耐久/护甲/基地减伤、3D 模型；
- **1~3 星产出**表（人口 / 训练位 / 基地减伤），写回 planning.json 的 star_output；
- 建筑速览：产出人口、可建造数、模型绑定数、开局座数；
- 卡池：新增/复制/删除建造、训练、策略卡；类型、CP、张数、Exhaust、绑定目标、训练 Tag；
- **12 张初始卡组**：deck.start 正好 12 张；点卡池行选中后「加入卡组」，点 × 移除；
  卡牌张数（count）之和也固定 12，和初始卡组一致。

### 03 长横道关卡 / 营地

- 三段横道：lane.segments 三行长度/宽度（游戏数值），每行实时显示 × R1 = 米；
  三段合计必须等于 lane.length（默认 4000 = 60 米）；
- 态势模板：平势 / 劣势 / 优势，切换时重排三段长度/宽度（合计不变）并套用意图权重；
- 敌方意图池：5 条权重，实时归一化占比、总权重 100；切模板写回 intent_templates；
- 营地：**RTS 错落营地 + 类自走棋独立石台**（十边形石台、槽位间留行军间隙）；
  - 预摆开局：1 基地 + 2 农场 + 1 兵营；
  - 拖动建筑到空石台换槽位；
  - 敌方固定建筑（红六边石台）可显示/隐藏、增删；
  - 画布只画岩层等高线和行军带，**没有棋盘格 / 五子棋连线格 / 自由障碍涂抹**。

## 数据字段（本次新增）

| 文件 | 字段 | 说明 |
|---|---|---|
| units.json | units[].model_path / model_scale | 单位 3D 模型；use_placeholder_mesh 仍管占位 |
| planning.json | buildings[].produce_tag | 训练牌按 Tag 找建筑（与 tag 分开，便于未来多套产线） |
| planning.json | buildings[].star_output[3] | {pop, train_slots, drain_reduction} 1~3 星产出 |
| planning.json | buildings[].model_path / model_scale | 建筑 3D 模型 |
| planning.json | deck.start[12] / deck.size | 初始卡组；卡牌 count 之和也固定 12 |
| planning.json | board.platforms[10] | 石台可视化坐标 {plot,x,y,radius,kind}（0..1） |
| planning.json | board.camp_m | 营地实际尺寸（米），用于最小行军间隙换算 |
| levels.json | lane.segments[3] | 三段 {name_key,length,width,role}；合计 = lane.length |
| levels.json | lane.templates | 三套 {lengths[3],widths[3],note} |
| levels.json | intent_pool[5] / intent_templates | 意图权重与三套模板权重 |
| levels.json | enemy_buildings[3] | 敌方固定建筑 {building,x,y,star}（画布归一化坐标） |
| Content/i18n/ui.csv | unit./building./card. | 三条术语表；显示名改动时同步写回 |
| Content/i18n/ui.csv | editor.* | 编辑器全部界面文案（源码零写死中文） |

## 写回与校验

- 任一字段提交后 0.7 秒自动调用 dev_data.save_all()：写 units.json / planning.json / levels.json / ui.csv，
  然后 I18n.load_csv()；右上角状态点变绿并显示写回时间。
- 右上角「校验数据」跑 10 项自检：单位/属性/建筑/卡组/横道/意图/石台/开局/模型/文案。
- run-game --check 另加 15 条断言（见 Tests/checks/check_all.gd 的 _check_dev_editor）：
  框架文件、数据层、模型路径、13 属性、12 卡组、三段横道、意图权重、石台间隙、敌方建筑、
  截图配方、发行排除、源码零中文等。

## 边界

- 开发工具不进发行版：Tools/build/release_exclude.txt 排除 Screens/editor 与编辑器场景；
- 不碰 Model/：所有算术仍走 C# 内核；编辑器只写内容；
- 不替代 addons/map_editor（地形/对象地图编辑器）；本编辑器只做《战争原岛》内容三页；
- 五子棋格/自由障碍涂抹是旧 RTS 编辑器的东西，本页面明确不做。
