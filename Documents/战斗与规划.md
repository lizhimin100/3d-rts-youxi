## 2. 棋盘规划（BoardSession）

### 开局

- 1 基地（重甲，人口 12）+ 2 农场（各 10 人口）+ 1 兵营。
- 人口上限 = 基地 12 + Σ 农场 10×星级倍率（1 星 1.0 / 2 星 1.4 / 3 星 2.0）。
- CP：每次规划 12 点，上限 24；经济建筑（伐木场）在每次规划开始时额外产 CP。

### 棋盘规则（2026-11-24）

- 玩家棋盘 = **6 列 × 3 行**（`shell_ridge_01` 的 18 个可建造格，主堡单独一格）。
- **列顺序**：新建筑必须落在"当前列从上到下第一个空格"（`BoardArena.NextFillTile`）；
  填满一列才开下一列；默认**禁止自由选格 / 禁止换位**。
- 钩子：`BoardSession.AllowFreePlacement` / `AllowSwap`（遗物/策略牌将来打开）。
- **3 合 1**：同名未满星建筑拖到目标格 → 星级 = 累计建筑数（封顶 3）；目标格保留、来源格空出。
- **拆除**：`Demolish(tile)` 清空格子；空出的格子自然成为下一个优先填充位（防满格死锁）。
- 空间光环：`BoardArena` 提供上下左右邻居 / 跨格偏移 / 列行号 / 曼哈顿格距；
  铁匠铺等 `kind=support` 建筑按 `aura.scope`（army/adjacent/column/self）影响来源建筑产出的兵。

### 卡牌

| 类型 | 行为 | 是否循环 |
|---|---|---|
| 建造牌（5 种） | 落**当前填充位**建 1 星建筑；打出即 Exhaust | 否 |
| 训练牌（2 种） | `units_mode=per_building`：每座匹配 `building_tag` 的建筑各产 `units` 名；兵种星级 = 建筑星级 | 是 |
| 策略牌（1 种） | 只影响本轮：「加快训练」征召 ×1.5 | 是 |

- 起手 9 张：2 建造 + 1 加快训练 + 4 步兵 + 2 弩手；之后每次规划抽 9 张，手牌上限 10。
- 核心循环：**打兵营 → 打征召牌 → 每座兵营各产一批**。2 座兵营打 1 张步兵牌（units=3）= 6 名。

### CP / 人口纪律

- CP 不够：一分不扣，操作失败。
- 人口不够：**整张牌打不出**（不半途产出），计入 `pop_blocked`。
- 建造不受人口限制；人口只卡训练。

## 3. 单轮单场死斗（BattleSession / CampaignRun）

### 战场

- `levels.json` 的 `battlefield`：`deploy_player / deploy_enemy / width / edge`（游戏数值）。
- 双方从各自部署线**直线对冲**（`OrderMarch`，不走脊线 A*）；近战在前、远程在后，
  中轴向外对称、超宽折行（96 / 144 / 240）。
- 玩家棋盘防御建筑 → 实体哨塔，落在部署线后方两翼（必须落在敌方阵线宽度内，否则零输出）。

### 战斗

- 固定步长 0.05 秒；质量分离（8 遍）、硬核 0.90；停火线 0.92R + 步长裁剪。
- 近战即时结算；远程生成投射物（按 `projectile_speed` 飞行，命中才结算）。
- 目标每 0.18~0.3 秒重算一次最近敌人；一方全灭即收场（敌方要等所有波次出场）。
- **45 秒狂暴**：全员攻速 ×2、护甲按 0 结算（`battle.json` 的 `berserk`）；
- 60 秒到点或一方全灭 → **结算**。

### 结算（唯一口径 `RoundResolver`）

- 只有一方有幸存 → 该方按幸存单位 `base_damage[star-1]` 之和扣对方；
- 双方都有幸存（60 秒整极端情况）→ 按两边总和**差值**扣少的一方（相等不扣）；
- 双方都没有 → 0 / 0；单方单轮封顶 `settle.base_damage_cap = 48`；
- 基地血跨轮保留，直到一方归零；12 轮上限只做僵持兜底。

### 每轮循环（Phase 3 的唯一口径）

```
BoardSession.BeginPlanning()        # 打牌 / 建造 / 升星（无限时）
  → EndPlanning() → BuildArmyPlan() # 固化成 ArmyPlan
  → BattleSim（60 秒）              # 部署线落地 + 敌方波次 + 45 秒狂暴
  → RoundResolver.Settle()          # 幸存 base_damage 扣基地（封顶 48）
  → 没分出胜负 → 回到 BeginPlanning()（**重新打牌**，第 N+1 轮）
```

`CampaignSession` 只暴露 `BeginPlanning / EndPlanning / BeginRound / SettleRound`；
旧的 `BeginAttack / BeginDefend / EndRound`（规划一次、攻防连打两场）已删除。

### 胜负

- 敌方基地归零 + 我方 >0 = 胜利。
- 我方基地归零 = 战败（输出简要死因：败于第几轮 / 敌方主力击杀 / 致命扣血单位）。
- 12 轮双方都还在 = 僵持（draw，极端兜底）。

## 4. 战败简报（取代统计面板）

只有战败时输出，**不再构建全场 DPS/承伤报表**：

```
败于第 N 轮（第 N 轮）；敌方主力击杀：bandit_marauder（12 杀）、bandit_chief（5 杀）；
致命扣血：豺狼人战士★2(2)、豺狼人萨满★2(2)，扣 14 点，基地 12 → 0。
```

数据结构：`CampaignResult.DefeatRecord / DefeatKillers / DefeatFatalUnits`。

## 5. 命令

```powershell
./Tools/run-game.ps1 --check
./Tools/run-game.ps1 --simulate --games=100
./Tools/run-game.ps1 --simulate --games=100 --seed=1
```

- `--check` 里与本专题相关的断言：4×4 表 / 兵种对表 / 训练牌 `building_tag` 闭环 /
  R1 配置 / 隔排几何 / 竖列棋盘 / 3 合 1 / 拆除 / 结算 / 跳字，共 37 项（C# `Phase2Checks`）。
- `--simulate` 末尾输出 `SIM {json}`，并跑 **配平门禁**（`BAND PASS` 才算过，否则退出码 1）：
  狂暴率 15~30% / 胜率 45~55% / 平均 3~5 轮 / 单轮 25~40 秒。
- 100 局基线（seed 1..100，2026-11-25 Phase 3）：
  胜 49 / 负 51 / 平 0（49%），4.00 轮，单轮 39.9 秒（中位 39.3 s，25~40 s 占 56%），
  单轮扣血 10.4，**狂暴轮 17.4%**（Phase 2 为 88.3%），差值结算 0.0%，
  分离后深叠 0.0 对 / 空挥 3.4 人·秒 / 朝向反转 3.32 /s。
