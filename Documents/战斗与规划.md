## 2. 规划阶段

### 开局

- 1 基地（坚固甲，人口 12）+ 2 农场（各 10 人口）+ 1 兵营。
- 人口上限 = 基地 12 + Σ 农场 10×星级倍率（1 星 1.0 / 2 星 1.4 / 3 星 2.0）。
- CP：每次规划 16 点，上限 24，不跨阶段累积。

### 卡牌

| 类型 | 行为 | 是否循环 |
|---|---|---|
| 建造牌（3 种） | 落空地建 1 星建筑；打出即 **Exhaust**（本局不再回牌堆） | 否 |
| 训练牌（4 种） | 按建筑 **Tag**，让全场同类建筑各产 1 队；兵种星级 = 建筑星级 | 是 |
| 策略牌（3 种） | 只影响本轮：急行军 +25% 移速 / 坚壁 +30% 护甲 / 致命瞄准 +20% 暴击 | 是 |

- 开局手牌固定 6 张：兵营、农场、步兵、长枪、弓手、致命瞄准。
- 之后每次规划抽 6 张；手牌上限 8。
- 核心循环：**打兵营 → 打训练牌 → 全场同类建筑一起产兵**。3 座兵营打 1 张步兵牌 = 3 队步兵。

### 3 合 1 升星

- 拖同名建筑叠在一起：累计 **3 座** → **3 星**（星级 = 累计建筑数，封顶 3）。
- 2 星 = 2 座，3 星 = 3 座；3 星建筑产 3 星兵（攻击 ×1.8、血量 ×2.0）。
- 农场 3 星人口 ×2.0；哨塔每座让敌方对基地的抽血 -15%，总上限 `max_drain_reduction` = 45%。

### CP / 人口纪律

- CP 不够：一分不扣，操作失败。
- 人口不够：该建筑本轮不产兵，计入 `pop_blocked`（不退款、不排队）。
- 建造不受人口限制；人口只卡训练。

## 3. 单场双 60 秒

### 横道

- 长 4000 游戏数值（60 米），宽 420（6.3 米），两端敌区各 600（9 米）。
- 玩家在左（+x 推进），豺狼人在右（-x 推进）。
- 单位按角色分三排：前排（射程 ≤120）→ 长枪（120~300）→ 远程（≥300）。
- 长枪会主动回到"前排步兵身后 0.9 米"的槽位；打不到人时先归位，再找目标。

### 战斗

- 固定步长 0.05 秒；圆形轻量排斥是位置约束（不是力），两遍收敛。
- 近战即时结算；远程生成投射物（按 `projectile_speed` 飞行，命中才结算）。
- 目标每 0.2~0.32 秒重算一次最近敌人；全歼后所有幸存小队继续越线。
- 停在敌区、且 9 米内没有敌人时，每队每秒抽 `zone_dps_per_squad` 点基地血。
- 轮末（60 秒或基地归零）清空全部部队；基地血量跨轮保留。
- **60 秒未全歼 = 平局且不加伤**：到点直接结算，不追加任何"破僵伤害"。
- 战斗期玩家微操只剩"选中我方小队 → 集火敌方小队"；移动/停火/驻守从玩家手里移除，
  推进与接敌交给自动战斗与预设偏好（`SquadBattle.OrderPlayerMany` 只白名单 attack）。
- 任一方基地归零立即结束本场（不用把剩下的一轮跑完）。

### 胜负

- 敌方基地归零 + 我方基地 >0 = 胜利。
- 我方基地归零 = 战败（基地被破）。
- 两轮结束双方基地都还在 = 战败（未攻克）。
- 同归于尽 = 平局。

## 4. 定性复盘

每局输出 1~4 条原因，第一条是 `top_reason`，100 局按 code 聚合：

| code | 含义 |
|---|---|
| `win` | 胜利 |
| `no_army` | 两轮一队没出 |
| `base_breach` | 基地被破 |
| `counter_push` | 被反推（敌方抽血 >300 或我方基地 <80%） |
| `outnumbered` | 同屏兵力劣势（敌方最多人数 > 我方 1.4 倍） |
| `exchange` | 交换比失衡（我方阵亡 > 敌方 1.3 倍） |
| `front_collapse` | 第一队 25 秒内全灭 |
| `no_zone` | 进攻战一次没摸到敌方基地 |
| `pop_blocked` | 训练被人口挡住 |
| `pike_gap` | 长枪在步兵身后的时间 <60% |
| `cp_waste` | 两轮结束共剩 ≥6 CP |
| `close_loss` | 敌方基地只剩 <10%，再推一波就能拆 |
| `unexplained_loss` | 没有单一短板（兜底，不再硬说“差一点”） |

## 5. 命令

```powershell
./Tools/run-game.ps1 --check
./Tools/run-game.ps1 --simulate --games=100
./Tools/run-game.ps1 --simulate --games=100 --seed=1
```

- `--check` 里与本专题相关的断言：6×6 表 / 12 兵种对表 / 训练牌 Tag 闭环 /
  R1 配置 / 隔排几何 / 规划自测（建造、3 合 1、训练、星级传递、人口）。
- `--simulate` 末尾输出 `SIM {json}`；100 局基线（seed 1..100，2026-11-21 修复后）：
  胜 66 / 负 34 / 平 0，胜率 66%，平均 159.0s，长枪身后占比 79.1%，
  平均间距 104.9 cm（按队形采样加权，不是按攻击次数）。
