# 概念：战争原岛（设计真相）

> 本文件是**设计真相**，只回答"这个游戏是什么、已经定了什么、还没定什么"。
> 实现细节在 `Documents/architecture.md`；战斗数值在 `Documents/combat_formula.md`；流程与硬约定在 `AGENTS.md`。
> 规则：被推翻的条目不删除，用删除线 + 作废日期保留。

## 一句话

**单通道 3D 长横道 + 规划阶段打牌/建造/升星三合一 + 90 秒攻防双场小队自动推进与局部微操**。玩家是**战场指挥官**，不是操作员：规划阶段（无限时、世界完全暂停）用手牌部署部队、建造工事、给部队升星；按【规划结束】后进入 90 秒执行阶段——攻防两场同时推进，小队自动接战、自动推进，玩家只做局部微操（拉队形、点技能、临时改目标）。目标平台 Steam + 低中端手机。

## 已确认

### 战场与节奏

- **单通道 3D 长横道**（2026-11-20）：战场是一条长横道，不再有"自由全图 RTS"的多线开矿与绕后。进攻场与防守场各占一端，90 秒内同时推进。
- **双阶段**（2026-11-14 起，2026-11-20 修订为 90 秒）：规划阶段无限时、世界 `paused`；执行阶段实时 90 秒；`Game.set_phase()` 是唯一阶段入口，`SceneTree.paused` 是真暂停。
- **短局是唯一模式**（2026-11-20）：删除 `--long` 旧即时战略；金币/木材只作局外长线账本（升星/改造），局内只认 **CP + 人口**。
- **小队是战斗实体**（2026-11-14）：命令记录存 `squad_id + unit_ids`；小队是 `Game/systems/小队注册表.gd` 的 RefCounted 记录。**不做士气**，成员死亡只减人数。
- **指挥官不做操作员**（2026-11-20）：执行阶段不要求持续操作；不操作也能打完，操作只提高上限。

### 规划阶段：打牌 / 建造 / 升星（三合一）

- **手牌部署**（2026-11-20）：规划阶段用手牌把部队放进战场；成本是 **CP**，人口另算。手牌数据走 `Content/data/*.json`，不写死在代码里。
- **建造**（2026-11-20）：建筑在规划阶段落点，**落点即完工**（不再有工地/进度条/农民钻入）。
- **升星**（2026-11-14 定稿，2026-11-20 保留）：击杀 15 经验、击杀者独得；升一星 = 金×2 + 木×3（三星同价）；新兵/老兵/精英/王牌；累计 +15/+30/+80% 攻击与移速、+20/+40/+100% 耐久。
- **CP**（2026-11-15）：CP 只在规划阶段出现并消耗，每回合由基地补满；执行阶段不回复、不显示。

### 工程与规则

- **引擎**：Godot 4.7 宿主 + **纯 C# 规则内核**（`Model/`，net8.0，零 Godot）。
- **距离铁律**（2026-11-20）：`R1 = 0.015`（1 点游戏数值 = 0.015 米）。`Model/` 只认游戏数值；只有 `Screens/` 在落到世界坐标时乘 R1。真值只在 `Model/Core/RtsUnits.cs`。
- **分层**：`Engine / Model / Screens / Content / Tests / Tools / Documents` 七块砖 + 迁移期 `Game/`（2026-11-14 起；2026-11-20 `Views/` 更名 `Screens/`）。
- **数据真源**：`Content/data/*.json`；文案 `Content/i18n/ui.csv`；资源 key `Content/keys/assets.json`。
- **测试默认**：静音、无焦点、隔离存档 `res://.test_profile/`，绝不读写玩家真实存档。
- **名字**：项目定名《战争原岛》（2026-11-14）。
- **语言**：结构性目录名保持英文契约；界面/注释/文档/新脚本优先中文，跨语言 key 用 ASCII。
- **平台**：Steam + 低中端手机；平台差异只允许出现在 `Engine/platform/`。
- **音效**：AudioStreamGenerator 运行时合成，不依赖音效文件；音乐仍可用文件。
- **地图编辑器**：地图/单位/建筑/技能卡的可视编辑继续由真人维护；agent 只改 JSON 并用检查验证。

## 建议（待试玩确认）

> 这些是方向，不是承诺；试玩数据说话。

- **手牌配比**：起手 5 张 / 每回合补 3 张 / CP 上限 24 —— 全部待试玩。
- **90 秒执行**：当前代码仍是 3 回合 × 60 秒的过渡值，切 90 秒要同步改 `game.json` 与波次表。
- **升星与手牌的关系**：升星是否消耗手牌、是否只在规划阶段做，待定。
- **轻量玩家路径**：默认自动施法 + 一键编队；高操作玩家可全手动。
- **手机操作**：面板化指令、框选简化、自动索敌；低端机降级项待实测。
- **数值基线**：先保证"同兵力对撞，胜负由克制与站位决定"，再谈肉鸽词条。
