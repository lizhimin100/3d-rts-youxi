# 地图底壳 × 玩家态势布局卡 × 敌人遭遇卡（三分离）

> 2026-11-21 拍板。旧的「一个 3D 地图编辑器里塞兵种/触发器/A*/经济」拆成**三层资产 + 一个组装台**。
> 一句话：**底壳管"地形与位置"，布局卡管"玩家怎么起"，遭遇卡管"敌人是谁"，关卡只是三张卡的组合。**

## 1. 三层资产

| 层 | 文件 | 谁写 | 谁读 | 里面有什么 |
|---|---|---|---|---|
| 地图底壳 | `Content/data/map_shells.json` | 3D 地图底壳编辑器（`addons/map_shell_editor`） | 布局卡页、遭遇卡页、组装页、局内 `Game/map/关卡装配.gd` | 地形高度场、地表材质、环境光/水面、纯视觉装饰、弯曲行军脊线、三块势力区域多边形、12 个战术格子（TacticalTile） |
| 玩家态势布局卡 | `Content/data/player_layouts.json` | 数据工作台 → 03 页 | 组装页、局内 | 平势/劣势/优势、激活哪几个战术格子、每个激活槽位的开局建筑（默认 1 主堡 + 2 农场 + 1 兵营） |
| 敌人遭遇卡 | `Content/data/enemy_encounters.json` | 数据工作台 → 04 页 | 组装页、局内 | 阵营（豺狼人/鱼人）、敌方基地血量、敌方格子上的固定建筑、按轮次权重的攻防意图池、波次角色表 |
| 战斗节点组装 | `Content/data/levels.json` | 数据工作台 → 05 页（一键生成） | C# 推演 / 关卡加载 | 最终可玩关卡：`assembly = {shell, player_layout, enemy_encounter}` + `lane` + `rounds` + `enemy_buildings` |

**铁律**：三张卡各自独立保存；关卡里的 `assembly` 只放三个 id，不复制三张卡的正文。改底壳不会悄悄改布局卡，改布局卡也不会写回底壳。

## 2. 3D 地图底壳编辑器（MapShellEditor）

启用：`项目设置 → 插件 → Map Shell Editor`（默认已启用）；顶部主屏出现「Map Shell Editor」，右侧 Dock 有「地图底壳」快捷工具。

只保留 **4 个纯视觉与空间划分工具**：

1. **地形与地表笔刷** — 抬升 / 降低 / 平滑 / 压平改高度场；涂抹地表改 4 个材质槽位；水面高度、环境光、雾密度实时可调。
2. **3D 装饰品** — 树 / 岩石 / 草丛 / 碎石 / 金矿 / 水面 / 栅栏 / 旗帜 / 木桩 / 木箱 / 木桶 / 帐篷 / 断墙 / 路标 / 尸骨。
   **纯视觉，不参与战斗碰撞，不写站立网格**；点空地放置、点已有选中、拖动移动、转 45°、缩放、删除。
   全部实例化 `Content/docs/asset_manifest.md` 里登记的现有资产（自然类走 `RtsDecorLib` 场景，道具类走登记的 GLB），
   **不现拼圆柱/球体占位网格**。
3. **弯曲行军脊线** — 控制点拖出自然弧度 + `通道宽度`（三位数逻辑长度，R1 换算）。
   **赛道圆环式分区已下线**，分区改由 §「势力区域多边形」的三块多边形负责。
4. **战术地形格子（TacticalTile）** — 自走棋式的地形格子：点空地新增、拖动改位置、左键拖框多选、Delete 删除、Ctrl+Z 撤销；
   **自动向下吸附地形高度**；格子之间必须留 ≥ 1.0 m 的边到边自然间隙（Model 校验）。
   每个格子两个标准本地锚点：`BuildingAnchor = 左上角`、`SquadSpawnAnchor = 正中心`；
   选中或悬停时在视口里画出金色建筑位方框与青色出兵位圈。

### 操作与观感继承旧地图编辑器（2026-11-21）

旧的 `addons/map_editor` 虽然整块下线，但**镜头手感与地形观感是资产，必须继承**：

- **镜头**：俯角 50° / FOV 52 / 距离 12–200m（默认 90，Ctrl+Shift+C 用 32 贴到玩家主堡）。
  - 右键拖动 = 平移（方向与旧编辑器逐字一致）；中键拖动 = 旋转；Shift+中键 = 平移；Alt+左键 = 旋转。
  - 滚轮 = **乘性**缩放（×0.88 / ×1.14，不是固定加减）；WASD = 平移；QE = 旋转；1/2 = 缩放；F = 聚焦选中；
    Esc/H = 取消选中；R = 装饰转 45°（Shift 反向）。
  - 镜头边界按「注视点 + 后退距离」夹取（和游戏 魔兽镜头 同一套），机位不会插进地形（只抬 y）。
  - 界外是一块深色底板 + 距离雾，不会露出天空/虚空。
- **地形材质**：直接挂 `Content/art/材质/地形材质.tres`（`Content/art/着色器/地形.gdshader`），
  路径与贴图全部转发 `RtsTerrain` 常量：8m 草/泥硬边地块 + `草泥` 图集 + `草地/泥土/裂纹泥地` 底材 + 岩石细节。
  **编辑器不另调一套顶点色配色**；顶点色只做 `RtsTerrain._tint_at` 同一套「乘法染色 + 干度」。
- **地块怎么来**：`surface.index` 的 0（草）/ 1（泥）翻译成 8m 地块格点（`mat_map`，0/255）；
  2（岩石）/ 3（沙地）在地块体系里没有对应材质，按旧编辑器走**覆盖层贴花**。
  默认新图只铺草 + 泥路（岩石/沙地手动刷），避免一开图就是大片灰色/米色贴花。
- **环境**：`战斗环境.tres` 复制一份再遮蔽（深色背景 + 0.0032 距离雾）；
  主光/补光与 `Screens/scenes/主场景.tscn` 同参数（暖色 2.35 / 冷色 0.30）。
- 自检：`godot --headless --editor --path . -- --map-shell-selftest` 会真的喂右键/滚轮/中键事件，
  断言平移、乘性缩放、旋转与地形材质 uniform 都在。

### 势力区域多边形（XZ）

- 玩家区 / 中立区 / 敌方区各是一个 **XZ 平面多边形**：`regions = {player:[[x,z],…], neutral:[…], enemy:[…]}`。
- 画法：顶栏三个按钮 `[定义玩家区] [定义中立区] [定义敌方区]` → 左键依次放顶点 → 点第一个顶点或按回车闭合；
  右键 / Esc 取消。顶点不足 3 个、面积退化、边自交都会被拒绝。
- **判定与校验只在 Model（C#）**：`Model/Map/RegionPolygon.cs` 的 `Contains(x,z)`（边界算内）与 `Validate()`；
  GDScript 通过 `Screens/bridge/ModelBridge.cs` 的 `RegionContains / RegionValidate` 调用，**不许再写第二份 Point-in-Polygon**。
- 新建底壳默认自带三块合理矩形（沿长轴切三条：玩家 0–33% / 中立 33–67% / 敌方 67–100%，z 留 8% 边距）。
- 校验（`--check`）逐块检查：顶点 ≥ 3、非退化、不自交；并用中心点验证落在中立区。

### 战术格子锚点

- 本地坐标：+X 向右、+Z 向后（屏幕上方 = -Z），与 Godot 的 Y 轴旋转一致。
- `BuildingAnchorLocal = (-w/2, -d/2)`（左上角）；`SquadSpawnAnchorLocal = (0,0)`（正中心）。
  唯一实现在 `Model/Map/TacticalTile.cs`，编辑器只调 `TileAnchors` 取世界坐标。
- 格子数据：`{index, side, role, x, z, w, d, yaw, terrain_y}`；旧 `radius/base_h` 已退役。

### 战术格子与遗迹

- 底壳有 **12 个战术格子**（左玩家区 1–6、右敌方区 7–12；玩家区 1 号 = 主堡位，敌方区 11 号 = 敌方主堡位）。
- **布局卡激活** = 局内可建造（build / keep）；**未激活** = 索引仍保留，但局内状态为 `ruin`（碎石遗迹，不可建造）。
- 这个规则只有一个实现：`Game/map/关卡装配.gd → tile_state()`。编辑器（3D 预览 + 2D 俯视图）和局内都读它。
- `--check` 会逐关核对：可建造数量 == 布局卡激活数量，且遗迹序号有效。

## 3. 数据工作台的五个页签

| 页签 | 做什么 |
|---|---|
| 01 单位与 DPS 靶场 | 12 兵种、13 项攻防穿透、真实 CombatCalculator 对账（原有） |
| 02 建筑与卡牌 | 人口 / 星级产出 / 12 张初始卡组（原有） |
| 03 **玩家态势布局卡** | 选平势/劣势/优势；在底壳俯视图上**点格子勾选激活**；给激活槽位选开局建筑；「预摆开局」= 1 主堡 + 2 农场 + 1 兵营；未激活显示「碎石遗迹」 |
| 04 **敌人遭遇卡** | 阵营下拉（豺狼人/鱼人，换阵营自动换波次角色）、敌方基地血量、敌方格子固定建筑外观（建筑 + 星级）、攻防意图池两列权重（进攻轮 / 防守轮，各 100） |
| 05 **战斗节点组装** | 三个下拉框 `[底壳] + [布局卡] + [遭遇卡]` → 「生成 / 刷新关卡」写回 `levels.json`；「跑 50 局 `--simulate`」当场出胜率 |

### 组装与推演

- `生成`：调 `dev_data.compose_level()`（唯一组装实现）→ `lane` 取自底壳（长度/宽度/敌区/三段横道）、`rounds` 取自遭遇卡波次角色表、`enemy_buildings` 取自敌方格子固定建筑、`player_board` 记录激活槽位。
- `跑 50 局`：立即落盘，然后起一个独立进程
  `godot --headless --script Tests/sim/run_simulate.gd -- --games=50 --level=<id> --out=<abs.json>`，
  页面轮询 `--out` 文件里的 SIM summary，显示「胜 / 负 / 平 · 胜率」。**不抓 stdout**，不阻塞编辑器。
- 命令行同一条路：`./Tools/run-game.ps1 --simulate --games=50 --level=level_asm_even_four__gnoll_press`。

## 5. 砍掉了什么（旧地图编辑器）

- 地图上直接摆**兵种**、**建筑**（作为战斗单位）→ 删除；建筑只作为布局卡/遭遇卡的"外观配置"存在。
- **触发器**、**波次编辑器**、**区域/出生点/玩家槽位** → 删除；波次回到遭遇卡的 `wave_plan`。
- **A\* 寻路网格涂抹**、**占位格/净空** → 删除；底壳只做视觉与空间划分。
- **经济/金矿/可采集物** → 删除。
- 旧插件 `addons/map_editor` 整目录下线；新插件源码零写死中文（文案走 `Content/i18n/ui.csv` 的 `shell.*` 键）。

## 6. 已知边界

- 战斗场景目前仍是既有单通道地图；底壳的"局内渲染"契约（`tile_state` / `ruin_tiles` / `enemy_tiles`）已可调用，
  正式战斗场景的格子渲染接线是下一阶段（渲染函数可直接复用底壳编辑器的格子构造）。
- 底壳高度场是 1.5 m 网格（120×63 m → 81×43 格）；更细的雕刻要改 `terrain.cell` 并重跑生成脚本。
- 水面是全局平面（沿用项目单水潭能力），不是局部水体。
