# 战斗公式与距离换算（combat_formula）

> **唯一实现（2026-11-24）**：`Model/Combat/CombatCalculator.cs`（6 步公式）、
> `Model/Combat/CombatRules.cs`（常数/表装载）、`Content/data/combat.json`（**4×4** 克制表 + R1）。
> 旧原型的 `Model/Core/Damage.cs`（4×5 表 + 线性护甲减免）只服务 `Game/systems/战斗.gd`
> 里的旧战斗层，**新代码一律不许再调它**；GDScript 战斗层迁完之后整块删除。
> 改公式 = 改 C# + 改本文 + 改 `--check` 的对照断言，一处都不能漏。

## 0. 距离铁律：R1

```
米 = 游戏数值 × R1        R1 = 0.015
```

- 卡面所有"距离类"数值都是**游戏数值**：射程 `95` / `155` / `650` / `850`。
- `Model/` 全层只认游戏数值；**只有 `Screens/` 把它落到世界坐标时才乘 R1**。
- 真值只有一处：`Model/Core/RtsUnits.cs` 的 `R1`；`Content/data/combat.json` 里的 `r1`
  是给数据校验用的声明，`--check` 会断言两者一致。
- `move_speed`（米/秒）与 `body_radius`（米）不是射程类数值，进场时由 `SquadBattle`
  乘 `1/R1` 换成游戏数值。

常用换算：

| 卡面数值 | 米 | 用途 |
|---:|---:|---|
| 65 | 0.975 | 鱼人奴隶 |
| 85 | 1.275 | 豺狼人斥候 |
| 95 | 1.425 | 联盟步兵 / 鱼人掠夺者 |
| 105 | 1.575 | 豺狼人战士 / 领主 |
| 155 | 2.325 | 长枪兵（隔排刺击） |
| 550 | 8.25 | 鱼人猎人 |
| 650 | 9.75 | 弓手 / 萨满 / 哨塔弩炮 |
| 850 | 12.75 | 弩兵 |

### 隔排几何（写进 --check）

```
155 - 95 = 60 游戏数值 = 0.9 米 = 0.45 + 0.45
```

步兵身位半径 0.45 米，长枪也是 0.45 米：长枪站在步兵正后方 0.9 米时，
中心到中心正好 155（2.325 米），**刚好能隔排刺击**。`--check` 直接断言
`155 - 95 == (0.45 + 0.45) / 0.015`，改任一数值都会变红。

## 1. 6 步伤害（`CombatCalculator.Compute`）

严格按顺序，纯函数（随机掷值由调用方传入 `[0,1)`）：

1. **实际命中率** = `MAX(攻方命中 - 防方闪避, 0) / 100`，夹到 `[0,1]`。
   掷值 `< 命中率` 才算命中；未命中直接 0 伤，不判暴击。
2. **暴击判定**：`掷值 < 暴击率` 时乘暴击倍率；单位默认暴击率 0，
   倍率默认 **2 倍**（`combat.json` 的 `crit_multiplier`）。
3. **有效护甲** = `基础护甲 × 护甲倍率 × (1 - 百分比穿透) - 固定穿透`
   （策略"坚壁"的护甲倍率先乘在基础护甲上；光环的 `armor_add` 直接加在基础护甲上）。
   弩兵是 `35% + 3`：10 点重甲 → `10×0.65-3 = 3.5`。
4. **护甲承伤比例**：
   - 有效护甲 `>= 0`：`1 / (1 + 有效护甲 × 0.06)`（永远 ≤ 1，不会变成 0）；
   - 有效护甲 `< 0`：`MIN(1 - 有效护甲 × 0.06, 3)`——负甲最多 **3 倍**伤害。
   - **45 秒狂暴期**：护甲按 0 结算（`berserk.armor_zero=true`）。
5. **克制表**：`counter_table[攻击类型][护甲类型]`，**4×4**，行序 =
   普通/穿刺/魔法/攻城，列序 = 无甲/轻甲/中甲/重甲。
6. **最终伤害** = `基础 × 暴击 × 承伤 × 克制 × 攻击倍率 × 承伤倍率`。

返回 `{hit, hit_chance, crit, effective_armor, armor_taken, counter, damage, feedback}`，
UI / 检查 / 复盘都直接读拆解，不再反推。

### 跳字反馈（`DamageBreakdown.Feedback`）

| 条件 | key | 表现层颜色 |
|---|---|---|
| 命中 &（暴击 或 克制 > 1） | `crit_or_counter` | 红 |
| 命中 & 克制 < 1 | `resisted` | 白 |
| 命中 & 克制 = 1 | `normal` | 常规 |
| 未命中 | `miss` | 不跳字 |

判定只发生在 `CombatCalculator`；表现层不许再查一遍克制表。

### 期望 DPS（纯数学）

```
期望单次 = 基础 × 命中率 × (1 + 暴击率 × (暴击倍率 - 1))
           × 护甲承伤(有效护甲) × 克制 × 攻击倍率 × 承伤倍率
期望 DPS = 期望单次 / max(攻击间隔, 0.05)
```

两个容易写错的地方，`--check` 都钉死：

- **必须乘实际命中率**（不是默认 100%）；
- **必须复用 `ArmorDamageTaken`**，负甲 3 倍上限不能在期望公式里丢掉。

## 2. 克制表（`Content/data/combat.json`）

| 攻\防 | 无甲 | 轻甲 | 中甲 | 重甲 |
|---|---:|---:|---:|---:|
| 普通 | 1.00 | 1.00 | 1.00 | 1.10 |
| 穿刺 | 1.50 | 1.75 | 0.75 | 0.60 |
| 魔法 | 1.25 | 1.00 | 0.75 | 1.25 |
| 攻城 | 1.00 | 0.90 | 0.50 | 1.00 |

护甲值口径：无甲 0 / 轻甲 3 / 中甲 6 / 重甲 10（玩家重甲建筑 4~8）。
`0.06` 的护甲系数让 10 点护甲 = 62.5% 承伤，克制表才是主要强弱来源。

> 2026-11-24 冻结：旧 6×6 的 `混乱 / 神力 / 坚固甲 / 神圣甲` 已从枚举、JSON、校验里
> 物理删除。`--check` 会扫所有 `armor_type/attack_type` 取值，出现旧名字直接 FAIL。

## 3. 单位默认值（`Content/data/units.json`）

- **命中 100 / 闪避 0 / 暴击 0**：随机词条留给后续升星与策略牌；
- 近战 `projectile=false`，远程 `projectile=true` 且 `projectile_speed>0`；
- 弩兵是唯一自带穿透的兵种（`armor_pen_pct=0.35`、`armor_pen_flat=3`）；
- 每单位最多 1 个自动触发的 `passive_trait`，**当前全部为 null**（字段预留）；
- `base_damage = [1,2,3]`：幸存时对敌方基地的伤害（1/2/3 星）；唯一消费点 `RoundResolver`；
- `static=true`：战场实体塔/障碍，不移动、`invMass=0`、`base_damage` 必须全 0；
- `bandit_lord` 的 `enabled=false`：配置保留，波次不许引用；
- 鱼人阵营 `use_placeholder_mesh=true`，三个兵种都走占位网格。

14 个兵种（12 + 2 种哨塔实体）与阵容见 `Documents/战斗与规划.md`。

## 4. 规划与单轮死斗（摘要）

- 开局 `1 基地（重甲）+ 2 农场 + 1 兵营`；人口 = 基地 12 + 农场 10×星级倍率。
- 建造牌：打出即 **Exhaust**，落**当前列的下一格**（竖列顺序）；拖同名建筑 **3 合 1 升满 3 星**。
- 训练牌：循环，`units_mode=per_building`（每座匹配 `building_tag` 的建筑各产一批），
  兵种星级 = 建筑星级；人口不够整张牌打不出并计入 `pop_blocked`。
- 策略牌：循环，只影响本轮（「加快训练」= 征召 ×1.5）。
- 每轮一场 **60 秒**自动战斗（`LevelDef.RoundSecondsSpec`）；双方从各自部署线直线对冲：
  - **45 秒狂暴**：全员攻速 ×2、护甲按 0 结算；
  - 一方全灭（敌方要等所有波次出场）或 60 秒到点即结束；
  - **唯一扣血结算**：幸存单位 `base_damage` 之和；双方都有幸存 → 只扣差值（相等不扣）；
    单方单轮封顶 `settle.base_damage_cap = 48`；
  - 基地血量跨轮保留，直到一方归零；12 轮上限只做僵持兜底。
- 玩家微操已全部下线：选中只读信息，推进/索敌/攻击全自动。
