## 0. 距离铁律：R1

```
米 = 游戏数值 × R1        R1 = 0.015
```

- 卡面所有"距离类"数值都是**游戏数值**：射程 `95` / `155` / `650` / `850`。
- `Model/` 全层只认游戏数值；**只有 `Screens/` 把它落到世界坐标时才乘 R1**。
- 真值只有一处：`Model/Core/RtsUnits.cs` 的 `R1`；`Content/data/combat.json` 里的 `r1`
  是给数据校验用的声明，`--check` 会断言两者一致。
- `move_speed`（米/秒）与 `body_radius`（米）不是射程类数值，进场时由 `LaneBattle`
  乘 `1/R1` 换成游戏数值。

常用换算：

| 卡面数值 | 米 | 用途 |
|---:|---:|---|
| 65 | 0.975 | 鱼人奴隶 |
| 85 | 1.275 | 豺狼人斥候 |
| 95 | 1.425 | 联盟步兵 / 鱼人掠夺者 |
| 105 | 1.575 | 豺狼人战士 / 领主 |
| 155 | 2.325 | 长枪兵（隔排刺击） |
| 550 | 8.25 | 鱼人猎人 |
| 650 | 9.75 | 弓箭手 / 萨满 |
| 850 | 12.75 | 弩兵 |

### 隔排几何（写进 --check）

```
155 - 95 = 60 游戏数值 = 0.9 米 = 0.45 + 0.45
```

步兵身位半径 0.45 米，长枪也是 0.45 米：长枪站在步兵正后方 0.9 米时，
中心到中心正好 155（2.325 米），**刚好能隔排刺击**。`--check` 直接断言
`155 - 95 == (0.45 + 0.45) / 0.015`，改任一数值都会变红。

## 1. 6 步伤害（`CombatCalculator.Compute`）

严格按顺序，纯函数（随机掷值由调用方传入 `[0,1)`）：

1. **实际命中率** = `MAX(攻方命中 - 防方闪避, 0) / 100`，夹到 `[0,1]`。
   掷值 `< 命中率` 才算命中；未命中直接 0 伤，不判暴击。
2. **暴击判定**：`掷值 < 暴击率` 时乘暴击倍率；单位默认暴击率 0，
   倍率默认 **2 倍**（`combat.json` 的 `crit_multiplier`）。
3. **有效护甲** = `基础护甲 × (1 - 百分比穿透) - 固定穿透`。
   弩兵是 `35% + 3`：10 点重甲 → `10×0.65-3 = 3.5`。
4. **护甲承伤比例**：
   - 有效护甲 `>= 0`：`1 / (1 + 有效护甲 × 0.06)`（永远 ≤ 1，不会变成 0）；
   - 有效护甲 `< 0`：`MIN(1 - 有效护甲 × 0.06, 3)`——负甲最多 **3 倍**伤害。
5. **克制表**：`counter_table[攻击类型][护甲类型]`，6×6，行序 =
   普通/穿刺/魔法/攻城/混乱/神力，列序 = 无甲/轻甲/中甲/重甲/坚固甲/神圣甲。
6. **最终伤害** = `基础 × 暴击 × 承伤 × 克制 × 攻击倍率 × 承伤倍率`。

返回 `{hit, hit_chance, crit, effective_armor, armor_taken, counter, damage}`，
UI / 检查 / 复盘都直接读拆解，不再反推。

### 期望 DPS（纯数学）

```
期望单次 = 基础 × 命中率 × (1 + 暴击率 × (暴击倍率 - 1))
           × 护甲承伤(有效护甲) × 克制 × 攻击倍率 × 承伤倍率
期望 DPS = 期望单次 / max(攻击间隔, 0.05)
```

两个容易写错的地方，`--check` 都钉死：

- **必须乘实际命中率**（不是默认 100%）；
- **必须复用 `ArmorDamageTaken`**，负甲 3 倍上限不能在期望公式里丢掉。

## 2. 克制表（`Content/data/combat.json`）

| 攻\防 | 无甲 | 轻甲 | 中甲 | 重甲 | 坚固甲 | 神圣甲 |
|---|---:|---:|---:|---:|---:|---:|
| 普通 | 1.00 | 1.00 | 1.00 | 1.10 | 0.70 | 0.80 |
| 穿刺 | 1.50 | 1.75 | 0.75 | 0.60 | 0.35 | 0.50 |
| 魔法 | 1.25 | 1.00 | 0.75 | 1.25 | 0.50 | 1.25 |
| 攻城 | 1.00 | 0.90 | 0.50 | 1.00 | 1.60 | 0.50 |
| 混乱 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 |
| 神力 | 1.20 | 1.20 | 1.20 | 1.20 | 1.20 | 1.00 |

护甲值口径：无甲 0 / 轻甲 3 / 中甲 6 / 重甲 10 / 坚固甲 8 / 神圣甲 14。
`0.06` 的护甲系数让 10 点护甲 = 62.5% 承伤，克制表才是主要强弱来源。

## 3. 单位默认值（`Content/data/units.json`）

- **命中 100 / 闪避 0 / 暴击 0**：随机词条留给后续升星与策略牌；
- 近战 `projectile=false`，远程 `projectile=true` 且 `projectile_speed>0`；
- 弩兵是唯一自带穿透的兵种（`armor_pen_pct=0.35`、`armor_pen_flat=3`）；
- 每单位最多 1 个自动触发的 `passive_trait`，**当前全部为 null**（字段预留）；
- `bandit_lord` 的 `enabled=false`：配置保留，波次不许引用；
- 鱼人阵营 `use_placeholder_mesh=true`，三个兵种都走占位网格。

12 兵种与队形/射程见 `Documents/战斗与规划.md`。

## 4. 规划与双 90 秒（摘要）

- 开局 `1 基地（坚固甲）+ 2 农场 + 1 兵营`；人口 = 基地 12 + 农场 10×星级倍率。
- 建造牌：打出即 **Exhaust**，落空地建 1 星；拖同名建筑 **3 合 1 升满 3 星**
  （星级 = 累计建筑数，封顶 3）。
- 训练牌：循环，按建筑 **Tag** 让全场同类建筑各产 1 队，兵种星级 = 建筑星级；
  人口不够的建筑跳过并计入 `pop_blocked`。
- 策略牌：循环，只影响本轮（急行军 +25% 移速 / 坚壁 +30% 护甲 / 致命瞄准 +20% 暴击）。
- 一场两轮各 **90 秒**：进攻战拆敌方基地，防守战守自己基地；基地血量跨轮保留；
  轮末清空全部部队；两轮都没拆掉敌方基地 = 未攻克。
- 全歼敌方后幸存小队继续越线；停在敌区且 9 米内无敌人时，每队每秒抽
  `zone_dps_per_squad` 点基地血；哨塔每座减 15%，最多 45%。
