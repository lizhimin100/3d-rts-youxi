# 单兵制（2026-11-22 起，2026-11-25 Phase 3 收尾）

> 本文是**现行口径**。`Documents/小队系统.md` 保留为历史记录（小队编制已被推翻），
> 两者冲突时以本文为准。`Documents/战斗表现契约.md` 是表现层接入的唯一契约表。

## 一句话

**一张征召牌 = N 名独立单兵**。每个兵自己寻路、自己索敌、自己挨打、自己死；
玩家在战斗里**只观察，不下令**（选中单位只弹只读信息面板）。

## 规则

1. **单兵原子性**：`Model/Squad/` 里一个实体就是一名单兵，**没有成员列表**
   （`SquadMember` / `Members` / `SquadMemberView` 已在 Phase 3 物理删除）。
   血量、攻击冷却、索敌目标、坐标全部直接落在 `BattleUnit` 上。
2. **攻击态 = invMass 0**：射程内（`R + 4`）有活目标 → `Locked = true` → **推不动，但仍按份额推别人**；
   硬核在所有情况下生效（唯一实现在 `BattleSim.ResolveSeparation`）。
   2026-11-24 修正：旧口径"任一方 Locked 就整对跳过分离"会让增援穿过正在对砍的人、两个锁定单位叠在同一点，
   已删除；现在只有 `invMass = 0`，不再是"删除碰撞"。
3. **无微操**：`BattleSim.IsPlayerMicroOrder` 恒 `false` —— 集火也一起下线；
   框选/点选只用于看信息（HUD 的 `UnitInfo` 面板）。
4. **结算**：幸存单位 `base_damage` 之和；双方都有幸存只扣差值（相等不扣）；单轮单方封顶 48。
   **没有占区抽血**（`zone_dps_*` 全部删除）。
5. **轮次**：60 秒一轮；轮末清场（部队抹掉，建筑与基地血保留）；
   回到规划重新打牌/建造/升星 → 下一轮（**每轮重规划**，不是"规划一次连打两场"）。
6. **胜负**：一方基地血归零即结束；12 轮仍分不出 → 僵持。

## 运动学（2026-11-24 Phase 1 / 2026-11-25 Phase 2）

### 自动布阵

| 旋钮 | 默认 | 说明 |
| --- | ---: | --- |
| `formation.file_pitch` | 96 | 同排中心距（1.44 m） |
| `formation.rank_pitch` | 144 | 排距（2.16 m） |
| `formation.line_gap` | 240 | 近战线最后一排 → 远程线第一排（3.60 m） |
| `formation.max_files` | 24 | 战场单排上限（偶数，中轴对称） |
| `formation.tile_files` | 4 | 棋盘格内出生位单排人数（7 m 格放得下） |

* **分类只认 `projectile`**：无投射物 = 近战前排（长枪兵 155 仍算近战）；有投射物 = 远程后排。
* **同定位按出牌/生成顺序排位**：`slot` 只增不减；中轴向外 ±0.5、±1.5、±2.5… × `file_pitch`；
  超宽 `slot / max_files` 自动折行，排向自家方向延伸。
* 棋盘格内出生从右下象限 `(+60,+60)` 起步，构造上避开左上建筑占地；同一格连出多批由
  `BattleSim._tileCursor` 继续往后排，不再回到同一组环点。

### 分离与停火

| 旋钮 | 默认 | 说明 |
| --- | ---: | --- |
| `combat.hard_core_factor` | 0.90 | 硬核 = 身位和 × 0.90；低于它才推 |
| `combat.stand_off_ratio` | 0.92 | 停火线 = 射程 × 0.92；**永远在开火线（R+4）内** |
| `combat.turn_rate_deg` | 540 | 转向速度（度/秒） |
| `combat.facing_deadzone_deg` | 6 | 朝向死区；差值小于它不转 |

* 逼近时步长裁到 `d - standOff`，**永不越过**停火线；不会在射程边界反复进出。
* `MoveToward` 只对**敌人**做硬核阻挡（友军交给分离）；否则后排会被前排堵死在同一条路径点上。
* 分离 **8 遍**、质量加权：攻击态/塔 `invMass=0`，驻守 `0.15`，行军 `1.0`；
  两个都不可推时各让一半（硬核始终生效）。
* 删除 `CheckStuck` 的 `X±40 / Z±180` 瞬移；开阔战场卡住只可能是人堆，交给分离。

## 表现（`Screens/world/units/`）

* **错峰空降**：新兵从 `DROP_HEIGHT = 7.2 m` 按 `y = H(1-p²)`（自由落体）落地，
  同批间隔 `DROP_STAGGER = 0.065 s`；落地压扁回弹 + 脚下光圈。
* **动画状态机只认 `state`**（Phase 3）：`march / fight / hold / dead` 四值，
  配 `state_age > 0.15 s` 防抖才换动作；旧的 `Engaged` 布尔已从快照里删除。
  有骨骼就播骨骼（步兵 `attack`、弩兵 `shoot`），同时叠一层程序动画。
* **伤害跳字**：`BattleStep` 每帧返回 `events[]`（`target_id / amount / feedback`），
  红字 = `crit_or_counter`、白字 = `resisted`、常规 = `normal`、`miss` 显示 MISS。
* **血条**：满血不画、挨打才画、选中必画（60 个人同时挂血条会把战场糊住）。
* **哨塔**：`watchtower_bolt / arrow_tower_bolt` 的 `render` 已打开，模型走
  `model_path`（`哨塔.glb` 缩到 0.18 ≈ 3.1 m 高），弹道走 `projectile`。

## Phase 2（2026-11-24 冻结）：单轮死斗 / 4×4 / 竖列棋盘

* **取消攻防轮**：`cards[].role`、`levels.rounds[].kind` 在规则里的分叉全部删除。
  每轮 = 1 场 60 秒死斗；`CampaignRun` 循环 `BoardSession → ArmyPlan → BattleSession → RoundResolver`
  直到一方基地归零。
* **结算唯一口径**：幸存单位 `base_damage[star-1]` 之和；双方都有幸存只扣差值；单轮封顶 48。
* **45 秒狂暴**：攻速 ×2、护甲按 0 结算；一方全灭即收场（敌方要等所有波次出场）。
* **4×4 克制**：普通/穿刺/魔法/攻城 × 无甲/轻甲/中甲/重甲；`DamageBreakdown.Feedback`
  输出 `crit_or_counter / resisted / normal / miss`。
* **竖列棋盘**：`BoardArena` 6 列 × 3 行；`BoardSession.PlaceBuild` 只接受当前填充位；
  `AllowFreePlacement / AllowSwap` 是钩子；`Merge` 3 合 1、`Demolish` 空出优先位。
* **机制总线**：`MechanicBus` 把 `planning.json` 的 `aura/economy/defense/mechanics` 求值成
  `ArmyPlan.Modifiers`；`BattleSim` 只认 `AttackMult / ArmorAdd / MoveMult / DamageTakenMult`。
* **战报**：胜利只留一句；战败输出 `DefeatRecord`（败于第几轮 / 敌方主力击杀 / 致命扣血单位）。

## Phase 3（2026-11-25 冻结）：表现契约 / 单轮循环 / 配平

* **单轮循环打通**：UI 删掉 `attack/defend` 两段式，改为
  `规划 → EndPlanning → BeginRound → 60 秒 → SettleRound → 回规划`；`CampaignSession` 只留
  `BeginRound / SettleRound`（旧 `BeginAttack / BeginDefend / EndRound` 已删除）。
* **表现契约**：`UnitView.State / StateAge / Moving`；`HitEvent` 队列；
  `BoardEvent`（`placed / upgraded`，带 `col/row/star`）；`DefeatRecord` 走桥暴露。
* **历史债务**：`Members / SlotError / SquadMemberView / SquadRoles / ActiveRole / outpost / zone`
  全部物理删除；`squad.json → battle.json`；`Squad*` 类型改名（见上）。
