# 单兵制（2026-11-22 起）

> 本文是**现行口径**。`Documents/小队系统.md` 保留为历史记录（小队编制已被推翻），
> 两者冲突时以本文为准。

## 一句话

**一张征召牌 = N 名独立单兵**。每个兵自己寻路、自己索敌、自己挨打、自己死；
玩家在战斗里**只观察，不下令**（选中单位只弹只读信息面板）。

## 数据（唯一数值源）

| 文件 | 字段 | 含义 |
| --- | --- | --- |
| `Content/data/units.json` | `hp / attack_damage / attack_cooldown / attack_range / armor / body_radius` | **一个卡面 = 一名单兵**的数值。没有 `squad_size / formation / squad_radius` |
|  | `pop_cost` | 征召一律 0（只吃 CP 不吃人口） |
|  | `icon_path` | 卡面图（HUD 用，不参与规则） |
| `Content/data/planning.json` | `cards[].units` | 一张训练牌一次产几名（进攻 6 / 防守 5） |
|  | `cards[].count` | 卡组里的副本数（5 / 5 / 1 / 1） |
|  | `strategies.train_boost.train_count_mult` | 「加快训练」本回合倍率 1.5（向上取整：6→9 / 5→8） |
|  | `pop.base` | 12（够造 1 座兵营，所以没有农场牌也不会卡死） |
| `Content/data/levels.json` | `player_base_hp / enemy_base_hp` | 72（StS 体量，60~80 区间） |
|  | `lane.zone_dps_per_unit` | 0.45 —— **一名**单兵停在敌区每秒抽的基地血 |
| `Content/data/squad.json` | `zone_dps_per_unit` | 覆盖关卡值（同一口径） |
|  | `free_defend.count` | 防守战白送几名据点防守兵 |

初始 12 张卡组：**征召进攻 ×5（各 6 名）+ 征召防守 ×5（各 5 名）+ 加快训练 ×1 + 建造兵营 ×1**。

## 规则

1. **单兵原子性**：`Model/Squad/` 里一个实体就是一名单兵（`Members` 恒 1 项，槽位 = 质心）。
   `SquadFormation.cs` 已物理删除 —— 没有阵型、没有队内分散 AI。
2. **攻击态锁定**：射程内有活目标 → `Locked = true` → 本 tick 不移动、且**不参与任何碰撞分离**
   （《接敌被推走》的唯一根治点，唯一实现在 `SquadBattle.ResolveSeparation`）。
3. **无微操**：`SquadBattle.IsPlayerMicroOrder` 恒 `false` —— 集火也一起下线；
   框选/点选只用于看信息（HUD 的 `UnitInfo` 面板）。
4. **占区扣血**：单兵停在敌区、且 9 米内没有敌人时，按 `zone_dps_per_unit` 抽基地血。
   72 血 ÷（10 人 × 0.45）≈ 16 秒 —— 先清场、再烧家。
5. **轮次**：60 秒一轮，轮末清场（部队抹掉，建筑与基地血保留）。

## 表现（`Screens/world/units/`）

* **错峰空降**：新兵从 `DROP_HEIGHT = 7.2 m` 按 `y = H(1-p²)`（自由落体）落地，
  同批间隔 `DROP_STAGGER = 0.065 s`；落点用 `UnitBody.SpawnRing`（黄金角螺旋 + 右下偏置，
  严格避开左上角建筑占地）；落地压扁回弹 + 脚下光圈。
* **动画状态机**：`idle / move / attack / death` 四态；有骨骼就播骨骼（步兵 `attack`、
  弩兵 `shoot`），同时叠一层程序动画 —— 走路上下颠 + 前倾、出手前冲（远程是后坐）、
  受击整身闪白、死亡向前扑倒。远程开火额外拉一条 0.1 秒的弹道亮条。
* **血条**：满血不画、挨打才画、选中必画（60 个人同时挂血条会把战场糊住）。
* 换模型只改 `units.json` 的 `model_path`；`方块人_步兵.glb` 是零动画资产（5 节点无骨骼），
  步兵已换成 `方块人_联盟步兵.glb`。

## 已知取舍

* `Squad*` 这些**类型名**保留（`SquadBattle / SquadView / SquadSession`）：它们是跨语言契约
  （GDScript 桥、208 条自检、截图配方都按这个名字调）。语义已是"一名单兵"，改名只会制造一次
  大范围迁移，不会让玩法更对。
* 战绩里的 "squads" 字段 = **人数**（不是队数），HUD 与战报文案统一写"名"。
