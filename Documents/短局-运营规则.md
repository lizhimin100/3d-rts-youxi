# 短局运营规则（CP / 人口 / 小队 / 建造订单）

> 状态：现行（2026-11-15）。实现真相；设计来源是玩家任务书与 `concept.md`。

这篇只写"代码现在按什么规则跑"，便于改数值和排查。数值全部在
`Content/data/cards/units/*.json`、`Content/data/cards/buildings/*.json`、`Content/data/game.json`。

---

## 1. CP：只活在规划阶段

| 规则 | 实现 |
|---|---|
| 每回合**规划阶段**由基地补满 | `回合控制.end_execution()` → `RtsFaction.begin_planning_cp()` |
| 上回合剩余清零（不是累加） | 同上，直接 `cp = cp_cap` |
| 执行阶段**不回复、不显示、不能花** | `Game._process` 不再 tick CP；HUD 执行资源条不显示 CP 胶囊 |
| 下单即扣、不退、不跨回合 | `Game.pay()`/`Game.refund()` 按短局走 CP；训练/建造在规划阶段结算 |
| 执行阶段点训练 = 无效 | `可用性.check_train(phase_ok=false)` → `not_planning`；建筑 `queue_train` 也会拒绝 |

`Cfg.game.short_cp_start` / `short_cp_cap` 默认都是 24（第一回合与后续回合都补满到上限）。
`short_cp_regen` 保留字段但已停用（0）。

## 2. 执行阶段 = 3 分钟

- `game.json` → `short_execution_seconds = 180.0`，读数是 `回合控制.execution_total()`。
- 只有"倒计时归零"或"基地被拆"结束；**清完一波不再提前收工**（旧版会提前回规划，已删）。
- 到点回规划；未完成训练在回合边界取消、不退 CP。

## 3. 小队（生产的基本单位）

卡的字段（单位卡）：

| 字段 | 含义 | 当前值 |
|---|---|---|
| `cp_cost` | 一次下单的 CP | 农民 1 / 步兵 2 / 弩兵 3 |
| `squad_size` | 一小队几人 | 农民 4 / 步兵 5 / 弩兵 4 |
| `pop_cost` | **一小队占多少人口**（不是人头） | 农民 4 / 步兵 8 / 弩兵 10 |

- 训练一次 = 出一整个小队（`RtsBuilding._spawn_trained` 按 `squad_size` 循环生成）。
- 人口按**队伍**记：成员减员不退还，整队打光才释放（`RtsFaction.squad_commits`）。
- 开局地图/布局卡摆的散兵会在 `Game.normalize_squads()` 里按 `squad_size` 编组。
- 长局仍是 1 个/次、按人头 `food_cost` 算人口（`RtsFaction.is_short()` 分流）。

## 4. 建筑也占人口

- 建筑卡 `pop_cost`：大本营/农场 = 0；兵营 4、铁匠铺 2、伐木场 2、哨塔/箭塔 2。
- 被拆/取消 → 节点释放，人口自动返还（`food_used()` 只统计存活建筑）。
- 农场 `food_provided` 从 8 调到 20、大本营 24 → 60：一队步兵就是 8 人口，旧上限撑不起小队制。
  这些都在卡里，随时可调。

## 5. 建造订单（执行阶段只能施工规划阶段下过的单）

- 规划阶段落一座工地 = 一条订单（`RtsFaction.build_orders`），CP 已在落地时扣掉。
- 执行阶段 `place_building` 只接受"有未落地订单"的建筑；没有就拒绝并提示。
- 执行阶段取消工地：**不退 CP**，订单回到"可重新选址"（`release_build_site`），农民走过去重建。
- 规划阶段撤销工地：退 CP、订单删除（`drop_build_site`）。
- 执行阶段取消训练/改队列：直接拒绝（`request_cancel_train*` + `queue_train` 双保险）。

## 6. UI 落点

- 规划卡：`Screens/hud/规划阶段界面.gd`，成本行 = `CP x · y 人`（I18n key `plan.card_cost*`）。
- 规划地图层：`Screens/hud/规划地图层.gd` 的兵牌可点击（建筑牌→训练，兵牌→部署，农民→建造）。
- 命令卡：`Screens/hud/命令卡.gd` 的训练/建造提示显示 CP + 人口 + 每队人数。
